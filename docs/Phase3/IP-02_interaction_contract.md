## 0. 文档定位与铁律遵守

本文为 B3 §8 归属校验表中 **TP-01…TP-30（= C01–C30）每一个触点**定义交互契约。节点集严格 = C01–C30，**无遗漏、无新增**。

每个触点契约包含字段：

| 字段 | 含义 |
|------|------|
| 能力ID | TP-nn ↔ Cnn |
| 所属主干/层 | Explore / Understand / Compare / Mirror / 常驻层 / 隐性底层 |
| 点击行为 | 用户单击该触点触发什么 |
| 导航行为 | 该触点把用户带向哪里（容器内） |
| 返回行为 | 从该触点如何返回 |
| 展开/折叠 | 该触点自身的展开/折叠语义 |
| 切换 | 涉及的主干/状态切换 |
| 反馈 | 用户对动作的可感响应 |
| 状态切换 | 触发哪些常驻层/认知态变化 |
| 与其他触点衔接 | 上游来源与下游去向（B3 §7 矩阵） |

**一致性根基**：在四主干同构语法（锚点→关系→理由→推进）下，所有触点的点击/导航/返回/展开/折叠/切换/反馈/状态切换**交互方式一致**。差异仅来自提问角度。

## 1. Explore 主干（TP-01…TP-09 中的 Explore 项，含 TP-24/25/26/27）

### TP-01 事实落地面（C01）— Explore
- 能力ID：TP-01 / C01 Fact 事实供给
- 所属主干：Explore（锚点格）
- 点击行为：单击历史实体 = 激活并载入事实落地面，留在 Session 容器（C-1）。
- 导航行为：作为 Explore 锚点；其关系可导向 TP-02。
- 返回行为：沿 TP-20 轨迹链回退一步（B-1）；不重置常驻层。
- 展开/折叠：展开 = 显示事实细节与可点关系端（E-1/E-2）；折叠 = 收回到锚点（F-1）。
- 切换：可经 TP-16 `open_dimension` 进入新维度锚点（§3.1）。
- 反馈：载入完成即时回执（FB-1）。
- 状态切换：更新 TP-15 覆盖态（已覆盖该实体）。
- 衔接：来源 TP-26/TP-24/TP-03；去向 TP-02（关系）。

### TP-02 关系展开面（C02）— Explore
- 能力ID：TP-02 / C02 Relationship 关系结构
- 所属主干：Explore（关系格）
- 点击行为：单击关系目标端 = 以该端为新锚点展开，原锚点保留为来源（C-2）。
- 导航行为：在 Explore 内沿关系推进；可分叉至 TP-03 跨主题。
- 返回行为：回退到来源锚点（B-1）。
- 展开/折叠：展开关系列表（E-2）；折叠回锚点（F-1）。
- 切换：关系中的因果链可经 TP-16 `follow_cause` 转 Understand（TP-10）。
- 反馈：关系载入回执（FB-1）。
- 状态切换：更新 TP-15 已覆盖关系。
- 衔接：来源 TP-01；去向 TP-01(新锚点)/TP-03/TP-10。

### TP-03 边界续走位（C03）— Explore
- 能力ID：TP-03 / C03 Cross-topic Connectivity
- 所属主干：Explore（推进格 / 跨主题连通）
- 点击行为：单击续走位 = 载入相邻主题锚点，原主题保留于轨迹（C-2）。
- 导航行为：Explore 内续走新主题；亦为 Compare 对比对象的结构来源（B3 §2.3）。
- 返回行为：回退到上一主题锚点（B-1）。
- 展开/折叠：展开主题邻接列表（E-1）。
- 切换：跨主题不改变主干；可经 TP-16 转其他主干。
- 反馈：续走回执（FB-1）。
- 状态切换：更新 TP-15 跨主题覆盖。
- 衔接：来源 TP-01/TP-02；去向 TP-01(新主题)/TP-14(对比对象来源)。

### TP-04 时间对齐轴（C04）— Explore
- 能力ID：TP-04 / C04 Temporal Structuring
- 所属主干：Explore（关系维度）；亦为 Compare 同时性前提
- 点击行为：单击时间节点 = 对齐并载入该时点锚点（C-1）。
- 导航行为：在 Explore 内沿时间轴推进；为 Compare 提供同时性前提（B3 §2.3）。
- 返回行为：回退时间节点（B-1）。
- 展开/折叠：展开时间轴相邻时点（E-1）。
- 切换：无主干切换。
- 反馈：对齐回执（FB-1）。
- 状态切换：更新 TP-15 时间覆盖。
- 衔接：来源 TP-01；去向 TP-14(同时性前提)。

### TP-05 地点锚定位（C05）— Explore
- 能力ID：TP-05 / C05 Spatial Anchoring
- 所属主干：Explore（关系维度）
- 点击行为：单击地点 = 载入该地锚点（C-1）。
- 导航行为：Explore 内空间维度推进。
- 返回行为：回退地点锚点（B-1）。
- 展开/折叠：展开地点邻接（E-1）。
- 切换：无。
- 反馈：锚定回执（FB-1）。
- 状态切换：更新 TP-15 空间覆盖。
- 衔接：来源 TP-01；去向 TP-02/TP-03。

### TP-24 定向直达（C24）— Explore（次级，不主导首屏）
- 能力ID：TP-24 / C24 Search
- 所属主干：Explore（次级通道，R6 / ADR-0014 D2，不主导首屏）
- 点击行为：用户已有目标名词 → 输入并直达该实体锚点（确定性直达，非推荐）（B3 §4.3）。
- 导航行为：直达 TP-01 锚点；不主导首屏心智（守则 ③）。
- 返回行为：回退到进入搜索前的锚点（B-1）。
- 展开/折叠：搜索结果可展开为锚点。
- 切换：无。
- 反馈：直达结果回执；无个性化（FB-2）。
- 状态切换：更新 TP-15 覆盖。
- 衔接：与 TP-16/TP-27 语义互斥（B3 §4.3）；来源常驻层/首屏；去向 TP-01。

### TP-25 问题锚（C25）— Explore
- 能力ID：TP-25 / C25 Question Asking
- 所属主干：Explore（锚点提问）
- 点击行为：用户提出问题 = 以问题为锚点载入相关事实（C-1）。
- 导航行为：Explore 内问题驱动探索。
- 返回行为：回退到问题前锚点（B-1）。
- 展开/折叠：展开问题关联实体。
- 切换：可经 TP-16 转 Understand（问「为什么」）。
- 反馈：问题锚定回执（FB-1）。
- 状态切换：更新 TP-15 覆盖。
- 衔接：来源 TP-01/TP-26；去向 TP-01/TP-10。

### TP-26 起跳台（C26）— Explore（首屏承担者）
- 能力ID：TP-26 / C26 Curated Exploration Package
- 所属主干：Explore（首屏承担者，R6 / ADR-0014 D2）
- 点击行为：首屏默认落点；单击起跳项 = 载入对应锚点（C-1）。
- 导航行为：首屏心智由 TP-26 承担；TP-24 检索在场不抢戏（守则 ③）。
- 返回行为：回到起跳台概览（B-1）。
- 展开/折叠：展开起跳包内各探索线（E-1）。
- 切换：可经 TP-16 进入任一主干。
- 反馈：起跳回执（FB-1）。
- 状态切换：初始化 TP-15/TP-20 会话态（ADR-0015 D6）。
- 衔接：首访默认落点；来源无（进场）；去向 TP-01/TP-16。

### TP-27 停滞接住（C27）— Explore
- 能力ID：TP-27 / C27 Deterministic Guide
- 所属主干：Explore（停滞接住）
- 点击行为：用户停滞、不知该做什么动作 → 单击确定性动作提示（禁个性化、禁打分）（B3 §4.3）。
- 导航行为：给出**动作提示**（确定性模板），不替代 TP-16 方向决策；不伪装为推荐。
- 返回行为：回到停滞前锚点（B-1）。
- 展开/折叠：展开动作提示列表（E-1）。
- 切换：提示可指向任一主干动作，但不自动切换。
- 反馈：确定性动作提示（FB-2，非评判）。
- 状态切换：不改覆盖态判定。
- 衔接：与 TP-16/TP-24 语义互斥；去向由用户选择的动作决定。

## 2. Understand 主干（TP-06/07/08/10/11/12/13 + TP-06/07/08 刻度归属）

### TP-10 机制陈述面（C10）— Understand
- 能力ID：TP-10 / C10 Causal Explanation
- 所属主干：Understand（因果机制）
- 点击行为：单击机制节点 = 载入因果陈述（C-1）。
- 导航行为：Understand 内部推进 → TP-11 → TP-13。
- 返回行为：回退机制前锚点（B-1）。
- 展开/折叠：展开因果链（E-1）；与 TP-11 理由同显。
- 切换：内部权威顺序 TP-12 > TP-10 > TP-11（ADR-0015 D4）。
- 反馈：机制载入回执（FB-1）。
- 状态切换：更新 TP-15 机制覆盖。
- 衔接：来源 TP-02(因果关系)/TP-16 `follow_cause`；去向 TP-11/TP-13。

### TP-11 连接理由行（C11）— Understand
- 能力ID：TP-11 / C11 Connection Explanation
- 所属主干：Understand（理由格）
- 点击行为：单击理由 = 就地展开可读解释 `rationale`（C-3/E-3）。

- 展开/折叠：展开 = 显示 `rationale.text` + 规则来源 + 触发维度（E-3）。
- 切换：无。
- 反馈：理由呈现回执（FB-1）。
- 状态切换：无。
- 衔接：来源 TP-10；去向 TP-13。

### TP-12 人话转译（C12）— Understand
- 能力ID：TP-12 / C12 Grounded AI Interpretation
- 所属主干：Understand（解释，权威最高阶）
- 点击行为：单击转译 = 载入 AI Gateway 解释（C-1）。
- 导航行为：Understand 内部；高阶不可用时低阶以自身身份出场（D4）。
- 返回行为：回退（B-1）。
- 展开/折叠：展开转译详情。
- 切换：无。
- 反馈：转译回执（FB-1）。
- 状态切换：无。
- 衔接：来源 TP-10/TP-11；去向 TP-13。

### TP-13 意义入口（C13）— Understand
- 能力ID：TP-13 / C13 Semantic Understanding
- 所属主干：Understand（意义 / 推进格落点）；亦为 Compare 对比结论落点、Mirror 理由格
- 点击行为：单击意义节点 = 载入意义结构（C-1）。

- 返回行为：回退到机制/对比前（B-1）。
- 展开/折叠：展开意义网络。
- 切换：意义建立后可转 Compare（`compare_context`）。
- 反馈：意义建立回执（FB-1）。
- 状态切换：更新 TP-15 意义覆盖。
- 衔接：来源 TP-10/TP-11/TP-14；去向 TP-16/TP-14。

### TP-06 来源分级刻度（C06）— Understand（真相刻度①，贴住结论）

- 切换：无。
- 反馈：刻度呈现回执（FB-1）。
- 状态切换：无。

## 3. Compare 主干（TP-14，P0 独立入口）

### TP-14 对比台（C14）— Compare（P0）
- 能力ID：TP-14 / C14 Cross-civilization Comparison
- 所属主干：Compare（P0 独立入口，ADR-0015 D3）
- 点击行为：① 从 Understand 自发触发进入；② **常驻层独立入口直入**（无前置条件、不要求先选定实体）（CD-1）。
- 导航行为：Compare 主干；不成对时呈现已知边界说明 + TP-16 补齐动作，不作空入口（CD-2 / B1 §9 F-3）。
- 返回行为：沿 TP-20 回退；或经常驻层返回其他主干（B-3）。
- 展开/折叠：展开并列对象的分岔分析（E-1）；对比结论同样挂真相刻度三件套（TS-1）。
- 切换：换一组对比对象（不退化下级，CD-3）；对比结论落 TP-13 或转 Explore 新起点。
- 反馈：对比载入回执；供给不足时诚实边界说明（FB-1/FB-3）。
- 状态切换：更新 TP-15 对比覆盖（全局唯一）。
- 衔接：来源 TP-13(自发)/常驻层(直入)/TP-03(对象来源)/TP-04(同时性前提);去向 TP-13/TP-01。

## 4. Mirror 主干（TP-19/TP-22，L4.5 只读终点）

### TP-19 成长刻度（C19）— Mirror
- 能力ID：TP-19 / C19 Growth Measurement
- 所属主干：Mirror（L4.5 只读投影）
- 点击行为：单击成长项 = 反射本次会话的四项增量（只读，不写回）（ME-3）。
- 导航行为：镜像内反射；**无出边**（ME-1）。
- 返回行为：无返回出边；用户想继续须自经常驻层返回（ME-2 / B3 §7 Mirror 行）。
- 展开/折叠：展开增量明细（只读）。
- 切换：无（镜像不切换主干去别处）。
- 反馈：反射呈现回执（FB-1，无打分）。
- 状态切换：不写回任何状态（ME-3 / ADR-0015 D6）。
- 衔接：原料来自 TP-20/TP-15/TP-18；无去向（终点）。

### TP-22 镜像出口（C22）— Mirror（L4.5 终点出口）
- 能力ID：TP-22 / C22 Cognitive Mirror
- 所属主干：Mirror（L4.5 终点出口，ADR-0015 D2）
- 点击行为：单击镜像节点 = 反射用户自身轨迹结构（只读，不评级不打分）（ME-3）。
- 导航行为：**反射即终点，无出边**。页内不得出现「下一步去看 X」（ME-1/ME-2）。
- 返回行为：无出边；用户经常驻层自行返回（B3 §7 Mirror 行）。
- 展开/折叠：展开轨迹段（只读反射）。
- 切换：无。
- 反馈：镜像反射回执（FB-1，给结构不给结论）。
- 状态切换：不作 ExplorationPolicy 输入；不持久化画像（ME-3 / X-R5 / D6）。
- 衔接：原料来自 TP-20/TP-15/TP-19；**与 EC-16（下一步决策）绝对隔离**（B4 §5）；无去向。

## 5. 常驻层（TP-15/16/18/20/23/28，跨主干保全）

### TP-15 探索状态（C15）— 常驻层
- 能力ID：TP-15 / C15 Exploration State
- 所属层：常驻层（全局唯一覆盖态）
- 点击行为：单击 = 展开覆盖/缺口视图（D-1/D-2）。
- 导航行为：不离开当前主干；仅展示状态。
- 返回行为：折叠回（F-1）。
- 展开/折叠：展开覆盖明细（E-1）。
- 切换：主干切换时**不清空**（PP-2 / 守则 ⑧）。
- 反馈：状态更新回执（FB-1）。
- 状态切换：自身即状态源；全局唯一不分裂（ST-1）。
- 衔接：被所有主干触点更新；驱动 TP-16 缺口。

### TP-16 下一步去哪（C16）— 常驻层（唯一方向出口，A2 契约）
- 能力ID：TP-16 / C16 Cognitive Advancement Decision
- 所属层：常驻层（四主干下均在场，语义一致）
- 点击行为：单击下一步项 = `onNodeClick(targetEntity)`（C-4），去向由 A2 `actionType` 决定（NP-1/§3.1）。
- 导航行为：唯一「下一步」出口；五 actionType 对应 Explore/Understand/Compare/下沉/引向 Mirror（§3.1）。**禁用推荐语汇**（X-R1）。
- 返回行为：折叠回（F-1）；不重置常驻层。
- 展开/折叠：展开五项下一步候选，每项携带 `rationale`(理由可读) + `coverageBeforeAfter.delta`(缺口可见)（NP-2/E-3）。
- 切换：可触发主干切换（`follow_cause`/`compare_context`/`open_dimension`）。

## 7. 特殊触点交互契约重点复核

### 7.1 TP-16 下一步（消费 A2 五 actionType，禁用推荐语汇）
- 唯一出口（X-R6）；五 actionType 标准映射见 IP-01 §3.1。
- 每个下一步携带 `rationale.text` + `ruleId` + `triggeredDimension`（理由可读）与 `coverageBeforeAfter.delta`（缺口可见）。
- 禁用「推荐/猜你喜欢/相关内容/其他用户也看了」（X-R1 / A2 红线）。
- 与 TP-24（已知目标直达）、TP-27（停滞确定性动作提示）语义互斥，互不替代（B3 §4.3）。

### 7.2 TP-22 Mirror（无出边，守 ADR-0013 D3 / ADR-0015 D2）
- 无出边至 TP-16；页内禁「下一步去看 X」（ME-1/ME-2）。
- 不作 ExplorationPolicy 输入（A1 §2 无镜像字段）。
- 只反射本次会话（D6 不持久化）。
- 解读权归用户，不评级不打分（ME-3）。
- 与 EC-16（TP-16 决策）绝对隔离（B4 §5）。

### 7.3 TP-14 Compare（可直入，不退化下级，ADR-0015 D3）
- 双入口：Understand 自发 + 常驻层独立直入（无前置条件）。
- 不成对时不作空入口，呈现边界说明 + TP-16 补齐（CD-2）。
- 对比结论落 TP-13 或转 Explore 新起点，不退化下级（CD-3）。

### 7.4 TP-26 首屏承担者 vs TP-24 检索不主导首屏（守则 ③）
- TP-26 承担首屏心智（起跳台默认落点）。
- TP-24 检索可在场，但不得主导首屏（R6 / ADR-0014 D2）。
- 二者在首屏共存，TP-24 次级不抢戏。
