## 0. 文档定位与 Phase 3 铁律遵守方式

本文是 Phase 3 的**唯一交互真理来源**：它定义「人与产品如何交互」——操作逻辑、点击行为、导航行为、返回行为、展开、折叠、切换、反馈、动画逻辑、状态切换。它不描述颜色、字体、具体视觉样式，不写代码，不进入 Phase 4。

| 条款 | 本文的遵守方式 |
|------|--------------|
| 唯一目标 = 交互逻辑 | 全文只描述「人做什么动作、产品给什么响应」；无任何视觉、组件、颜色、字体、布局描述 |
| 不得提前设计 | 不出现任何具体 UI 组件名称（按钮/卡片/弹窗）的视觉定义；只定义交互动作语义 |
| 不写代码 | 全文为规则与契约，无函数、无样式表、无标记语言 |
| 节点集一致 | 交互维度与触点全部映射到 B3 §8 的 TP-01…TP-30，无新增能力 |
| 每阶段有产出物 + Exit Criteria | 文末 §10 Exit Criteria 自检 |

**一致性根基（一句话）：** 四条主干共用同一探索语法「**锚点 → 关系 → 理由 → 推进**」，因此交互动作**完全同构**——用户学会一次，四处通用。任何交互规则在四条主干下必须一致表达，差异只允许来自「提问角度」而非「操作方式」。

## 1. 统一交互词汇表（Interaction Vocabulary）

> 全产品只使用以下术语表达交互。术语在四主干、常驻层、隐性底层含义恒定，不做语境重定义。

| 术语 | 含义（交互层） | 标准交互动作表达 |
|------|--------------|----------------|
| **锚点 Anchor** | 用户当前落定的一个对象（实体 / 结论 / 可比组 / 自身轨迹段） | 单击 = 激活并载入锚点内容；不离开容器 |
| **关系 Relation** | 锚点连向的其他锚点（因果 / 邻接 / 同时 / 分岔） | 单击关系中的目标端 = 以该端为新锚点展开；原锚点保留为来源 |
| **理由 Reason** | 为什么连、为什么可信、为什么不同、为什么反复（可读的解释） | 展开 = 呈现 `rationale`（可读文本 + 规则来源），不隐藏、不跳外链 |
| **推进 Advance** | 沿探索语法进入下一格（下一步探索 / 深入 / 换角度） | 触发 TP-16，呈现 A2 `ExplorationAction`（五 actionType 之一） |
| **主干 Trunk** | 四条提问角度之一：Explore / Understand / Compare / Mirror | 切换 = 换提问角度，保留常驻层与探索语法不变 |
| **常驻层 Persistent** | 始终在场、跨主干延续的六项坐标（TP-15/16/18/20/23/28） | 任何位置均可见、可点，不随主干切换重置 |
| **隐性底层 Ambient** | 用户以「不出事」感知的五项底层保证（TP-09/17/21/29/30） | 无显式触点交互；只在违约时被用户感知为「出事了」 |
| **真相刻度 Scale** | 来源分级 / 证据强度 / 溯源异议三件套（TP-06/07/08） | 贴住每条结论出现；随结论展开/折叠而同显隐 |
| **下一步 Next** | 全产品唯一方向出口 TP-16 | 只呈现 A2 `ExplorationAction`；禁用推荐语汇 |
| **镜像 Mirror** | L4.5 只读投影出口（TP-19/22） | 反射即终点；无出边、无决策输入、只反射本次会话 |
| **对比 Compare** | 并列对象的分岔分析（TP-14） | P0 独立入口；可直入；不退化下级 |
| **Workspace** | 主探索工作区容器（承载当前主干的锚点/关系/理由） | 单一主工作区；同一时刻只有一条主干在其中活动 |
| **Companion** | 解释伴随层（TP-21 呈现粒度） | 与当前锚点同显的辅助解释；不抢占主区焦点 |
| **Panel** | 侧载面板（展开/折叠的信息块） | 展开 = 就地展开同上下文面板；折叠 = 收起回锚点 |
| **Dock** | 常驻停靠条（常驻层六项的归所） | 常驻不消失；点击任一项不重置其他项 |
| **Rail** | 主干切换轨（四条主干的切换入口） | 点击切换主干；不重建容器、不丢失常驻层 |
| **反馈 Feedback** | 用户对任何动作的可感响应 | 状态即时回执（接受/进行中/完成/缺口可见），无装饰性动效 |
| **状态切换 State Switch** | 认知状态 / 覆盖态 / 语言态等变化 | 切换即更新常驻层对应项；全局单一状态，不分主干各算 |
| **动画逻辑 Animation** | 动作间的过渡表达 | 仅功能性过渡（进入/退出/展开）；禁用弹跳缓动；可被降级为瞬时切换 |
| **返回 Back** | 回退到上一交互节点 | 返回 = 沿轨迹链回退一步；不重置常驻层；不丢覆盖态 |

## 2. 全局统一交互维度规则

> 以下对 FRW Phase 3 列出的**全部交互维度**逐一给出统一规则。任一维度在四主干下表达一致。

### 2.1 点击行为 Click
- **规则 C-1**：单击锚点 = 激活并载入锚点内容，留在原容器，不新开窗口/不跳转外部。
- **规则 C-2**：单击关系目标端 = 以该端为新锚点展开，原锚点作为来源被保留在轨迹链（TP-20）。
- **规则 C-3**：单击理由 = 就地展开可读解释（`rationale.text` + 规则来源），不离开上下文。
- **规则 C-4**：任何「下一步」点击 = 触发 `onNodeClick(targetEntity)`，去向由 A2 `actionType` 决定（见 §3.1）。
- **规则 C-5**：点击不得伪装意图——TP-24/TP-27/TP-16 三者点击语义互斥，互不替代（B3 §4.3）。

### 2.2 导航行为 Navigation
- **规则 N-1**：唯一容器 = Explorer Session；任何能力导航都在容器内完成（B3 §9 守则 1）。
- **规则 N-2**：四条主干共用同构语法；导航去向只由「当前主干 + 用户提问角度」决定，不由「组件形态」决定。
- **规则 N-3**：主干间转移只允许 B3 §7 转移矩阵中的格子；任意两主干间必有明确转移与携带物，无导航死角。
- **规则 N-4**：Compare 可直入（常驻层或首访 T4 入口），不要求先选定实体，不退化下级（B3 §9 守则 5）。

### 2.3 返回行为 Back
- **规则 B-1**：返回 = 沿 TP-20 轨迹链回退一步，回到上一锚点/关系节点。
- **规则 B-2**：返回**不重置**常驻层（TP-15/16/18/20/23/28 保持），**不丢失**认知覆盖态（TP-15）。
- **规则 B-3**：Mirror（TP-22/19）无返回出边；用户想继续须自行经常驻层返回（B3 §7 Mirror 行）。

### 2.4 展开 Expand
- **规则 E-1**：展开 = 在当前上下文就地展开（Panel / 关系 / 理由 / 刻度）。
- **规则 E-2**：展开锚点的关系 = 显式列出关系目标端，每条可独立点击成新锚点。
- **规则 E-3**：展开理由 = 呈现 `rationale`（可读文本 + 规则来源 + 触发维度），缺口可见（`coverageBeforeAfter.delta`）。

### 2.5 折叠 Collapse
- **规则 F-1**：折叠 = 收起回锚点，保留已展开内容的来源痕迹于轨迹链。
- **规则 F-2**：折叠真相刻度 = 与其所贴结论同显隐，结论在则刻度在。
- **规则 F-3**：折叠不触发新导航，不改变常驻层。

### 2.6 切换 Switch
- **规则 S-1**：主干切换（Rail）不重建容器、不丢失常驻层、不清空轨迹链与覆盖态（B3 §9 守则 8）。
- **规则 S-2**：语言切换（TP-28）不改变认知对象身份，只改变术语表达（B3 §5）。
- **规则 S-3**：状态切换（覆盖态/认知态）全局单一，不按主干各算一份（B3 §5 TP-15）。

### 2.7 Workspace（主工作区）
- **规则 W-1**：单一主工作区承载当前主干的锚点/关系/理由/推进。
- **规则 W-2**：同一时刻只有一条主干在 Workspace 内活动；切换主干 = 换提问角度，不换工作区。
- **规则 W-3**：Workspace 内所有交互遵循本章节维度规则，不以主干而变。

### 2.8 Companion（伴随层）
- **规则 P-1**：Companion 承载 TP-21 的解释粒度，与当前锚点同显。
- **规则 P-2**：Companion 不抢占 Workspace 主区焦点；可独立折叠，不影响主区锚点。
- **规则 P-3**：Companion 解释权威顺序 = AI Gateway(TP-12) > Causal(TP-10) > 模板短语(TP-11)，高阶不可用时低阶以自身身份出场（ADR-0015 D4）。

### 2.9 Panel（侧载面板）
- **规则 A-1**：Panel 为就地展开的信息块，展开/折叠不改变导航位置。
- **规则 A-2**：Panel 内容可承载关系、理由、刻度、溯源清单（TP-08）。

### 2.10 Dock（常驻停靠条）
- **规则 D-1**：Dock 是常驻层六项（TP-15/16/18/20/23/28）的归所，常驻不消失。
- **规则 D-2**：点击 Dock 任一项不重置其他项；Dock 在主干切换时保持（B3 §9 守则 8）。

### 2.11 Rail（主干切换轨）
- **规则 R-1**：Rail 提供四条主干切换入口，点击切换主干（见 §3.4）。
- **规则 R-2**：Rail 不可扩展出第五种主干；新能力须归入四主干或常驻层（B3 §3 约束 3）。

### 2.12 反馈 Feedback
- **规则 FB-1**：任何动作须有即时可感响应——接受 / 进行中 / 完成 / 缺口可见。
- **规则 FB-2**：反馈表达状态，不表达个性化评判；TP-27 确定性引导与 TP-16 方向决策语义互不替代（B3 §4.3）。
- **规则 FB-3**：反馈不引入「推荐/猜你喜欢」等语汇（见 §4 红线）。

### 2.13 动画逻辑 Animation
- **规则 AN-1**：仅功能性过渡——进入 / 退出 / 展开 / 折叠。
- **规则 AN-2**：**禁用弹跳缓动** `cubic-bezier(0.68,-0.55,0.265,1.55)`；仅用线性或缓入缓出（ease-in-out）。
- **规则 AN-3**：动画可被降级为瞬时切换（无障碍 / 低性能下关闭动效）。
- **规则 AN-4**：动画不产生新交互含义，仅为状态变化的可见表达。

### 2.14 状态切换 State Switch
- **规则 ST-1**：认知覆盖态（TP-15）全局唯一；切换主干不算新状态。
- **规则 ST-2**：语言态（TP-28）切换只改术语，不改对象身份。
- **规则 ST-3**：会话态（TP-18/20）不持久化（ADR-0015 D6）；离场即清空口径明示（B5 §5）。

### 2.15 主干切换 Trunk Switch（B3 衍生）
- 见 §3.4 与 2.6 / 2.11；核心是「换角度不换台、不重置、不丢态」。

### 2.16 常驻层保全 Persistent Preservation（B3 衍生）
- **规则 PP-1**：常驻层六项（TP-15/16/18/20/23/28）在任意主干切换、展开/折叠、导航中保全。
- **规则 PP-2**：主干切换不清空 From/Why/Value 叙述（TP-23），轨迹累加不叉分（TP-20），覆盖态全局唯一（TP-15）。

### 2.17 真相刻度呈现 Truth Scale Presentation（B3 衍生）
- **规则 TS-1**：真相刻度三件套（TP-06 来源分级 / TP-07 证据强度 / TP-08 溯源异议）**贴住每条结论出现**，包括 Explore 与 Compare 主干下的结论（B3 §2.2 归属说明）。
- **规则 TS-2**：刻度随结论展开/折叠同显隐；弱证据不隐藏、不跳外链（B1 §5 / B4 §4）。
- **规则 TS-3**：异议叙述（TP-08）按 ADR-0015 D7 呈现，叙述权归用户解读。

### 2.18 下一步呈现 Next Presentation（B3 / A2 衍生）
- **规则 NP-1**：全产品唯一「下一步」出口 = TP-16，契约唯一来源 = A2 `ExplorationAction`。
- **规则 NP-2**：呈现五 actionType 的标准语汇（见 §3.1），每个携带 `rationale`（理由可读）+ `coverageBeforeAfter.delta`（缺口可见）。
- **规则 NP-3**：禁用推荐语汇；禁用个性化、打分式表达（守 X01 禁止 / B3 §4.2）。

### 2.19 镜像出口 Mirror Exit（B3 / ADR-0013 D3 衍生）
- **规则 ME-1**：Mirror（TP-22/19）= L4.5 只读投影出口；反射即终点，**无出边**。
- **规则 ME-2**：Mirror 页内不得出现任何「下一步去看 X」；用户继续须自经常驻层返回。
- **规则 ME-3**：Mirror 不作 ExplorationPolicy 输入；不评级、不打分用户本人（解读权归用户）。
- **规则 ME-4**：只反射本次会话（ADR-0015 D6，不持久化）。

### 2.20 对比直入 Compare Direct Entry（B3 / ADR-0015 D3 衍生）
- **规则 CD-1**：Compare 双入口——① 从 Understand 自发触发；② 常驻层独立入口，无前置条件，不要求先选定实体。
- **规则 CD-2**：不成对时不作空入口；呈现已知边界说明 + TP-16 补齐动作（B1 §9 F-3）。
- **规则 CD-3**：对比结论可落 TP-13 成理解结构，或转为新探索起点回 Explore；不退化下级。

## 3. 由 B3 结构衍生的关键交互契约锚点

### 3.0 ModeBar 现状模式 ↔ FRW 四主干映射（2026-08-08 PO 裁决：文档对齐，不改 ModeBar）

> 现状 ModeBar（M90.3，`components/shell/ModeBar.tsx`）提供 4 个运行时模式：
> `exploration / explanation / relationship / understanding`，是实际生效的模式切换 UI。
> FRW 四主干（Explore / Understand / Compare / Mirror）是产品架构层的提问角度定义。
> 经 PO 裁决（2026-08-08），两者**不互相替换**，以本文档作为对齐锚点：

| ModeBar 运行时模式 | 归属 FRW 主干 | 说明 |
|-------------------|--------------|------|
| `exploration`（探索） | **Explore** | 直接对应 Explore 主干的默认提问角度 |
| `explanation`（解释） | **Explore** | Explore 主干下的解释深化角度（TP-10 机制） |
| `relationship`（关系） | **Explore** | Explore 主干下的关系展开角度（TP-03/25） |
| `understanding`（理解） | **Understand** | 对应 Understand 主干（UnderstandingWorkspace 唯一独立渲染分支） |
| — | **Compare** | 不走 ModeBar：独立 CrossTopic 直入入口（TP-14，P0 独立入口，不退化下级） |
| — | **Mirror** | 不走 ModeBar：MirrorPanel 只读投影（TP-19/22，无出边） |

**对齐规则**：
1. ModeBar 的三个 Explore 系模式（exploration/explanation/relationship）语义上都是 Explore 主干的提问角度，ModeBar 保留它们作为精细切换。
2. Compare / Mirror 有各自独立入口（CrossTopic 直入 / 面板），**不强行并入 ModeBar**，避免空壳模式。
3. 未来若 ModeBar 演化，新增模式必须先映射到四主干或常驻层，不得凭空新增第五种主干（R-2 规则不变）。

### 3.1 TP-16 下一步的五 actionType 标准映射（唯一契约来源 A2）
| actionType | 用户读到的意思 | 导航去向 | 交互动作 |
|-----------|--------------|---------|---------|
| `open_dimension` | 你还没看过这个维度 | Explore（新维度锚点） | 展开新锚点 |
| `follow_cause` | 这条因果链你还缺一环 | Understand（TP-10） | 切换主干 + 载入机制 |
| `deep_continue` | 当前这条线还能再深 | 当前主干，锚点下沉 | 就地下沉展开 |
| `compare_context` | 别处同期是另一种做法 | Compare（TP-14） | 切换主干 + 载入对比台 |
| `reflect` | 你手上的东西可以收一收了 | Understand 收束 / 引向 Mirror 出场 | 收束或触发镜像时机 |

### 3.2 TP-24 / TP-27 / TP-16 三者点击语义互斥
- TP-24 定向直达：用户已知目标名词 → 确定性直达。
- TP-27 停滞接住：用户停滞、不知该做什么动作 → 确定性动作提示（禁个性化、禁打分）。
- TP-16 下一步探索：用户一段做完、不知下一段去哪 → 规则可审计方向决策。

### 3.3 真相刻度三件套贴住结论（C2 落点）
TP-06/07/08 归属 Understand，但呈现位置在任一结论处（含 Explore / Compare）。归属定义回答的问题类别，不定义出现位置。

### 3.4 主干切换交互（Rail）
- 点击 Rail 切换主干 = 换提问角度。
- 携带物：常驻层连续、轨迹链累加、覆盖态唯一、From/Why/Value 不清空。
- 不存在「切换主干 = 开始新探索」。

## 4. 禁用清单（四条红线 + 扩展禁令）

| 编号 | 禁令 | 依据 |
|------|------|------|
| X-R1 | 禁用「推荐 / 猜你喜欢 / 相关内容 / 其他用户也看了」等推荐语汇 | B3 §4.2 / A2 命名红线 / P1-01 X01 |
| X-R2 | 禁用弹跳缓动 `cubic-bezier(0.68,-0.55,0.265,1.55)` | 动画逻辑规则 AN-2；任何过渡仅缓入缓出或线性 |
| X-R3 | 禁用多套交互范式 | 四主干同构语法（B3 §3）；术语/定位/不换台三约束 |

## 5. 一致性原则（四主干同构语法下交互完全一致）

1. **语法一致**：四条主干动作序列同构（锚点→关系→理由→推进），Mirror 推进格为空是唯一刻意差异。
2. **点击一致**：同一术语（锚点/关系/理由/下一步）在四主干下点击语义相同。
3. **导航一致**：任意两主干间转移方式唯一且明确（B3 §7 矩阵）。
4. **返回一致**：返回均沿轨迹链回退，均保全常驻层。
5. **刻度一致**：真相刻度三件套在任一主干结论处同式呈现。
6. **反馈一致**：反馈只表状态不表评判；无推荐语汇。
7. **动画一致**：仅功能性过渡，禁用弹跳缓动。
8. **状态一致**：覆盖态/语言态全局单一，不按主干分裂。

> 验收硬指标：不存在「这里一种交互、那里另一种交互」。任何入口、任何能力，交互方式与学习成本一致。
