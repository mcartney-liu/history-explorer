# M71 POC 材料 ③ — Pilot 验收标准（草案框架）

> 性质：**草案框架**，正式验收标准需结合 M71 真实体验者基线 + PO 商务决策后校准。
> 表述口径：早期探索行为验证指标，非"证明商业成功"。

---

## 1. 候选 Pilot 场景（3 个，供 PO 选择）

| 场景 | 机构类型 | 主题 | 亮点 |
|---|---|---|---|
| P1 | 学校（高中/大学历史课） | 唐宋制度演化（中国包） | 关系链（科举→文官→内阁）契合课程单元 |
| P2 | 博物馆 | 罗马展陈导览（罗马包） | 时间链+制度链与展线对应 |
| P3 | 文旅 | 丝路主题线路（丝绸包） | 跨文明叙事适合线路包装 |

## 2. 候选成功指标（草案）

| 指标 | 定义 | 建议目标（待校准） |
|---|---|---|
| 探索深度 | 会话内访问实体 ≥3 | ≥40% 用户 |
| 包完成趋势 | 关系链段覆盖率 ≥60%（T2 路径） | ≥50% 参与用户 |
| Guide 使用率 | 会话中使用「下一步」 | ≥50% |
| 跨包扩展 | 会话打开 ≥2 包 | ≥30% |
| 内容可信度 | 来源链被展开（`view_source` 接入后） | 定性反馈为主 |

## 3. 试点规模与周期（草案）

- 用户数：20–50 名（1 个机构场景）
- 周期：2–4 周
- 数据：匿名 localStorage 事件流 + 结构化访谈（PO/机构组织）

## 4. 前置条件（正式启动前需满足）

1. M71 真实体验者基线（PO 组织 3–5 名，回填阈值）
2. （可选）`open_entity` 补 gid + `view_source` 接入（改 M43 文件，需 Freeze Gate）——提升指标精度
3. PO 对"机构级部署基础设施（账户/云）"是否解冻的决策（当前维持冻结）

## 5. 明确不做（本草案边界）

- 正式商务合同/付费条款（POC 阶段免费试点）
- 平台化/多租户/权限体系（维持冻结红线）
