# M71 POC 材料 ② — Institution 价值说明（一页纸）

> 面向：学校 / 博物馆 / 文旅 / 文化机构（商务沟通用）
> 定位：**探索式历史平台（当前阶段以数字博物馆形态验证）**
> 本材料为 M71 POC 就绪文档——不涉及账户/授权/云/支付系统（维持冻结红线）。

---

## 一句话价值主张

**History Explorer 让"一段历史"变成"一次可追溯的探索"——策展的叙事 + 冻结的史实图谱 + 确定性的导览，每一步都有据可查。**

## 三个核心卖点（区别于历史百科/课件）

| 卖点 | 说明 | 对机构的直接价值 |
|---|---|---|
| **可追溯** | 每条关系/主张回链 EvidenceClaim + 来源（一手/学术/参考，带 tier） | 教学可信度：学生看到的不只是结论，而是证据链 |
| **零幻觉** | 探索向导是确定性导航（基于冻结图谱 + 模板解释），无 LLM 生成事实 | 内容质量可控：机构敢把内容交给学生/观众，不怕 AI 编造 |
| **策展内容** | 官方探索包 = 策展单元（探索目标→时间链→关系链→来源→推荐） | 开箱即用：机构无需自建知识库，选包即开课/开展 |

## 分机构差异化价值

| 机构 | 契合场景 | 差异化价值 |
|---|---|---|
| **学校** | 历史课程主题包（如"唐宋制度课"） | 可溯源的探究式学习素材；教师可用关系链设计课堂路径 |
| **博物馆** | 展陈导览动线（馆藏主题 = 探索包） | 展品背后的"关系叙事"延展；观众离馆后可继续线上探索 |
| **文旅机构** | 主题线路叙事（丝路/古城） | 让"一条线路"变成"一个故事链"，提升内容附加值 |

## 当前可交付（POC 阶段）

- 3 个官方探索包（中国文明 / 丝绸之路 / 罗马帝国），零悬空可溯源
- 探索向导（当前位置 / 下一步 / 原因 / 覆盖度）
- 确定性、离线、无账户——**零部署摩擦**（本地即可演示）

## POC 合作形态（草案，不启动签约）

- 形态：指定主题的官方包定制 / 演示 + 试用反馈
- 周期：2–4 周试运行
- 机构侧投入：主题选择 + 反馈（无技术开发负担）
- 我方交付：定制包 + 演示 + 使用数据摘要（匿名）

## 边界声明

本产品当前为**本地匿名使用**（localStorage 事件缓存，无账户/云同步/用户画像）；机构级部署（账号/授权/云端）属于商业化基础设施，尚在研究阶段，不在本 POC 范围。
