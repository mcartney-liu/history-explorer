# M85.11.2 Explorer Interaction & Discoverability Audit

> 模式：Strict Read-Only。仅分析 Frontend，未修改任何代码、未修复 Bug、未提交、未输出 PR。
> 视角：第一次打开 History Explorer 的真实用户。
> 目标：回答"这个产品到底应该怎么使用？"

---

## 0. 一句话结论

**这个产品现在不是一个"开箱即可探索"的产品。**

它内部有丰富的知识（Fact Layer / Explanation Layer / Understanding Layer 三层结构），但**用户站在门口时，没有任何一条清晰的线索告诉他"我应该点这里、然后会发生什么、为什么值得继续"**。用户能够偶然进入深层页面，但几乎不可能理解"我为什么在这里、下一步该去哪"。

最大的阻碍（按影响程度排序）：

1. **入口即死胡同**：打开产品后，唯一可见的主按钮是「开始探索」。点了之后进入的不是"探索"，而是「Package 选择页」——一个由技术代号（`m77-package-01`）、编号、和"深度/覆盖"等内部指标伪装成卡片的目录。用户不知道自己选的是什么，也不知道选了之后会看到什么。
2. **叙事层缺失**：整个产品没有"为什么"。每一次跳转都只是"换一组更具体的数据"，而不是"帮你理解一个更大的问题"。用户看不到自己正在构建的理解链。
3. **认知词汇裸露**：用户直接面对 `CausalObject`、`Knowledge Graph`、`relation_type`、`Semantic Relationship`、`Exploration Package`、`Global Id` 等产品/架构术语，没有一层"人话"把它们翻译成"故事/原因/联系"。
4. **两个不可发现的抽屉**：左边"探索工作台"、右边"AI 历史学家"都默认收起，只有屏幕边缘的两个小图标。用户不会知道里面有什么，也不会知道能问 AI。
5. **理解入口藏得最深**：M85 的核心价值"文明理解种子（Understanding Seeds）"只活在 AI 历史学家聊天面板的脚注里，不主动展示。

# 第四部分：Explorer Walkthrough（第一次使用）

**第 0 步 · 打开产品**
我看到：一个深色页面，大标题"History Explorer"，副标题像宣言。一个按钮「开始探索」。
我会点吗：会，因为这是唯一的动作。
我知道之后会发生什么吗：**不知道**。按钮没说"探索什么"。

**第 1 步 · 进入 Explore 壳**
我看到：顶部有搜索框、几个 tab（探索引导/种子/包）、左右两个边缘小图标。主区是「探索引导」页：一堆卡片，标题是"先有事实，再有理解""从问题出发"等；下面一排卡片写着 `m77-package-01`、`m82-package-01`… 带"深度 4 / 覆盖 12"之类的数字。
我为什么点这里：因为"开始探索"把我带到了这里，这是唯一的内容。
我知道下一步吗：**犹豫**。这些卡片是什么？`m77` 是啥？数字代表什么？我要选一个吗？选错了会怎样？

**第 2 步 · 假设我点了某个 Package**
我看到：一列"文明：人物""文明：事件"的实体卡片，配头像和一句话。
我会点吗：会，因为这是这里唯一可点的具体东西。
我知道点了之后去哪吗：**不知道**。

**第 3 步 · 进入 Entity Page**
我看到：顶部 tab（Info / Research / Extensions）。Info 是一堆关系、时间线、解读。Research 里有一个聊天框，标题"与历史学家对话"。
我知道现在在干嘛吗：**部分**。我在"看一个东西的详情"。但我不知道这个东西和我选的 Package 有什么关系，也不知道为什么系统让我看它。

**第 4 步 · 我点了一个"相关实体"**
我看到：跳到另一个 Entity Page。
我知道为什么跳吗：**不知道**。只是"有个链接，我点了"。我又回到了第 3 步的样子。

**第 5 步 · 我尝试右边的 scholar 图标**
我看到：一个 AI 聊天面板，四种模式（历史学家/解释者/批评者/引导者），底下有一行"理解种子"。
我知道能干什么吗：**模糊**。我可能试着问一句。但没人告诉我"你可以问它帮你理解"。

**第 6 步 · 我尝试左边的 book 图标**
我看到：最近探索、旅程、工作区。
我知道这有什么用吗：**模糊**。像是后台记录，不是探索入口。

**结论**：一个真实用户能"走到"深层页面，但**每一步都是盲目的**。他不知道自己在构建什么理解，不知道为什么从 A 到了 B，也不知道什么时候"看懂了"。

# 第五部分：Dead End Audit

| Dead End | 原因 |
|----------|------|
| **Landing → 无返回** | 进入 Explore 后，没有任何 UI 能回到 Landing。用户一旦开始，无法"退出到首页"。 |
| **Extensions tab** | 点击后只显示"即将推出"。是明确的空终点。 |
| **Skill Tree 视图** | 仅展示能力/里程碑结构，**没有任何可点击进入的下一步**（纯展示树）。用户看了不知道能做什么。 |
| **Package 页无"为什么"** | 进入后只有实体列表，没有解释"这个包想让你理解什么"，用户看完列表即止。 |
| **Dev Catalog** | 技术上可达但 UI 无任何入口，且内容是开发者视角的包/种子清单，普通用户进入即迷路。 |
| **CausalObject 关系链末端** | 当 Related CausalObject 为空时，只能"← 返回"，无横向探索。 |
| **搜索无结果 / 弱引导** | 搜索框孤立存在，输入后若结果不相关，没有"换个方式"的引导。 |

# 第七部分：Loop Audit

| 循环 | 性质 | 是否有意义 |
|------|------|-----------|
| Entity → 相关实体 → Entity → … | 无限横向跳转 | **无意义**。每次只是换一个实体详情，没有叙事推进，用户会"转圈"。 |
| CausalObject → Related CausalObject → CausalObject → … | 无限横向跳转 | **无意义**。同上加剧"迷路感"。 |
| Explore ↔ Discover（tab 切换） | 来回切换 | 中性，但 Discover 本身无终点，易陷入"换入口看看"。 |
| Workspace/Companion 抽屉开关 | 叠加层 | 中性，不阻断主流程。 |

> 没有"强制死循环"，但存在**两个无终止条件的横向探索循环**，用户停不下来也不知道何时该停。

# 第八部分：Discoverability Audit（最重要）

站在第一次使用者的角度：

**第一页（Landing）**
- 我知道点哪里吗：**知道**——只有一个按钮。
- 但我知道点了之后会怎样吗：**不知道**。没有一句话告诉用户"这是一个帮你理解文明的工具，你会先选一个主题"。
- 让我犹豫的地方：副标题是宣言式文案，不解释产品能帮我做什么。

**进入 Explore 后**
- 入口名字看不懂：
  - `m77-package-01`、`m82-package-01` —— 这是开发里程碑代号，用户完全无法理解"这是什么主题"。
  - "深度 4 / 覆盖 12" —— 内部指标，对用户无意义。
  - "探索引导""种子""包" —— 三个词都不像日常语言。"种子"指什么？"包"又是什么？
- 哪些功能存在但用户不会发现：
  - **右边 AI 历史学家**：默认收起，只有一个小图标。用户不会知道可以"问 AI"。
  - **左边工作台**：同样默认收起。用户不会知道有"最近探索/旅程"可以回看。
  - **理解种子（Understanding Seeds）**：藏在 AI 聊天面板脚注，是 M85 核心价值，但完全不主动展示。
  - **HistorianChat**：在 Entity Page 的 Research tab 里，不显眼。
- 哪些地方让我不知道"下一步该干什么"：
  - Discover 页选完 Package 后，进入实体列表，然后呢？
  - Entity Page 看完 Info，没有"建议你接着看 X 来理解 Y"的引导（M85.11 禁止推荐，但**解释性引导**≠推荐，目前两者都被拿掉了，用户失去方向）。
  - Seed 页有节点，但节点之间的关系叙事不显式，用户散点点击。

**核心体验问题（不讨论代码）**
1. 产品用"架构语言"和用户对话，而非"理解语言"。
2. 用户始终在"看数据"，从未被邀请"形成理解"。
3. 两个最有价值的助手（AI、工作台）都藏在边缘，不主动。
4. 每次跳转都缺乏"你为什么来到这里"的上下文。

# 第十部分：Top 20 UX Issues（影响探索体验）

按"为什么用户会迷路 / 不知道点哪 / 停止探索 / 失去理解链"排序：

1. **Landing 不交代"之后会发生什么"** —— 用户盲点进入。
2. **Package 用里程碑代号（m77-package-01）而非主题名** —— 用户不知道选的是什么。
3. **"深度/覆盖"等内部指标直接展示给用户** —— 无意义数字增加认知负担。
4. **无"返回首页"入口** —— 开始后无法退出到起点。
5. **AI 历史学家默认收起且仅小图标** —— 核心价值不可发现。
6. **探索工作台默认收起且仅小图标** —— 回看/续探能力不可发现。
7. **理解种子（M85 核心）藏在 AI 脚注** —— 产品灵魂不主动。
8. **Entity Page 无"你为什么在这里"上下文** —— 跳转后迷失。
9. **两个无终止横向循环（实体↔实体、CausalObject↔CausalObject）** —— 转圈无进展。
