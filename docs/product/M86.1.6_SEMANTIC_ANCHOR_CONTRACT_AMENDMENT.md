## 修正 1：Anchor — entityProvenance 与 selectionProvenance 分离

**问题**：M86.1.5 中 Anchor 只有一个 provenance 字段，混淆了"对象来自哪里"和"为什么选它"。

**修正**：

```ts
Anchor {
  entityId: string
  entityType: string
  displayName: string

  entityProvenance: {          // 对象本身来自哪里（始终 Knowledge Layer）
    source: 'knowledge_layer'
    dataset?: string
    version?: string
  }

  selectionContext: {          // 为什么现在看到它
    source: 'curator_layer' | 'knowledge_layer' | 'user_search'
    reason?: string
  }

  semanticRole?: string
}
```

示例：探索包中的 Entity → entityProvenance.source = knowledge_layer, selectionContext.source = curator_layer。Related Entity 跳转 → selectionContext.source = knowledge_layer。用户搜索 → selectionContext.source = user_search。

---

## 修正 2：新增 relationChain

**问题**：M86.1.5 只有 activeRelation（当前跳转），缺少历史关系序列。Batch 3 Understanding Runtime 需要完整关系链判断因果链。

**修正**：新增 `relationChain: Relation[]`，与 anchorChain 配对：

```
anchorChain:   [A,      B,      C]
                  \     / \     /
relationChain:    [rel_AB] [rel_BC]
```

- activeRelation = 当前这一步（实时展示）
- relationChain = 已经走过的路（累积，供 Understanding Layer 和 Workspace）

---

## 修正 3：Relation 模型确认

M86.1.5 的 Relation 定义不变：`{ relationId, fromEntityId, toEntityId, relationType, provenance: { source, dataset, version }, descriptionRef }`。
