## 1. 观察目标

```
核心问题：
  这个 Understanding Journey（理解 → 关联 → 继续探索）真的让人想继续吗？

不是验证功能是否正常。
不是验证数据是否正确。
是验证：用户是否因为"理解关联"而产生下一步探索意愿。
```

## 4. 观察重点

```
不是观察：
  ❌ 用户喜不喜欢页面设计
  ❌ 用户觉不觉得好看
  ❌ 用户愿不愿意付费

是观察：
  ✅ 用户是否自然阅读 explanation
  ✅ 用户是否因为 explanation 产生点击行为
  ✅ 用户是否在进入下一个 CausalObject 后继续探索
  ✅ 用户是否表达了 "这个关联帮助我理解了" 类似的认知
```
