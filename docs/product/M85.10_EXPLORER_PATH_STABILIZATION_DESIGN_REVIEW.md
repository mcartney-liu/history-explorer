## 2. 样本量标准

### 2.1 最小样本量

| 指标 | 最低 | 目标 | 理由 |
| --- | --- | --- | --- |
| 总 Session 数 | 50 | 200 | 50 条以下无法区分随机和模式 |
| 每个 Seed 的 Session 数 | ≥15 | ≥50 | 三个入口各需足够样本 |
| 单 Session 平均 Depth | ≥2 | ≥3 | Depth=1 不是探索，是浏览 |

### 2.2 样本质量

```
有效 Session 定义：
  ✅ visitedObjects.length ≥ 2（至少形成一次跨对象探索）
  ❌ visitedObjects.length ≤ 1（单页面浏览，非探索行为）
  ❌ depth=0（未走任何探索路径）
```

## 3. Pattern 定义

### 3.1 什么算 Pattern？

```
Pattern = 在多个独立 Explorer Session 中，
          从不同 Seed 出发，
          自然汇聚到相同的 visitedObjects 序列或子序列。

不是：
  ❌ 同一个 Seed 的重复路径（那只是入口固定导致的）
  ❌ 相邻两个对象的共现（那只是 KG 关系导致的）
  ❌ 单个高频对象（那只是内容热门）
```

### 3.2 Pattern 的三个等级

| 等级 | 定义 | 示例 |
| --- | --- | --- |
| **L1 — Path Pattern** | 相同 Seed 产生相同的 visitedObjects 序列 ≥10 次 | Seed1 → [co-004, co-001, co-010] 出现 15 次 |
| **L2 — Cross-Seed Pattern** | 不同 Seed 汇聚到相同的 visitedObjects 子序列 ≥5 次 | Seed1→[co-004,co-001] + Seed2→[co-009,co-004,co-001] 共享 [co-004,co-001] |
| **L3 — Cognitive Pattern** | 不同 Seed 汇聚到相同的认知阶段序列（非具体对象，而是理解层次） | 治理问题→制度→人才→行政 作为一个抽象模式出现 |

### 3.3 Pattern 判定标准

```
L1 Pattern 成立条件：
  同一 Seed 下，完全相同的 visitedObjects 序列出现 ≥10 次
  且该序列不是 KG 直接连接的简单遍历

L2 Pattern 成立条件：
  至少 2 个不同 Seed 的路径中，
  共享 ≥2 个连续的 visitedObjects 子序列，出现 ≥5 次

L3 Pattern 成立条件：
  人工审查 L1/L2 Pattern 后，
  判断是否可以抽象为 "文明问题 → 认知阶段序列"
```

## 4. 观察指标

### 4.1 定量指标

| 指标 | 定义 | 用途 |
| --- | --- | --- |
| Total Sessions | 总有效 Session 数 | 样本量基准 |
| Avg Depth | 平均探索深度 | 探索行为质量 |
| Path Diversity | 不同 visitedObjects 序列的数量 / 总 Session 数 | 路径分散度 |
| Top Path Frequency | 最常见路径的出现次数 | L1 Pattern 候选 |
| Cross-Seed Overlap | 不同 Seed 间共享的子序列数量 | L2 Pattern 候选 |
| Seed Distribution | 各 Seed 的 Session 分布 | 入口均衡性 |

### 4.2 定性指标

| 指标 | 定义 | 用途 |
| --- | --- | --- |
| Cognitive Stage Clustering | 人工审查路径，判断是否形成认知阶段聚类 | L3 Pattern 候选 |
| Explorer Question Patterns | explorerQuestion 字段中出现的高频问题类型 | 用户认知需求 |
| Path Convergence Points | 多条路径汇聚的共同节点 | 理解网络的关键节点 |

## 6. 判定规则

### 6.1 Pattern 成立（→ M86 Pattern Layer）

```
条件：
  1. 总 Session ≥ 50
  2. 至少 1 个 L1 Pattern（同一路径 ≥10 次）
  3. 至少 1 个 L2 Pattern（跨 Seed 汇聚 ≥5 次）
  4. Path Diversity < 0.5（路径有收敛，非随机漫步）

含义：
  人类探索历史时确实存在稳定的认知模式。
  M86 进入 Pattern Layer 设计。
```

### 6.2 Pattern 部分成立（→ 继续观察）

```
条件：
  1. 总 Session ≥ 50
  2. 有 L1 Pattern 但无 L2 Pattern
  3. Path Diversity > 0.5

含义：
  同一入口内有模式，但跨入口未汇聚。
  可能 Seed 设计需要调整，或样本量不足。
```

### 6.3 Pattern 不成立（→ 重新审视方向）

```
条件：
  1. 总 Session ≥ 50
  2. 无 L1 Pattern（无任何路径出现 ≥5 次）
  3. Path Diversity > 0.8

含义：
  人类探索历史的路径高度个性化，不存在稳定的跨用户模式。
  M86 方向可能需要从 "Pattern Layer" 调整为
  "Explorer Experience Enhancement"。
```
