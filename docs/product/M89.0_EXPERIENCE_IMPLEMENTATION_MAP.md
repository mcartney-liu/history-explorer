## 一、M85 体验宪法逐条回顾与 Runtime 能力映射

---

### EO-001：用户可以从好奇进入探索

**体验要求**（M85.15）：
- 30 秒内选择一个自己真正想理解的问题
- 不是搜索框，不是技术代号

**当前前端状态**：
- `LandingPage`：Hero + Quick Start 快捷问题 + 精选主题卡片 + 主题网格
- `DiscoverPage`：Hero + 精选入口 + 按实体类型分类卡片
- 两个 Landing Page **同时渲染**（重复的 Hero，无统一的入口设计）
- 快捷问题使用硬编码数组，与 Exploration 引擎无关

**已有 Runtime 能力**：
- `HistoricalKnowledgeProjection`（法国大革命：6 维度 / 16 entities / 11 relations）
- `ExplorationState.buildExplorationState()`（纯函数，可接收 Projection 生成初始 State）

**缺失**：
- Landing Page 不读取任何 Projection 数据
- 没有"选择一个你想理解的问题"的入口——只有"搜索"和"浏览主题"
- 快捷问题是静态的，无法动态生成基于 coverage 的引导问题

**M89 需要**：
- 用 `HistoricalKnowledgeProjection.topicName` + `description` 替换静态快捷问题
- 用 `understandingTemplate.requiredDimensions` 展示"这个问题涉及哪些维度"
- 入口文案从"用 AI 探索历史文明"改为"选择一个你想真正理解的问题"

---

### EO-002：用户知道自己为什么走这条路

**体验要求**（M85.15）：
- 选定主题后，系统告诉你"你正在探索 X，涉及 A/B/C 维度，先从 Y 开始"
- 能回答"这个探索会帮我理解什么"

**当前前端状态**：
- `ExplorationPath` + `Breadcrumb` 展示已访问节点，但只显示 title/name
- 没有"为什么现在看这个"的解释
- 没有维度/覆盖状态的可视化

**已有 Runtime 能力**：
- `ExplorationState`：{ currentTopic, coveredDimensions, missingDimensions, coverageRatio }
- `ExplorationAction.reason` + `narrativeHook`
- `Decision.trace`（RuleTrace 可审计）

**缺失**：
- `ExplorationState` 的数据从未渲染到前端
- `coveredDimensions` / `missingDimensions` 没有任何 UI 表达
- Navigation 只显示"从 A 到 B"，不显示"为什么从 A 到 B"

**M89 需要**：
- Orientation Panel：显示当前主题 + 已覆盖/未覆盖维度 + coverage 进度
- 每次跳转显示 `ExplorationAction.reason`（而非裸 title）

---

### EO-003：用户每一次跳转都有理解理由（最大核心）

**体验要求**（M85.15）：
- Navigation Contract：`看到 A → 理解 A 的意义 → 发现 A 与 B 的关系 → 因为 A 所以探索 B → 理解更大的 X`
- 连续三次跳转后，用户能解释"A 为什么带我到 B"

**当前前端状态**：
- `pushHistory()` 只记录 `{ type, id/topic, title/name }`，不记录任何关系语义
- `Breadcrumb` 只显示节点名称序列
- 没有 From/Why/Value 的 Navigation Card

**已有 Runtime 能力**：
- `ExplorationAction`：{ type, targetRef, reason, narrativeHook, expectedGrowth }
- `Decision.trace`：每条 Action 都有 ruleId + inputs + decision
- `ExplorationMetrics.connectionDelta`

**缺失**：
- 导航栈不存储 `reason` 或 `narrativeHook`
- 没有任何 Navigation Card 组件

**M89 需要**：
- `NavNode` 扩展：增加 `reason`、`narrativeHook` 字段
- Navigation Card 组件：展示 From → Why → Value
- 跳转时从 `ExplorationAction` 提取语义信息

---

### EO-004：用户完成一次 Understanding Loop（产品价值证明）

**体验要求**（M85.15）：
- 经历 `事实 → 原因 → 关系 → 理解 → 新问题`
- 产生"原来如此"的闭合信号
- 用户能复述因果链，而非只能说"我看了很多资料"

**当前前端状态**：
- 没有任何 Understanding Completion 信号
- `SummarizationPanel` 等组件存在但无明确"闭环"设计
- 用户探索完一个主题后没有"你现在理解了 X"的反馈

**已有 Runtime 能力**：
- `ExplorationPolicy` 的 `reflect` Action
- `ExplorationMetrics.understandingGrowthScore`
- `ExplorationState.coverageRatio`（0 → 1.0）
- `CompanionPolicy` 的 `summarize` actionType

**缺失**：
- `reflect` Action 没有对应的前端展示
- `understandingGrowthScore` 从未渲染
- 没有"理解完成"的 UI 信号

**M89 需要**：
- Understanding Completion Panel：显示"你已覆盖 X 个维度，形成以下理解"
- 用 `ExplorationMetrics.understandingGrowthScore` 可视化成长
- `reflect` Action 触发一个总结视图

---

### EO-005：核心能力主动被发现

**体验要求**（M85.15）：
- 第一分钟发现 AI 对话伙伴
- 第三分钟发现理解种子
- 在需要回看时不超过一次操作找到工作台

**当前前端状态**：
- `HistorianChat` / `AIExplanationPanel` 存在但默认收起
- Workspace 默认收起
- 理解种子（M85 核心）藏在 AI 脚注
- M85.11.2 Audit 评分：3.2/10，第 8 条 Discoverability Audit 得分最低

**已有 Runtime 能力**：
- `CompanionPolicy` / `ExplanationRenderer` / `ExplanationArtifact`
- `ExplorationState`（理解种子）
- `MemoryProjection`（工作台数据）

**缺失**：
- 这些能力在前端仍然不可见或默认收起
- 没有主动发现的触发机制

**M89 需要**：
- Companion 入口默认可见（非收起）
- ExplorationState 可视化（理解种子）
- Workspace 一键可达

## 二、前端当前状态总评

### 核心页面

| 页面 | 当前状态 | 问题 |
|------|----------|------|
| Landing | Hero + Quick Start + 主题网格 + 最近探索 | 两个 Landing 同时渲染，快捷问题静态，无 Projection 驱动 |
| 主题探索 | 概览面板 + 时间线 + 关系图 + 15+ 面板 | 面板多但无序，无语义导航，无 ExplorationState 驱动 |
| 实体详情 | EntityPage + 10+ 子面板 | AI 面板默认收起，无"为什么看这个"的解释 |
| 因果对象 | CausalObjectDetailPage | 有因果链展示，但无 Exploration 语义 |

### 导航

| 组件 | 当前状态 | 问题 |
|------|----------|------|
| NavNode | `{ type, id/topic, title/name }` | 不存储 reason/narrativeHook/relationType |
| Breadcrumb | 节点名称序列 | 无 From→Why→Value 语义 |
| pushHistory | 去重 + 截断 | 无关系语义 |

### 关键缺失

1. **ExplorationState 从未渲染**：`coveredDimensions` / `missingDimensions` / `coverageRatio` 没有任何 UI
2. **ExplorationAction 从未渲染**：`reason` / `narrativeHook` 从未展示给用户
3. **Navigation Contract 不存在**：跳转无 From/Why/Value
4. **Understanding Completion 不存在**：无"理解完成"信号
5. **核心能力不可见**：Companion/Workspace 默认收起

## 三、M89 实施边界

### 允许 ✅

- 修改 Landing Page 入口设计
- 新增 Orientation Panel（基于 ExplorationState）
- 新增 Navigation Card（基于 ExplorationAction）
- 新增 Understanding Completion Panel（基于 ExplorationMetrics）
- 修改 Companion 入口（默认可见）
- 修改 NavNode 类型（增加 reason/narrativeHook）
- 前端读取 ExplorationState / ExplorationAction / ExplorationMetrics 数据

### 禁止 ❌

- 新 Runtime Kernel 能力
- 新 AI 模型 / LLM 集成
- 新 Policy 规则
- 新知识图谱数据
- 大规模数据建设
- 新推荐算法
