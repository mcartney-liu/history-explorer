# M81a — Moderator Script（主持人口径）

> 本文档**只给主持者（Moderator）用**。严格按口径宣读，不得引导探索方向、不得评价内容、不得提示功能名。
> 对应 `M81a_EXPLORATION_PROTOTYPE_EXECUTION_GUIDE.md` 第3节 User Task Script。
>
> **场景基线（v2，2026-08-03）**：Scenario A 已由「秦→汉」替换为「制度承袭演化」。依据 PO 决策与 `M81a_VALIDATION_READINESS_SUMMARY.md`。

## 开场前轻量确认（Explorer 到场前 10 秒，非强制重启）

> 环境默认常驻（后端 `:8000` + 前端 `:5173` 一直开着，不逐场重启）。本步仅作"开场前瞥一眼"，不要求完整自检。

- [ ] 浏览器打开 `http://localhost:5173/`，**确认首页主题列表有内容**
  - 有内容 → 直接开场
  - 空白/加载失败 → 后端可能挂了，按 `M81a_VALIDATION_SESSION_PLAN.md` 环境 SOP 重启后再开
- [ ] 浏览器恢复到首页初始状态，清空上一场遗留的探索足迹

> 仅当首页异常时才触发重启；正常运行状态下跳过所有启动步骤。

## 开场（照读）

"欢迎参与这次体验。接下来大约 15 到 20 分钟，请你像平时了解一段历史那样去了解它。没有标准答案，也没有正确路径。你在探索中想到的任何问题，都可以随时记下来。**过程中你可以把自己看到的、想到的、觉得奇怪的地方，随时念出来讲给我们听——想到什么就说什么，不用组织语言。** 我们会在旁边安静观察，过程中不打扰你。结束后我们聊几句你刚才的过程。"

## 已知情况说明（照读，紧接开场，不得展开解释）

"有几件事先告诉你：这是一个还在打磨中的早期版本。你这次的探索过程不会被保存下来，所以不用考虑要不要存。里面的内容有中文也有英文，这是目前的状态，不是出错。另外有些文字读起来可能比较生硬，如果你觉得别扭，请直接说出来。"

> 只读这一段，**不解释为什么**、不举例、不演示。Explorer 若追问细节 → "就是目前的状态，你按自己的感觉来就好。"

## 发布任务 A（照读，不演示）

"请探索：一项制度是怎样一代代传下来、又慢慢变样的？你在探索过程中想到的任何问题，都可以随时记下来。"

## 发布任务 B（照读，不演示；按需轮换）

"请探索：某个思想或技术是如何在不同文明之间流动的？你发现了什么关联，都可以继续看下去。"

## 过程中允许说的话

- Explorer 问"怎么用？" → "就像平时了解一段历史那样去了解它。"
- Explorer 卡住沉默 → 等待，不打断；超过明显长停顿可说"按你自己的节奏来"。
- Explorer 问"我做得对吗？" → "没有对错，按你的想法走就好。"
- Explorer 边点边说时 → **不打断、不接话、不评价**，让其自然流出（录音采集路径+停顿+原话的关键来源）
- Explorer 全程沉默只点 → 不强迫说话；其探索路径与停顿将依赖结束后访谈补全

## 严格禁止说的话（任一提及即违规）

- ❌ "点击这里"
- ❌ "查看关系 / 查看来源"
- ❌ "使用某功能 / 用筛选 / 用比较"
- ❌ "看罗马节点 / 看那个对照"
- ❌ "保存到 Trail / 收藏一下"
- ❌ 任何暗示预期路径或正确答案的表述
- ❌ 提示具体朝代或主题名（如"看看科举""从唐朝开始""丝绸之路那个"）
- ❌ 对生硬文案的辩解或翻译（如"这里 outgoing 的意思是……"）——Explorer 的困惑本身就是数据，**不得解释掉**

## 关于已知问题的应答口径（Explorer 主动提及时）

| Explorer 说 | Moderator 回 | 禁止 |
|---|---|---|
| "这个记录会保存吗？" | "这次不会保存。" | 不解释 Trail 概念、不承诺未来 |
| "怎么是英文？" | "目前就是中英都有的状态。" | 不道歉、不解释数据来源 |
| "这句话什么意思？"（指关系解释文案） | "你觉得它像在说什么？" | **不得代为翻译或解释** |
| "是不是坏了？" | "没有坏，就是目前的样子。" | 不排查、不演示 |

> 以上四类均记入 Observer Worksheet 第六节，属**有效验证信号**，不是事故。
