## 一、定位

HistoricalKnowledgeProjection 是真实历史知识进入 Exploration Cognitive Loop 的入口。

```
Historical Knowledge (Dataset)
    ↓
HistoricalKnowledgeProjection
    ↓
ExplorationState (via buildExplorationState)
    ↓
ExplorationPolicy
```

不是数据清洗。是：**将历史知识转换为可被探索智能理解的认知结构。**

## 二、HistoricalKnowledgeProjection 类型

```typescript
HistoricalKnowledgeProjection {
  topicRef: string
  topicName: string
  description: string

  dimensions: {
    id: string
    label: string
    description: string
  }[]

  entities: {
    ref: string              // entityId
    name: string
    type: string              // "person" | "event" | "institution" | "concept" | "place"
    dimensions: string[]      // 属于哪些维度
    description: string
  }[]

  relations: {
    id: string
    from: string              // entityId
    to: string                // entityId
    type: string              // "causes" | "enables" | "influences" | "precedes" | "contrasts"
    description: string
  }[]

  understandingTemplate: {
    requiredDimensions: string[]
    expectedRelations: { from: string; to: string; type: string }[]
  }
}
```
