# M86.1.2 — Explorer Runtime Context Governance
### Strict Read-Only / Governance Rules（非实现）

> 模式声明：严格只读。冻结 Explorer Runtime Context 的治理规则——谁拥有最终解释权、哪些事件允许改变 Context、认知阶段转换规则、探索边界判定、记忆交接协议。不写代码、不设计组件。这是 M86.1 进入开发前的最后一道治理护栏。

---

## 第一部分：EP-008（冻结）

> **Explorer Runtime Context is the only authority of user's current understanding state.**
>
> **Explorer Runtime Context 是系统判断用户当前理解状态的唯一权威。**

当需要判断"用户当前正在理解什么"时，唯一答案来源是 Context——不是 ExplorerPath、不是当前 Entity、不是 AI 对话历史、不是 URL。

**EP-006 + EP-007 + EP-008 的三条防线**：

| 原则 | 内容 | 防线层级 |
|---|---|---|
| EP-006 | Context 是唯一语义来源 | 防止多数据源 |
| EP-007 | Context 是关系性的，不是事实性的 | 防止存知识副本 |
| EP-008 | Context 是理解状态的唯一权威 | 防止其他层自行推断 |

三条共同构成 **Single Semantic Reality**。

---

## 第二部分：Mutation Rules（哪些事件允许改变 Context）

### 允许改变 Context 的事件
| 事件 | 触发者 | 改变的字段 | 条件 |
|---|---|---|---|
| Exploration 创建 | Curiosity Entry Layer | 全字段初始化 | 用户明确选择探索方向 |
| 理解锚点移动 | Navigation Context Layer | current_focus, previous_focus, relation_reason | 同 Exploration 内，新对象与理解线存在可解释关系 |
| 认知阶段变化 | Understanding Layer | cognitive_stage | 基于理解结构变化，非基于页面跳转 |
| 理解闭环达成 | Understanding Layer | cognitive_stage → UNDERSTANDING, unresolved_gap | 至少连接两个节点并形成因果链 |
| 新问题孵化 | Question Transition Layer | 创建新 Context，旧 Context 完成 | 用户主动选择 |
| 探索暂停/完成 | ExplorePage | Context → COMPLETED | 用户主动操作 |

### 禁止改变 Context 的行为
- ❌ 路由变化自动触发 Context 更新（路由变化 ≠ 理解推进）
- ❌ AI 对话触发 Context 更新（AI 是消费者，非写入者）
- ❌ Workspace 操作触发 Context 更新（只读消费者）
- ❌ 任何 Experience Layer 绕过宿主直接 mutate
- ❌ 定时器/自动推进 cognitive_stage

## 第三部分：Stage Transition Rules（认知阶段转换规则）

### 核心原则（修正 M86.1.1）

> **cognitive_stage 不由 Navigation Layer 更新——由 Understanding Layer 基于理解结构的变化判定。**

Navigation 知道"用户去了哪里"，Understanding 判断"用户理解到了哪里"。

### 阶段转换规则
| 当前阶段 | 可转换到 | 触发条件 | 判定者 |
|---|---|---|---|
| FACT | EXPLANATION | 获取了因果解释 | Understanding Layer |
| FACT | CONNECTION | 跳转到有语义关系的对象 | Understanding Layer |
| FACT | FACT | 回到事实确认 | Understanding Layer |
| EXPLANATION | CONNECTION | 跳转到有语义关系的对象 | Understanding Layer |
| EXPLANATION | FACT | 回到事实确认 | Understanding Layer |
| CONNECTION | UNDERSTANDING | 至少连接两个节点形成因果链 | Understanding Layer |
| CONNECTION | FACT | 回到事实确认 | Understanding Layer |
| UNDERSTANDING | NEW_QUESTION | 看到闭环并表达新好奇 | Question Transition Layer |
| UNDERSTANDING | FACT | 从闭环回到探索 | Understanding Layer |
| NEW_QUESTION | FACT（新 Exploration） | 选择继续新问题 | Curiosity Entry Layer |

### 不可自动推进
- FACT → EXPLANATION 不可自动（需获取解释数据）
- CONNECTION → UNDERSTANDING 不可自动（需形成因果链）
- 任何阶段 → NEW_QUESTION 不可自动（需用户表达新好奇）

## 第四部分：Context Authority（谁拥有最终解释权）

```
ExplorePage（Context 宿主）—— 持有唯一实例，暴露有限更新方法
  │
  ├── Understanding Layer —— cognitive_stage 和 unresolved_gap 的权威判定者
  ├── Navigation Context Layer —— current_focus / previous_focus / relation_reason 的权威记录者
  ├── Question Transition Layer —— 新 Context 创建的权威触发者
  └── 其余 Layer —— 只读消费者（Orientation / AI Companion / Seeds / Workspace）
```

### 冲突解决
- cognitive_stage 分歧 → 以 Understanding Layer 为准
- current_focus 分歧 → 以 Navigation Context Layer 为准
- unresolved_gap 分歧 → 以 Understanding Layer 为准
- Context 是否完成 → 以 ExplorePage 为准
- 未覆盖冲突 → 回到 EP-008（Context 本身是唯一权威）

---

## 第五部分：Exploration Boundary（一次探索什么时候结束）

### 结束的合法条件
- 用户显式退出探索 → Context → COMPLETED
- 用户完成 UNDERSTANDING 后不继续 NEW_QUESTION → Context → COMPLETED
- 用户选择 NEW_QUESTION 并继续 → 旧 Context COMPLETED，新 Context 创建
- 用户关闭页面/离开 → Context → COMPLETED（内存态）

### 结束 ≠ 删除
Context 进入 COMPLETED 后数据保留（供 Workspace 读取为 Understanding Memory），不再活跃。

### 未完成的探索
如果 cognitive_stage 未达 UNDERSTANDING 就结束 → Workspace 展示为"未完成的理解"（可续接，M87+）。

---

## 第六部分：Memory Handoff（Context → Workspace 交接协议）

Context 进入 COMPLETED 时，Workspace 获得完整快照：exploration_id / user_question / understanding_goal / 完整 previous_focus → current_focus 链 / 每步 relation_reason / 最终 cognitive_stage / unresolved_gap / 完成状态。

Workspace 展示语义：ACTIVE + 未达 UNDERSTANDING → "正在探索中"；COMPLETED + 达 UNDERSTANDING → "已理解"；COMPLETED + 未达 → "未完成（可续接）"。

---

## 第七部分：治理违规检测信号

- 两个 Layer 对 cognitive_stage 产生分歧
- cognitive_stage 在无用户操作时自动变化
- AI 回答与 Context 中 current_focus 无关
- Workspace 轨迹与 Context 的 previous_focus 链不一致
- 新 Exploration 创建时旧 Context 未标记 COMPLETED
- 任何 Layer 创建了独立 Context 副本
