## 四、附加约束检查：失败信号分布

| 失败信号 | 出现人数 | 触发 ≥2 人？ |
| --- | --- | --- |
| 不知下一步点什么 | 4 人（全踩） | ⚠️ 是 |
| 只浏览节点列表 | 1 人（E1） | 否 |
| 理解成百科 | 2 人（E1 强，E2 弱） | ⚠️ 是 |
| 无探索欲望 | 1 人（E1） | 否 |
| 要求"保存收藏"才肯离开 | 0 人 | 否 |

**附加约束判定**："不知下一步点什么"和"理解成百科"各达 2 人。按 §7 规则，任一失败信号 ≥ 2 人 → NEED REVISION。

**但**：需区分"失败信号"与"原型未完成导致的现象"。
- "不知下一步点什么"：四场全踩，但三场 Explorer 仍能通过推荐/向导找到下一步——这说明不是"完全没有探索欲望"，而是"导航指引不够清晰"。属于 M82 Causal Semantics + M83 Trail 应解决的问题，非致命。
- "理解成百科"：E1 强（"百科更方便全面"）、E2 弱（"有一点像百科，占比大一点"）。E5/E3 明确区分了"和百科不一样"。

**PO 判断**：两项信号与原型工程完成度强相关（导航、内容质感、AI Role 缺失），非 Exploration Experience 定义本身不成立。不因此逆转 Gate PASS。

## 六、M80.5 修订建议

基于四场验证，建议 M80.5 以下节修订：

| 节 | 修订方向 | 依据 |
| --- | --- | --- |
| **First 5 Minutes** | 入口需显式化——当前"首页浏览→选主题→进探索包"链路中，入口与搜索的边界模糊。建议增加 Landing 引导（非教程，是方向提示） | 四场全踩 |
| **Loop §Interpreter** | AI 角色当前缺位——Explorer 期待"向 AI 提问"但无回应，或回应生硬。M82 因果语义落地前，Interpreter 至少应有兜底话术 | E1/E2/E5 共证 |
| **Loop §Guide** | 向导"下一步原因"已本地化（M81b-A），但 Explorer 仍反馈"每一步到下一步让我不是很明白"。Guide 需从"推荐"升级为"叙事引导" | E3/E5 |
| **Object Model** | Signal/CausalStatement 语义未建立——Explorer 将评分/权重读成"后台参数"，关联解读为"不知道为什么做关联"。需在 UI 层区分"这是事实"和"这是系统推断" | E5 强 / E3 强 |
| **Shell** | Trail 感知已成立（3/4 Explorer 愿意回访），但 Shell 的"探索状态"感不完整——面包屑/路径缺失、状态丢失、包内定位不明确。M83 Trail Landing 需解决 | E2/E3/E5 |

> 以上为 Revision Recommendation，不纳入本 Gate 裁定。正式修订建议在 M83 启动前完成 M80.5 修订。
