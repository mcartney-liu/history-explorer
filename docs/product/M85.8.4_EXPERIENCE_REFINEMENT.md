### 2.2 CausalObject 页面体验规范

基于 M85.8.3 三场观察，固化以下体验规范：

| 规范 | 内容 | 来源 |
| --- | --- | --- |
| **三幕叙事弧不可破坏** | Act 1（理解）→ Act 2（关联）→ Act 3（探索）顺序固定 | 3/3 按此顺序自然浏览 |
| **explanation 不可省略** | 每个 related_causal_objects 条目必须包含 explanation | P3："没有解释就不会点" |
| **relation_type 标签必须可见** | 每个关系卡片顶部显示彩色标签 | 3/3 通过标签理解关系性质 |
| **CTA 使用 "探索" 非 "推荐"** | 按钮文案："探索 %{name}"，非 "了解更多" / "推荐阅读" | M85 C2 |
| **理解关联区块有独立视觉身份** | 金色分割线 + 独立 section heading | 3/3 在 Act 2 区域停留 |

### 2.3 探索深度验证

当前最大深度：3 步（P2：罗马法 → 秦制 → 科举）。

下一步验证问题：

```
Q1: 用户是否愿意在 5-10 分钟内持续探索？
Q2: 3 步是否是自然上限？
Q3: 是否需要 "breadcrumb trail" 帮助用户回溯？
```

**不做**：在验证前添加 "继续推荐" / "自动下一步" 等机制。
