# M86.1.13 — Projection Evaluation Pipeline Contract
### Strict Read-Only / Pipeline Architecture Freeze

> 模式声明：严格只读。将判定逻辑从 Runtime 抽离为独立 Pipeline。不写代码。

---

## Pipeline 架构

```
ContextSnapshot + Template
    → Projection Builder (Runtime, 纯事实) → RawProjection
    → Coverage Policy → CoverageResult
    → Stage Policy → UnderstandingStage
    → MissingLink Policy → MissingLink[]
    → UnderstandingProjection
```

---

## 各层定义

**Projection Builder**：anchorChain→knownObjects, relationChain→discoveredRelations, dimensionMapping→coveredDimensions。不做判定。

**Coverage Policy**：{ policyId, version, evaluate(raw, template) → { coverageRatio, threshold, passed } }

**Stage Policy**：{ policyId, version, evaluate(raw, coverage) → UnderstandingStage }

**MissingLink Policy**：{ policyId, version, evaluate(raw, template, stage) → MissingLink[] }。当前仅 Structural Missing。

---

## Policy 可替换性

```
ProjectionPolicy { coverage, stage, missingLink }
evaluateProjection(raw, template, policy) → UnderstandingProjection
```
