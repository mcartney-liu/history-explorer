# M89.2.7 — Understanding Path Contract
### Product Unit Freeze / Understanding Evolution Path

> 模式：冻结认知演化路径。Workspace 展示的不是 Evidence 列表，而是一条 Understanding Path。

---

## 一、定位

**单个 Evidence 成立 ≠ Exploration 成立。** Exploration 的价值不在于"有多少 Evidence"，而在于"Evidence 如何连成一条改变用户理解结构的路径"。

```
错误：Evidence A → Evidence B → Evidence C（内容浏览）
正确：Evidence A → 连接 A→B → Evidence B → 连接 B→C → Evidence C（理解演化）
```

---

## 二、Understanding Path 定义

> **Understanding Path 是从 Starting Belief 出发，经过一系列认知转化，最终形成新理解结构的完整路径。**

```
Starting Belief（用户开始时怎么理解）
    ↓
Evidence 1 → 改变理解 A
    ↓
Connection 1→2 → 发现关系
    ↓
Evidence 2 → 改变理解 B
    ↓
Connection 2→3 → 发现更深关系
    ↓
Evidence 3 → 形成因果结构
    ↓
Reflection → "原来如此"
    ↓
New Question → "那接下来呢？"
```

---

## 三、Understanding Path 结构

```typescript
UnderstandingPath {
  explorationQuestion: string       // 大问题

  // ── 起点 ──
  startingBelief: string            // 用户初始可能的理解

  // ── 转化节点 ──
  nodes: UnderstandingNode[]

  // ── 连接 ──
  connections: PathConnection[]

  // ── 终点 ──
  completionModel: CompletionModel
  nextQuestion: string
}

UnderstandingNode {
  evidenceId: string
  beforeBelief: string              // 进入这个节点前用户的理解
  afterBelief: string               // 离开这个节点后用户的理解
  dimensionAdded: string            // 新覆盖的维度
  keyInsight: string                // 这个节点最关键的认知收获
}

PathConnection {
  fromNodeIndex: number
  toNodeIndex: number
  connectionType: 'causal' | 'structural' | 'comparative'
  insight: string                   // "因为 X，所以现在理解 Y"
}

CompletionModel {
  summary: string                   // 因果链总结
  coveredDimensions: string[]
  keyCausalChain: string[]          // 关键因果链（如 ["财政→政治", "政治→社会"]）
}
```

## 四、法国大革命 Understanding Path

```
Question: 法国大革命为什么发生？

Starting Belief: "革命就是人民不满意国王，把他推翻了。"

Node ① — 财政危机
  before: "国王没钱"
  after:  "旧制度的财政体系无法维持国家运转——不是国王个人问题，是制度问题"
  keyInsight: 革命首先是制度危机，不是个人问题

Connection ①→②: 财政危机 → 政治制度
  "因为财政危机，国王不得不召开三级会议，这暴露了政治制度的结构性矛盾"

Node ② — 三级会议
  before: "国王开会解决问题"
  after:  "三级会议的投票制度让第三等级意识到——旧制度不会自我改革"
  keyInsight: 制度僵化是革命的直接原因

Connection ②→③: 政治制度 → 社会结构
  "政治制度的不公反映了更深层的社会结构问题——特权 vs 平民"

Node ③ — 第三等级
  before: "人民反抗国王"
  after:  "97%的人承担全部税负却没有政治权力——这不是反抗，是结构性的不平等"
  keyInsight: 社会结构的不平等是革命的群众基础

Connection ③→④: 社会结构 → 思想
  "社会不平等为什么变得不可接受？因为启蒙思想提供了新的标准"

Node ④ — 人权宣言
  before: "革命是暴力"
  after:  "革命有思想基础——自由、平等、人权的理念为革命提供了合法性"
  keyInsight: 思想为革命提供了"为什么应该改变"的理由

Connection ④→⑤: 思想 → 军事
  "革命的思想威胁了欧洲君主国，引发外部干预"

Node ⑤ — 革命战争
  before: "法国国内的事"
  after:  "革命不是法国一国的事——欧洲列强的干预反过来加速了革命的激进化"
  keyInsight: 外部压力改变了革命的走向

Connection ⑤→⑥: 军事 → 外交/人物
  "战争产生了新的军事领袖，也改变了欧洲的政治格局"

Node ⑥ — 拿破仑崛起
  before: "革命结束了"
  after:  "革命产生的新制度、新军队、新社会结构为拿破仑的崛起提供了条件"
  keyInsight: 革命的遗产不只是推翻国王，还包括新的社会秩序

Reflection:
  "法国大革命不是突然爆发的。财政危机 → 制度无法改革 → 社会结构不平等 → 启蒙思想提供合法性 → 外部战争加速激进化 → 产生新秩序。"

Next Question:
  "为什么革命最终走向拿破仑而不是共和国？"
```

## 五、这对 Workspace 意味着什么

Workspace 不是展示 6 个 Evidence 的列表。Workspace 展示的是这条 Understanding Path 的**当前状态**。

```
错误：
  [Evidence 1] [Evidence 2] [Evidence 3] ...（内容列表）

正确：
  你的理解正在形成：

  财政危机
      ↓（因为制度无法自我改革）
  政治制度
      ↓（因为特权结构不公）
  社会结构
      ↓（因为启蒙思想提供了标准）
  思想
      ↓（因为外部干预加速变化）
  军事
      ↓（因为新秩序产生新领袖）
  拿破仑

  当前：第 3 步 / 共 6 步
  已理解：财政、政治、社会
  还缺：思想、军事、外交
```

Path 是产品对象。Evidence 是 Path 上的节点。用户看到的是 Path，不是 Evidence 列表。

## 六、验收标准

- [ ] Understanding Path 包含 Starting Belief + Nodes + Connections + Completion
- [ ] 每个 Node 有 beforeBelief → afterBelief 的认知转化
- [ ] 每个 Connection 解释了为什么从 A 到 B
- [ ] 法国大革命 Path 形成完整因果链
- [ ] Path 可以映射到 Workspace 的视觉表达
