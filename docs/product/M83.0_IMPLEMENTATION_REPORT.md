## 4. Data Pipeline Status

### Before (M82 baseline)

```
explore()
  ↓
_explain_path(steps) → tuple[str, list[dict]]
  ↓
str → ExploredNode.explanation
list[dict] → ❌ 丢弃
  ↓
API response: {..., "explanation": "..."}
```

### After (M83.0)

```
explore()
  ↓
explanation, cs_list = _explain_path(steps)
  ↓
str → ExploredNode.explanation
list[dict] → ExploredNode.causal_statements
  ↓
API response: {..., "explanation": "...", "causal_statements": [...]}  ← 非空时
```
