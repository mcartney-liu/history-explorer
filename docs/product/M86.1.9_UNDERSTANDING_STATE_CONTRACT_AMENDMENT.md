## 修正 1：KnownFact → KnownObject

KnownFact 语义不准确——"罗马军团"不是 Fact。改为 KnownObject = { anchorRef }。移除 entityType（Anchor 已有）、firstSeenAt/revisitCount（行为指标）。

## 修正 2：移除行为指标

firstSeenAt 和 revisitCount 本质是行为指标。从 Understanding State 完全移除。行为 ≠ 理解。

## 修正 3：MissingLink 去文本化

MissingLink.reason: string → templateRef: string。展示文本由 Experience Layer 从 Curator Template 查询。Context 保存引用，不保存解释。

## 修正 4：UnderstandingTemplate 正式化

understandingGoal: string → UnderstandingTemplate { templateId, requiredDimensions[], expectedRelations[] }。Context.understandingGoal 升级为 understandingGoalRef。

## Understanding State v2

```
UnderstandingState {
  topicRef, knownObjects[], discoveredRelations[],
```
