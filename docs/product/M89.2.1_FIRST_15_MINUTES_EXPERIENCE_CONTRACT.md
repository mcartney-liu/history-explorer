# M89.2.1 — First 15 Minutes Experience Contract
### Strict Read-Only / Experience Baseline Freeze

> 模式声明：严格只读。冻结用户第一次使用 History Explorer 前 15 分钟的体验契约。不讨论 UI、页面、组件、代码。

---

## 一、为什么需要这一层

M85 定义了产品宪法（5 条 EO，8 条 Principle），但从未定义"第一次使用时具体发生什么"。

M89.2.1 是 M85 宪法和 M89.2.2 原型之间的翻译层。它回答：

> **用户第一次进入，15 分钟后，脑子里应该发生什么变化？**

---

## 二、进入前：用户脑子里有什么

### 典型初始状态

```
"法国大革命是不是因为人民太穷？"
"法国大革命和拿破仑有什么关系？"
"为什么国王会被砍头？"
```

特点：**有模糊好奇，但理解是单因单果的**。

### 系统初始状态

```
ExplorationState {
  topic: "法国大革命为什么发生？"
  coveredDimensions: []
  missingDimensions: [财政, 政治, 社会, 思想, 军事, 外交]
  coverageRatio: 0
}
```

---

## 三、离开后：用户脑子里应该发生什么变化

### 理解结构变化

```
之前（单因单果）：
  革命 = 人民推翻国王

之后（因果链）：
  财政危机
      ↓
  政治制度僵化（三级会议 → 国民议会）
      ↓
  社会结构冲突（第三等级 vs 特权阶级）
      ↓
  启蒙思想传播（人权宣言）
      ↓
  革命爆发（巴士底狱 → 共和国）
      ↓
  欧洲战争 → 拿破仑崛起
```

### 关键变化

| 维度 | 之前 | 之后 |
|------|------|------|
| 因果理解 | 单因单果 | 多因多果链 |
| 维度覆盖 | 0 | ≥3 |
| 时间跨度 | 只看爆发那一刻 | 看到前因后果的演化 |
| 问题质量 | "发生了什么" | "为什么这样演变" |

## 四、四个 Moment（非四个页面）

### Moment 1："原来不是让我搜资料"

**发生时机**：进入后 30 秒内

**用户心理**：
- 之前：打开产品，预期看到搜索框或目录
- 现在：看到"法国大革命为什么发生？"——这是一个问题，不是一个主题名
- 变化：意识到"这个产品不是让我查资料，是帮我理解一个问题"

**Runtime 支撑**：`HistoricalKnowledgeProjection` → 问题入口（非主题列表）

**失败信号**：用户说"这是什么？""我该搜什么？"

---

### Moment 2："原来我知道下一步为什么"

**发生时机**：第一次跳转时（约第 2-3 分钟）

**用户心理**：
- 之前：看完财政危机，不知道接下来看什么
- 现在：系统说"因为你刚理解财政危机，而政治制度缺口还没补齐，所以下一步看三级会议"
- 变化：从被动点击到主动理解跳转理由

**Runtime 支撑**：`ExplorationAction.reason` + `narrativeHook` + `RuleTrace`

**失败信号**：用户说"我怎么到这了""为什么给我看这个"

---

### Moment 3："原来这些事情有关联"

**发生时机**：第 2-3 次跳转后（约第 8-10 分钟）

**用户心理**：
- 之前：看到了几个孤立事件（财政危机、三级会议、巴士底狱）
- 现在：意识到它们是一条因果链——财政危机 → 三级会议 → 政治冲突 → 革命爆发
- 变化：从"知道了几个事"到"看懂了它们为什么连在一起"

**Runtime 支撑**：`ExplorationState` 的 `coveredDimensions` 增长 + `discoveredRelations` + `connectionDelta`

**失败信号**：用户只能逐个描述事件，无法说出它们之间的关系

---

### Moment 4："原来我还想继续"

**发生时机**：15 分钟结束时

**用户心理**：
- 之前：觉得"看完了"或者"看累了"
- 现在：自然产生新问题——"那革命之后为什么走向拿破仑？"
- 变化：从"完成了一个任务"到"产生了新的好奇"

**Runtime 支撑**：`UnderstandingClosure` + `ExplorationMetrics.understandingGrowthScore` + 新问题入口

**失败信号**：用户说"我看完了"但没有新问题；或说"我看了很多资料"但无法复述因果链

---

## 五、失败判定（继承 M85，具体化）

### 15 分钟后，以下任一语言 = 失败

| 用户说的话 | 违反的 EO | 含义 |
|-----------|----------|------|
| "这是什么？我该搜什么？" | EO-001 | Curiosity 入口失败 |
| "我怎么到这了？" | EO-003 | Navigation Contract 失败 |
| "为什么给我看这个？" | EO-002, EO-003 | Orientation / Navigation 失败 |
| "我看了很多资料" | EO-004 | Understanding Loop 失败 |
| "我不知道还能问 AI" | EO-005 | Core Value 不可见 |

### 成功信号

| 用户说的话 |
|-----------|
| "原来法国革命不是突然发生的" |
| "我现在知道财政危机怎么一步步变成政治危机了" |
| "那革命之后为什么走向拿破仑？" |
