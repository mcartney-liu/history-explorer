## 一、BEDAE 定位：Runtime Cognitive Pattern（非 Universal Pattern）

```
Application Architecture
  ├── Runtime Pattern (BEDAE)   ← 认知评估（Understanding/Memory/Companion/Personalization）
  ├── Data Pipeline Pattern      ← ETL/Import/Export
  ├── Repository Pattern         ← 数据存储
  └── Workflow Pattern           ← 编排/调度
```

## 二、Evaluator 与 Decision 分离

Evaluator(算法) → EvaluationResult → DecisionBuilder → Decision<T>。

## 三、Assembler → Projection Factory

Decision Package → ProjectionFactory → UnderstandingProjection | MemoryProjection | ReplayProjection | AuditProjection。

## 四、统一 Decision Policy

DecisionPolicy → ProjectionPolicy | MemoryPolicy | CompanionPolicy | RecommendationPolicy。

## 五、BEDAEP 完整链路

Builder → Evaluator → Decision → Assembler(Factory) → Explainability → Persistence。

Persistence 永远在最后——消费 Projection，不参与计算。

## 六、Evaluation Engine 定位

> M86.1 的真正产物是 Evaluation Runtime Framework。Understanding 是第一个应用实例。

后续应用：Memory(M86.2) / AI Companion(M87) / Personalization(M87+) / Recommendation(M87+)。全部遵循 BEDAEP。
