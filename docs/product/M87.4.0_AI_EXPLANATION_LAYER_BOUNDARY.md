# M87.4.0 — AI Explanation Layer Boundary Contract
### Strict Read-Only / Explanation Boundary Freeze

> 模式声明：严格只读。冻结 AI Explanation Layer 边界。不写代码。

---

## 一、Explanation 属于 Experience Layer（非 Runtime）

Runtime 负责判断。Explanation 将 Decision 转为人类语言。

## 二、LLM 输入 = Decision Package

Decision.output（结构化数据），非原始对话。

## 三、LLM 输出不可改变 Decision

Decision 保持不可变。LLM 只生成表达。

## 四、Explanation Replay

Replay 对象 = Decision（不变）。同一 Decision + 不同 Renderer → 不同表达。

## 五、AI 版本管理

Decision 版本（policyVersion）与 Explanation Artifact（rendererVersion/modelProvider/modelVersion/promptVersion）分离。

## 六、Explanation 不进入 Runtime

Explanation 是 Runtime Consumer。
