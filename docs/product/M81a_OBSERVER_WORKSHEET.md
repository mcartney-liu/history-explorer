## 一、First 5 Minutes（信号达成）
- [ ] 知道自己探索什么（North Star 锚点）
- [ ] 理解一个变化（信号1）
- [ ] 发现跨文明关联（信号2）
- [ ] 产生未知方向（信号3）

## 二、Exploration Loop（八步自然发生）
- [ ] 进入主题
- [ ] 获得上下文（理解）
- [ ] 发现关联 / 异常
- [ ] 提出问题
- [ ] 探索下一节点
- [ ] 形成个人路径（Trail）
- [ ] 留存（留下未完成问题）
- [ ] 回访意愿

## 三、Object Model（语义理解 vs 退化）
理解为：
- [ ] Entity → 主角（非"节点"）
- [ ] Relationship → 作用力（非"边/RELATION_TYPE"）
- [ ] Signal → 线索（非"相似度分数"）
- [ ] CausalStatement → 故事（非"三元组"）

退化信号（出现即勾）：
- [ ] 节点浏览（只点列表不进叙事）
- [ ] 数据查询（当检索工具）
- [ ] 百科阅读（当静态目录）

## 四、Exploration Shell（Trail 性质）
- [ ] Trail ≠ 收藏（未要求"保存"才离开）
- [ ] Trail ≠ 历史记录（回任一点恢复上下文）
- [ ] Trail = 探索状态（感知"活着的探索"）
