# M86.1 — Final ADR Amendment
### Strict Read-Only / Engine Boundary Freeze

> 模式声明：严格只读。四条架构原则修正。不写代码。M86.1 最终收口。

---

## 修正 1：BEDAEP ≠ Evaluation Engine

Evaluation Engine 包含 Runtime Contract / Evaluation Model / Version Model / Explainability Model。BEDAEP 是默认 Pipeline，非唯一实现。

## 修正 2：DecisionPolicy = Protocol

DecisionPolicy 是协议（定义生命周期/输入输出/版本/Explainability/Replay），非 God Object。真正 Policy 永远小而独立。

## 修正 3：Factory 与 Assembler 分离

Factory 选择 Assembler，Assembler 负责组装。符合 Open/Closed。

## 修正 4：Engine 不拥有 Domain

> **Evaluation Engine is domain-agnostic. It evaluates structures, not historical knowledge. Domain semantics belong to modules, never to the engine itself.**

---

## M86.1 最终定位

> History Explorer 从 M86.1 开始，拥有了一套领域无关、可解释、可重放、可版本化、可审计的 Evaluation Runtime Framework。Understanding 只是它的第一个实现。

---

## 七条完整原则

1. 不可突破边界（数据≠解释 / 行为≠理解 / AI≠真相 / Replay≠Re-evaluate）
2. BEDAEP = Runtime Cognitive Pattern，非 Universal Pattern，非 Engine 唯一实现
3. Evaluator 只做算法，Decision Builder 组装
4. Decision Policy = Protocol，非 God Object
5. Factory 选择 + Assembler 组装（Open/Closed）
6. Persistence 在最后
7. Engine Domain-agnostic
