# M89.2.10.1 — Explorer Identity Integration Contract
### Identity Integration / Before M89.3

> 模式：身份融合。不是 UI 融合。让 Understanding Workspace 回到 History Explorer 身体里。

---

## 一、核心问题

```
当前：#/m89 是孤立 Demo → 用户感觉"这是什么页面？"
目标：从 Explorer Shell 进入 Understanding Mode → 用户感觉"我在用 History Explorer 探索"
```

---

## 二、设计原则

> **Understanding Workspace 不是目的地，是 Explorer 的一种 Mode。**
>
> Browse Mode / Map Mode / Timeline Mode / **Understanding Mode**

---

## 三、四个边界

### 1. 保留现有 Shell
复用 Explorer Shell（Header / Navigation / Theme context / Timeline context），不新造。

### 2. Workspace 只负责认知层
不负责 Entity 浏览、时间导航、地图探索——这些仍属于 Explorer。

### 3. Evidence 增加 provenance
```ts
Evidence.provenance = { entities: ["Louis XVI", "Estates General"], relations: ["Fiscal → Political"] }
```
防止退化为 AI 编故事，未来可接 KG/Source/Citation。

### 4. 不急着改 URL
`#/m89` 暂时保留，但抽象为 ExplorationRoute，不绑定 milestone 编号。

---

## 四、实施顺序

1. 读取现有 Shell 结构（App.tsx / Layout / ExplorerShell）
2. 找到已有法国大革命入口（如果有）
3. 把 `#/m89` 改为 Explorer Understanding Mode（包裹在 Shell 内）
4. 补 Evidence provenance
5. 从产品入口走完整路径验证

---

## 五、验收

```
打开 History Explorer → 找到法国大革命 → 进入探索 → 进入 Understanding Mode → 完成 3 Evidence Loop
```

用户不会问"这是什么页面？"
