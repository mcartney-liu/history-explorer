# M86.1 — Architecture Baseline（Final）

### Evaluation Runtime Foundation

> **M86.1 建立了 History Explorer 的 Evaluation Runtime Foundation。**
> Domain-agnostic / Explainable / Replayable / Versioned / Auditable。
> Understanding 只是第一个使用它的模块。

---

## 五条不可突破边界

1. 数据 ≠ 解释
2. 行为 ≠ 理解
3. **Decision ≠ Truth**（Decision 是特定 Policy/Version/Evidence 下的判定，不是真相）
4. AI ≠ 真相
5. Replay ≠ Re-evaluate

---

## 七条架构原则

1. **Execution Semantics vs Domain Semantics** — Engine 拥有执行语义，Module 拥有领域语义
2. BEDAEP = Runtime Cognitive Pattern，非 Universal，非 Engine 唯一实现
3. Evaluator 只做算法，Decision Builder 组装
4. Decision Policy = Protocol，非 God Object
5. Factory 选择 + Assembler 组装（Open/Closed）
6. Persistence 在最后
7. Engine Domain-agnostic

---

## 架构层次

```
Evaluation Engine (Domain-agnostic)
  B Builder → E Evaluator → D Decision → A Assembler → E Explainability → P Persistence
  协议版本: EngineProtocolVersion

Understanding Module (Domain-related)
  Context → ProjectionInput → Pipeline → Projection
  领域语义: Coverage / Stage / MissingLink
```
