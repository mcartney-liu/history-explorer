## 2. Task Script（固定）

### Phase A — Traditional Exploration（8-10 min）

```
观察员：
  "请打开这个探索包，自由探索你感兴趣的内容。"

规则：
  - 不提示 CausalStatement
  - 不推荐任何具体路径
  - 不打断 Explorer 的自然行为
  - 仅在 Explorer 主动提问时回答，但回答不涉及 CS 内容
```

### Phase B — Causal Exploration（8-10 min）

```
观察员：
  "现在请打开另一个探索包，同样自由探索。"

规则：
  - 同上 — 不提示 CS
  - 如果 Explorer 主动提到 CS 内容，观察员只追问理解，不评价
```

### Phase C — Free Exploration（5 min）

```
观察员：
  "如果你还想继续，可以自由探索任何内容。"

规则：
  - 同上
```

## 3. Observer Record

### 3.1 观察员规则

| 禁止 | 允许 |
| --- | --- |
| 提醒 "这里有一段解释" | 记录 Explorer 点击了什么 |
| 问 "你看到因果了吗？" | 记录 Explorer 在哪个区域停留 |
| 推荐点击下一步 | 记录 Explorer 提出的问题 |
| 解释 CS 内容 | 记录 Explorer 的口头评论 |
| 评价 CS 质量 | 记录 Explorer 的困惑点 |

### 3.2 行为记录

```
Topic A（对照组，无 CS）:
  - Explorer 点击了哪些 Entity？ [记录 GID]
  - Explorer 在哪些区域停留？ [记录区域]
  - Explorer 提出了什么问题？ [记录问题]
  - Explorer 探索了多少步？ [记录步数]
  - Explorer 是否主动切换了探索方向？ [是/否]

Topic B（实验组，有 CS）:
  - 同上
  - Explorer 是否注意到了 CS Card？ [是/否 — 仅观察，不询问]
  - Explorer 是否点击了 CS Card？ [是/否]
  - Explorer 是否在 CS Card 区域停留？ [是/否]
  - Explorer 是否点击了 evidence refs？ [是/否]
  - Explorer 是否在 CS 出现后改变了探索方向？ [是/否]
```
