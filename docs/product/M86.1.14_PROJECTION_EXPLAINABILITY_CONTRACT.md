## 修正 1：RuleTrace 去文本化

RuleTrace { ruleId, inputs: Record<string,unknown>, decision: boolean }。展示文本由 Experience Layer 翻译。

## 修正 2：Decision 不保存 ProjectionInput 副本

Decision { inputRef }。Decision Package 共享一份 ProjectionInput。

## 修正 3：Composer 保持无业务

Composer 只产出 Projection + Metadata + Version。Evidence 由 Explainability 层产出。

## 修正 4：Evaluator.affectedBy 接口

Evaluator { affectedBy: ('anchor'|'relation'|'template'|'coverage')[] }。M87+ Selective Recompute。

## 修正 5：Explain() 统一接口

Explainable.explain() → Explanation { summary, evidence: Evidence, trace }。

Evidence 三层：
- ObservationEvidence { anchorRefs[], relationRefs[] }
- StructuralEvidence { causalChains: CausalChain[], dimensionCoverage }
- PolicyEvidence { evaluatorId, evaluatorVersion, rulesApplied: RuleTrace[] }
