## 一、定位

M87.4.4 是 M87 的最后一关。不是测试"文本是否一样"，而是验证：

> **Decision Replay 稳定，但 Explanation 可以重新生成。**

---

## 二、核心声明

> **Replay ≠ Re-evaluate。Replay 对象 = Decision（不变）。Renderer 版本影响的是表达，不是认知。**

---

## 三、三个验证 Case

### Case 1：Decision Replay

```
输入：旧 DecisionPackage
执行：replay()
结果：Decision === Original Decision
```

验证：
- Decision 不变（decisionId / output / trace 完全一致）
- 即使 Policy Version 不匹配，仍可读取历史 Decision

### Case 2：Renderer Replay（核心）

```
同一 Decision + ExplanationContext
    ├── Renderer-v1 → Artifact-A
    └── Renderer-v2 → Artifact-B

验证：
  Artifact-A.sourceDecisionId === Artifact-B.sourceDecisionId  ✅
  content 可以不同                                        ✅
```

### Case 3：历史解释重建

```
2026: Decision-001 + Renderer-v1 → Artifact-A
2027: Decision-001 + Renderer-v3 → Artifact-C

验证：
  历史认知不变
  表达可升级
  Artifact-A.sourceDecisionId === Artifact-C.sourceDecisionId
```

## 四、ExplanationReplay 类型定义

### 4.1 ExplanationReplayResult

```typescript
interface ExplanationReplayResult {
  /** 原始 Decision（不变） */
  decision: Decision<CompanionResponsePayload>
  /** 原始 ExplanationContext（重新计算） */
  originalContext: ExplanationContext
  /** 使用当前 Renderer 重新渲染的 Artifact */
  reRenderedArtifact: ExplanationArtifact
  /** 原始 Artifact（如果有保存） */
  originalArtifact: ExplanationArtifact | null
  /** Decision 是否匹配 */
  decisionMatch: boolean
  /** Context 是否匹配（同一 Decision + 同一 Projection → 相同 Context） */
  contextMatch: boolean
  /** Replay 时间戳 */
  replayedAt: number
}
```

### 4.2 replayExplanation()

```typescript
function replayExplanation(
  decisionPackage: DecisionPackage<CompanionResponsePayload>,
  renderer: ExplanationRenderer,
  rendererConfig: RendererConfig,
  originalArtifact?: ExplanationArtifact | null,
): ExplanationReplayResult
```

流程：
1. `replay(decisionPackage)` → 获取原始 Decision（不变）
2. `projectDecisionToExplanation(decision)` → 重新计算 ExplanationContext
3. `renderer.render(context, config)` → 重新渲染 Artifact
4. 对比：decisionMatch / contextMatch

## 五、验收标准

### 核心验收

- [ ] **Case 1**：Decision Replay 返回原 Decision（decisionId/output/trace 完全一致）
- [ ] **Case 2**：同一 Decision + 不同 Renderer → 不同 Artifact（sourceDecisionId 相同）
- [ ] **Case 3**：历史 Decision 可用新 Renderer 重新渲染（认知不变，表达升级）

### 边界验收

- [ ] Replay 不调用 Policy（只消费 DecisionPackage）
- [ ] Replay 不访问 MemoryStore
- [ ] Replay 不生成新 Decision
- [ ] ExplanationContext 可重新计算（纯函数，确定性）
- [ ] 同一 Decision + 同一 Projection + 同一 Renderer → 相同 Artifact content
- [ ] Artifact 可追溯回 Decision（sourceDecisionId 链路完整）
- [ ] 不同版本 Renderer 产生的 Artifact 都合法
- [ ] DecisionMatch === true（即使 Policy Version 变化）
