## Findings

### A 类（必须修复 — 影响探索数据）

---

**A-1**：`JourneyKind` 和 Journey 相关类型缺少 `causal_object`

| 维度 | 内容 |
| --- | --- |
| **Severity** | A — 影响 journey history 记录和 ExplorerPath 数据完整性 |
| **Location** | `journey.ts` line 11, `JourneyPanel.tsx` line 56 |
| **Symptom** | Explorer 在 CausalObject 之间的探索不会被正确记录为 journey entry。JourneyPanel 中 CausalObject 节点的 kind 标签显示异常 |
| **Root Cause** | M85.8.2 扩展了 `NavNode` 为 `topic | entity | causal_object`，但 `JourneyKind = 'topic' | 'entity'` 未同步扩展 |
| **Observation Impact** | ExplorerPath 中的 visitedObjects 仍然记录正确（通过 recordVisit），但 journey trace 不完整 |

**修复**：
```typescript
// journey.ts
export type JourneyKind = 'topic' | 'entity' | 'causal_object'

// JourneyPanel.tsx — 新增 causal_object 标签
node.type === 'causal_object' ? '理解' : ...
```
