## A. Component Design

### CausalStatementCard

```
┌─────────────────────────────────────────────┐
│ [为什么发生]                                  │
│ 科举制度通过标准化考试选拔文官...               │
│                                              │
│ [产生了什么影响]                               │
│ 文官体系的确立使中国形成了世界上最早的...        │
│                                              │
│ ┌──────────────┐  ┌───────────────────────┐  │
│ │ 学术界广泛共识 │  │ 证据来源: ec-cn-001 ... │  │
│ └──────────────┘  └───────────────────────┘  │
└─────────────────────────────────────────────┘
```

### 关键设计

| 设计点 | 实现 |
| --- | --- |
| **confidence 不展示 raw enum** | `"high"` → `causal.confidenceHigh` i18n key → "学术界广泛共识"（用户可理解文本） |
| **mechanism/consequence 独立节** | 各自带语义标签（"为什么发生"/"产生了什么影响"），帮助 Explorer 区分因果机制和长期影响 |
| **Evidence refs 预留 P1.7** | `evidence_refs` 渲染为按钮——无 `onEvidenceClick` 时 disabled，有 `onEvidenceClick` 时 clickable |
| **三语 i18n** | 9 个新 key（zh/en/ja），覆盖 mechanism/consequence/evidence/confidence×4/noStatement |

## E. i18n Keys

| Key | zh | en | ja |
| --- | --- | --- | --- |
| `causal.mechanism` | 为什么发生 | Why it happened | なぜ起こったか |
| `causal.consequence` | 产生了什么影响 | What impact it had | どのような影響があったか |
| `causal.evidence` | 证据来源 | Evidence sources | 証拠ソース |
| `causal.confidenceHigh` | 学术界广泛共识 | Broad academic consensus | 学界の広範な合意 |
| `causal.confidenceMedium` | 有证据支撑，存在学术争议 | Supported by evidence, scholarly debate exists | 証拠に裏付けられているが、学術的議論あり |
| `causal.confidenceLow` | 初步假设，学术界仍有争议 | Preliminary hypothesis, still debated | 予備的仮説、学界で議論中 |
| `causal.confidenceUnknown` | 置信度未标注 | Confidence not assessed | 信頼度未評価 |
| `causal.noStatement` | 暂无因果解释 | No causal explanation available | 因果説明はありません |
