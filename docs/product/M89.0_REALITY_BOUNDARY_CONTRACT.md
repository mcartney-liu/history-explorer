## 一、定位

M89.0 不是设计数据库接口。而是冻结：**真实世界知识如何进入认知循环。**

```
Historical Knowledge (KG / Dataset)
    ↓
Knowledge Projection               ← M89.0 核心
    ↓
ExplorationState
    ↓
ExplorationPolicy
    ↓
Decision<ExplorationAction>
```

---

## 二、核心声明

> **真实历史知识不是直接喂给 ExplorationPolicy，而是通过 Knowledge Projection 转化为 Exploration 可理解的状态。**

---

## 三、三个原则

### 原则 1：Knowledge Projection 隔离

```
✅ KG / Dataset → Knowledge Projection → ExplorationState → Policy

❌ Policy → 直接查询 KG
❌ Policy → 直接访问数据库
```

### 原则 2：不追求规模

```
✅ 一个高密度历史事件（如法国大革命 或 罗马共和国→帝国）

❌ 全球历史
❌ 500 万实体
```

### 原则 3：验证探索价值，不验证知识正确性

```
✅ 系统是否帮助用户形成更好的理解路径
✅ depthDelta / dimensionDelta / connectionDelta / continuityScore

❌ 回答正确率
❌ 系统是不是历史学家
```

## 四、HistoricalKnowledgeProjection 类型

```typescript
HistoricalKnowledgeProjection {
  topic: string
  description: string
  dimensions: {
    name: string           // "military" | "economy" | "politics" | ...
    entities: string[]     // 该维度的 entityId 列表
  }[]
  entities: {
    id: string
    name: string
    description: string
    dimensions: string[]   // 属于哪些维度
  }[]
  relations: {
    id: string
    from: string           // entityId
    to: string             // entityId
    type: string           // "causes" | "enables" | "influences" | "precedes" | "contrasts"
    description: string
  }[]
  understandingTemplate: {
    requiredDimensions: string[]
    expectedRelations: { from: string; to: string; type: string }[]
  }
}
```

## 五、第一个验证场景建议

### 法国大革命（高密度事件）

天然包含 6 个维度：
- 财政（financial）
- 政治制度（political）
- 阶级/社会（social）
- 思想/启蒙（intellectual）
- 战争（military）
- 欧洲外交（diplomatic）

因果链密集：财政危机 → 三级会议 → 政治冲突 → 革命爆发 → 欧洲战争 → 拿破仑崛起

### 或：罗马共和国→帝国转型

包含：制度变化、军事扩张、经济、人物、内政、文化
