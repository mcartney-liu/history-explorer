| 来源 | 目标数量 | 标记 |

### 1.3 Pattern Candidate Registry

```
在数据积累过程中，维护 Pattern Candidate 表：

| Candidate | 来源 | 状态 |
| --- | --- | --- |
| 治理 → 制度 → 人才 | co-004→co-001→co-010 链 | Observe |
| 技术 → 传播 → 文明扩散 | co-008→co-011 链 | Observe |
| 法律 → 国家治理 | co-009→co-004 链 | Observe |

状态流转：
  Hypothesis → Observed → Validated → Pattern
```

### 1.4 反证测试

```
给用户随机入口（非 curated Seed）：
  例如：直接进入 co-013（佛教传播）

观察：
  用户是否自然走向 co-016（丝路）或 co-014（理学）？

如果随机入口也形成稳定路径：
  → 不是 Seed 设计造成的
  → 是 KG + Explanation + Explorer UX 产生的自然认知模式
```

## 2. L0 Cognitive Motif（补充 M85.10）

### 2.1 定义

```
L0 Cognitive Motif = 用户探索行为的认知结构模式，
                     而非具体对象路径。

路径不同，但认知结构相同：
  秦制→科举    = 制度形成 → 人才机制
  罗马法→秦制  = 外部规范 → 内部制度
  丝路→佛教    = 传播通道 → 文化适应

共同的认知结构：
  外部压力/需求 → 制度/文化响应 → 文明稳定/扩散
```

### 2.2 Pattern 层级（更新）

```
L0 Cognitive Motif      — 认知结构模式（最抽象）
L1 Path Pattern         — 相同 Seed 的相同路径
L2 Cross-Seed Pattern   — 不同 Seed 汇聚到相同子序列
L3 Civilization Pattern — 跨文明的高层模式
```

### 2.3 L0 判定

```
L0 成立条件：
  人工审查 ≥20 条 Session 后，
  识别出 ≥3 种重复出现的认知结构（非具体路径）
  每种认知结构出现 ≥5 次

如果 L0 成立但 L1/L2 不成立：
  → Pattern 存在，但不是以 "路径重复" 的形式
  → M86 方向应该是 "认知模式引导" 而非 "路径推荐"
```

## 3. 观察重点

### 不是观察

```
❌ 用户满意度
❌ 页面停留时长
❌ 点击率
❌ 哪个 CausalObject 最热门
❌ 哪个 Seed 最受欢迎
```

### 是观察

```
✅ 为什么继续点？
✅ 什么时候停止？停止时表达了什么？
✅ 路径是否收敛？（不同用户走向相同对象）
✅ 路径是否分叉？（同一入口走向不同方向）
✅ 不同入口是否汇聚？（Seed1 和 Seed2 最终到达相同节点）
✅ 用户是否产生新问题？新问题指向什么方向？
```
