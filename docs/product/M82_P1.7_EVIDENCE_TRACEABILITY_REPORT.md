## C. Implementation Design

### `evidenceTrace.ts` — Pure Functions

| 函数 | 输入 | 输出 | 用途 |
| --- | --- | --- | --- |
| `resolveEvidenceRefs(evidenceRefs)` | `string[]` | `PackageEvidenceRef[]` | CausalStatementCard → SourceChain 的桥接 |
| `lookupEvidenceClaim(evidenceId)` | `string` | `claim \| null` | 单条 evidence claim 查找 |

### 设计原则

- **纯函数**：无状态管理，无 React hooks，可直接在任意组件中调用
- **不复制数据**：直接消费 `explorationPackages.ts` 的 `getEvidenceWithSources()` 和 `getEvidenceClaim()`
- **不解析 source 内容**：SourceChain 负责 source 渲染
- **优雅降级**：不存在的 claim ID 返回 fallback 记录，不抛异常
