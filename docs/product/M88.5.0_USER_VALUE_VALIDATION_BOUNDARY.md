## 四、三类评估指标（非 Analytics）

### 4.1 Exploration Depth（探索深度）

问题：用户是否自然进入更深层理解？

```
Session Start: Rome
    ↓
Political Structure
    ↓
Republic Institutions
    ↓
Senate
    ↓
Patrician Conflict
    ↓
Social Reform
```

指标：
```
explorationDepth = exploredAnchors.length（Session 内）
```

### 4.2 Knowledge Continuity（知识连续性）

问题：用户下一次回来，系统是否知道上次理解到哪里、缺什么、下一步是什么？

```
Session 1: coverageRatio = 0.5, missingDimensions = [economy, culture]
Session 2: 继续从 economy 开始（而非重新开始）
```

指标：
```
continuityScore = 是否从上次 missingDimension 继续
```

### 4.3 Understanding Growth（理解增长）

问题：用户的理解结构是否变得更丰富？

```
之前：知道 Roman Republic 政治制度
之后：知道政治制度 + 阶层冲突 + 制度演化 + 因果关系
```

指标：
```
understandingGrowth = {
  dimensionGrowth: coveredDimensions.length 的增量
  connectionGrowth: discoveredRelations.length 的增量
  depthGrowth: exploredAnchors.length 的增量
}
```

## 五、ExplorationMetrics 类型（M88.5.1）

```typescript
ExplorationMetrics {
  sessionId: string

  // Exploration Depth
  totalAnchorsExplored: number
  maxDepth: number                    // 最深探索层级

  // Dimension Coverage
  initialCoverageRatio: number
  finalCoverageRatio: number
  dimensionCoverageGrowth: number     // 覆盖维度增量
  dimensionsOpened: string[]          // 新打开的维度

  // Connection Discovery
  connectionsDiscovered: number       // 新发现的因果连接
  missingLinksResolved: number        // 已解决的缺口

  // Decision Acceptance
  totalDecisions: number
  decisionsAccepted: number
  decisionAcceptanceRate: number      // 采纳率

  // Understanding Delta
  understandingDelta: {
    before: { dimensions: number; connections: number; depth: number }
    after: { dimensions: number; connections: number; depth: number }
  }
}
```

## 七、边界约束

| 允许 | 禁止 |
|------|------|
| 建立 Exploration 专属评估指标 | 使用 PV/UV/CTR 等互联网指标 |
| 模拟用户旅程验证 | 真实用户系统 |
| 指标属于 Experience Evaluation Layer | 指标进入 Runtime Kernel |
| 纯函数计算 | 依赖 Analytics 基础设施 |
