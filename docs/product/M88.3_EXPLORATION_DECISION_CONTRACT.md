# M88.3 — ExplorationDecision Contract
### Strict Read-Only / Decision Lifecycle Freeze

> 模式声明：严格只读。冻结 ExplorationAction 在 Runtime 中的完整生命周期。不写代码。

---

## 一、定位

M88.3 不是增加规则。是验证 **ExplorationAction 是否完整进入 Runtime 生命周期**。

```
ExplorationPolicy.evaluate()
    ↓
Decision<ExplorationAction>        ← 复用 Runtime Decision<T>
    ↓
DecisionPackage（持久化）           ← 复用 Runtime Persistence
    ↓
Replay（历史重放）                  ← 复用 Runtime Replay
    ↓
Explanation（可解释）               ← 复用 M87 Explanation Layer
    ↓
Memory Growth（用户采纳后记录）      ← 不直接写 MemoryStore
```

---

## 二、核心声明

> **ExplorationDecision 不创建第五套 Decision 体系。它复用 Runtime 的 Decision<T> / DecisionPackage / Replay。**

---

## 三、ExplorationDecision 生命周期

### 3.1 创建

```typescript
// ExplorationPolicy 已输出 Decision<ExplorationAction>
const decision = evaluateExploration(state, policyContext)
// decision: Decision<ExplorationAction>
```

### 3.2 持久化

```typescript
// 复用 Runtime createDecisionPackage
const pkg = createDecisionPackage(
  decision,
  'exploration-input',
  '1.0',
  '1.0',
)
// pkg: DecisionPackage<ExplorationAction>
```

### 3.3 Replay

```typescript
// 复用 Runtime replay()
const replayResult = replay(pkg, 'current-policy', 'current-engine')
// replayResult.decision === 原始 Decision ✅
```

### 3.4 可解释

```typescript
// 复用 M87 ExplanationProjection
const context = projectDecisionToExplanation(decision)
// context: ExplanationContext
// 注意：需要适配 ExplorationAction → CompanionResponsePayload 的转换
```

### 3.5 Memory Growth（用户采纳后）

```
Decision<ExplorationAction>
    ↓ (用户采纳)
GrowthGraph.append(node)
    ↓
MemoryPolicy.evaluate()
    ↓
Decision<MemoryPersistencePayload>
```

注意：ExplorationPolicy 不直接写 MemoryStore。
