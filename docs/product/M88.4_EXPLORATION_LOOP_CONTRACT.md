## 一、定位

M88.4 是 M88 的最小闭环验证。不是加功能，是验证完整链路：

```
ExplorationState
    ↓
ExplorationPolicy.evaluate()
    ↓
Decision<ExplorationAction>
    ↓
用户采纳 / 不采纳
    ↓
ExplorationState 变化（新的 exploredAnchors）
    ↓
下一轮 Decision<ExplorationAction> 变化
```

---

## 二、ExplorationLoop 模拟

### 2.1 模拟一次探索 Session

```
Step 1: 用户进入 → buildExplorationState()
Step 2: Policy 评估 → evaluateExploration() → Decision<ExplorationAction>
Step 3: 用户采纳 Action → 更新 exploredAnchors
Step 4: 重新 buildExplorationState() → 新 State
Step 5: 重新 evaluateExploration() → 新 Decision
```

### 2.2 验证

- 同一 Session 内：State 变化 → Action 变化
- 采纳 Action 后：missingDimensions 可能减少
- 不采纳 Action：State 不变（exploredAnchors 不变）
