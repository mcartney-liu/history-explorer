## 一、定位

Exploration Metrics 不是 Analytics，不是用户评分，不是行为指标。

它是 **Exploration Growth Model**：一次探索之后，用户认知结构发生了什么变化？

---

## 二、核心声明

> **Metrics 衡量的是认知结构变化（Cognitive Delta），不是用户行为（User Behavior）。**

---

## 三、ExplorationMetrics 类型

```typescript
ExplorationMetrics {
  sessionRef: string

  // ── Before / After ──
  before: {
    coveredDimensions: string[]
    exploredAnchorsCount: number
    exploredRelationsCount: number
    coverageRatio: number
    missingConnectionsCount: number
  }
  after: {
    coveredDimensions: string[]
    exploredAnchorsCount: number
    exploredRelationsCount: number
    coverageRatio: number
    missingConnectionsCount: number
  }

  // ── Growth Deltas ──
  depthDelta: number              // exploredAnchors 增量（深度变化）
  dimensionDelta: number          // coveredDimensions 增量（广度变化）
  connectionDelta: number         // exploredRelations 增量（关系变化）
  continuityScore: number         // 跨 Session 连续性（0-1）

  // ── Composite ──
  understandingGrowthScore: number // 综合增长 = depth + dimension + connection + continuity
}
```

---

## 四、四个 Delta 的含义

### 4.1 Depth Delta

回答：用户有没有进入更深层？

```
初始：Rome (depth=1)
探索：Rome → Republic → Senate (depth=3)
depthDelta = +2
```

计算：`after.exploredAnchorsCount - before.exploredAnchorsCount`

### 4.2 Dimension Delta

回答：用户有没有从单一视角进入多维理解？

```
之前：[military]
之后：[military, economy, religion, law]
dimensionDelta = +3
```

计算：`after.coveredDimensions.length - before.coveredDimensions.length`

### 4.3 Connection Delta

回答：用户有没有发现新的因果关系？

```
之前：0 relations
之后：3 relations（军事→经济、政治→法律、文化→宗教）
connectionDelta = +3
```

计算：`after.exploredRelationsCount - before.exploredRelationsCount`

### 4.4 Continuity Score

回答：下一次 Session 是否从上一次缺口继续？

```
Session 1: missingDimensions = [economy, religion]
Session 2: 从 economy 开始
continuityScore = 1.0（完全连续）

Session 1: missingDimensions = [economy, religion]
Session 2: 从无关话题开始
continuityScore = 0.0（不连续）
```

计算：Session 2 的 firstExploredDimension 是否在 Session 1 的 missingDimensions 中

---

## 五、Understanding Growth Score

综合指标：
```
understandingGrowthScore = depthDelta + dimensionDelta + connectionDelta + continuityScore
```

不是用户评分。不是行为指标。是系统内部认知增长指标。

---

## 六、computeExplorationMetrics()

```typescript
computeExplorationMetrics(
  before: ExplorationState,
  after: ExplorationState,
  previousSessionMissing?: string[],     // 上一个 Session 的 missingDimensions
): ExplorationMetrics
```

纯函数。输入两个 State 快照 + 可选的上次缺口 → 输出 Metrics。
