# M86.1.16 — Memory Boundary Contract
### Strict Read-Only / Memory Architecture Freeze

> 模式声明：严格只读。冻结 Memory 与 Evaluation 的边界。不写代码。

---

## 修正 1：EvaluationSession 不保存 composerResult

Projection 是 Session 的 View，随时可从 DecisionPackage 重新生成。

## 修正 2：Composer → ProjectionAssembler

Assembler 只做 deterministic mapping，不做任何判定。

## 修正 3：Replay 不知道 Projection

Replay 产出 ReplayTimeline（decisionSequence + cursor）。Projection 由 Consumer 通过 Assembler 自行生成。

## 修正 4：Decision 不可变（Immutable Event）

Decision 一旦生成永远不可修改。如需修正 → 创建新 Decision。

## 修正 5：Evidence 不独立

Evidence ID = hash(decisionId + traceId)。Evidence 是 Decision 的派生视图。

## 修正 6：Memory Unit 定义

UnderstandingMemoryUnit { unitId, latestProjection, growthTimeline: GrowthEvent[], sessionRefs[], evidenceRefs[], versions, status }。

Memory 保存"认知变化事件"（GrowthEvent），非"评估日志"（EvaluationSession）。仅 stage 变化时写入 Memory。

```
Context 变化 → Pipeline → Projection → stage 变化? → YES → Memory(GrowthEvent)
```
