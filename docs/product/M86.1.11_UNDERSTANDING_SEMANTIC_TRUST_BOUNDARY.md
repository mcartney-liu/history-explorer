## 修正 1：Understanding State ≠ 用户真实理解

> **UnderstandingProjection = System-inferred cognitive structure projection. NOT user's actual cognitive state.**

stage = UNDERSTANDING 表示"探索结构满足闭合条件"——不代表用户真的懂了。Memory Layer 保存 exploredStructure，非 learnedKnowledge。

---

## 修正 2：unresolvedQuestions 归属 Experience Layer

Understanding Layer 只产出 MissingLink[]（结构缺口）。将缺口翻译为人类问题是 Experience Layer 的职责。Question Transition Layer 输入调整为 missingLinks → 翻译。

---

## 修正 3：Coverage Dimension 来源显式映射

UnderstandingTemplate 新增 `dimensionMapping: { [dimension]: entityId[] }`。coveredDimensions 基于 Template 显式映射判定，不由 entityType 自动推断。

---

## UnderstandingProjection 最终模型

```
UnderstandingProjection {
  topicRef, knownObjects[], discoveredRelations[],
  coverageState { requiredDimensions[], coveredDimensions[], coverageRatio },
  stage, missingLinks[],
  basedOn { anchorChainLength, relationChainLength, computedAt }
}
```

---

## 信任层级

事实层（可信）：knownObjects / discoveredRelations。推导层（系统推断）：coverageState / stage / missingLinks。表达层（Experience）：unresolvedQuestions。
