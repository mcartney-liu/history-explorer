# M89.2 — First Human Experience Reconstruction Contract
### Strict Read-Only / UI Flow Freeze

> 模式声明：严格只读。冻结法国大革命 15 分钟首次体验的最小 UI 流程。不写代码。

---

## 一、唯一目标

**一个陌生用户第一次进入，15 分钟内能不能完成一次探索闭环？**

只做一个场景：法国大革命。不扩展。不平台化。不组件化。

---

## 二、禁止

- ❌ 新 Runtime / Policy / AI Agent / KG / 推荐系统
- ❌ 大量历史数据 / 完善后台
- ❌ 平台化 / 组件化
- ❌ 做全部页面的重构

---

## 三、第一版体验链（6 个 UI 节点）

### 1. Landing Experience

**用户看到**：
```
History Explorer
选择一个你想真正理解的问题

[法国大革命为什么会发生？]
这个问题涉及财政、政治、社会、思想、军事、外交 6 个维度
```

**消费**：`HistoricalKnowledgeProjection.topicName` + `description` + `dimensions`

**当前前端**：`LandingPage` + `DiscoverPage` 同时渲染，快捷问题静态

**M89.2 改动**：新增 `CuriosityEntry` 组件——一个问题 = 一个入口卡片（标题 + 一句话 + 维度数 + "开始探索"按钮）

---

### 2. Orientation Panel

**用户看到**：
```
你正在探索：法国大革命为什么发生？

这个问题包含 6 个角度：
□ 财政    □ 政治    □ 社会
□ 思想    □ 军事    □ 外交

我们先从「财政危机」开始。
[开始第一步]
```

**消费**：`ExplorationState` { currentTopic, coveredDimensions=[], missingDimensions=[6个], coverageRatio=0 }

**当前前端**：无。`ExplorationState` 从未渲染。

**M89.2 改动**：新增 `OrientationPanel` 组件——主题 + 维度清单（全部 unchecked）+ 第一步预告

---

### 3. Exploration Workspace

**用户看到**：
```
左侧                          右侧
────                          ────
当前探索：财政危机             理解进度：▰▱▱▱▱▱ 0/6
                              已理解：
法国在路易十六时期              （无）
面临严重财政危机
                              还缺：
原因：战争开支 + 税制不公       财政 ✓（当前）
+ 贵族免税                      政治
                              社会
                              思想
                              军事
                              外交

[下一步：为什么财政问题         探索深度：1 步
 引发了政治危机？]             
```

**消费**：`ExplorationState`（实时更新 covered/missing）+ `ExplorationAction.narrativeHook`

**当前前端**：`EntityPage` + 15+ 面板（数据展示模式）

**M89.2 改动**：新增 `ExplorationWorkspace` 组件——左右分栏（内容 + 理解地图），替代 EntityPage 的数据堆叠

---

### 4. Navigation Contract Card

**用户看到**（每次跳转前显示）：
```
┌─────────────────────────────────┐
│ 你刚才理解了：财政危机           │
│                                 │
│ 因为：财政危机导致国王召开       │
│       三级会议                   │
│                                 │
│ 所以下一步：三级会议             │
│                                 │
│ 帮你理解：为什么财政问题最终     │
│           演变成政治危机         │
│                                 │
│     [继续探索]    [换一个方向]   │
└─────────────────────────────────┘
```

**消费**：`ExplorationAction` { reason, narrativeHook, targetRef, expectedGrowth }

**当前前端**：`NavNode` 只存 `{type, id, title}`——无语义

**M89.2 改动**：扩展 `NavNode` 增加 `reason` / `narrativeHook` 字段；新增 `NavigationCard` 组件

**M89.2 改动**：新增 `ContinueExploration` 入口

## 四、前端改动清单（最小集）

### 新增组件（6 个）
1. `CuriosityEntry` — Landing 入口
2. `OrientationPanel` — 维度地图
3. `ExplorationWorkspace` — 核心探索页面（左右分栏）
4. `NavigationCard` — 跳转前的原因展示
5. `UnderstandingClosure` — 理解完成信号
6. `ContinueExploration` — 继续探索入口

### 修改组件（2 个）
7. `NavNode` — 增加 `reason` / `narrativeHook` 字段
8. `App.tsx` — 新增 M89 路由（`#/m89/*`）

### 不修改
- EntityPage / CausalObjectDetailPage / Timeline / Map / Graph 等全部现有页面
- Runtime / Policy / KG / AI 全部后端

---

## 五、M89 路由结构

```
#/m89/
  ├── landing          → CuriosityEntry（法国大革命入口）
  ├── orientation      → OrientationPanel（维度地图 + 第一步预告）
  ├── explore          → ExplorationWorkspace（核心探索页面）
  └── closure          → UnderstandingClosure（理解总结 + 继续）
```

**不删除** `#/explore`、`#/entity` 等现有路由。M89 路由与现有路由共存。

## 六、数据流

```
HistoricalKnowledgeProjection（法国大革命）
    ↓
buildExplorationState() → ExplorationState
    ↓
evaluateExploration() → Decision<ExplorationAction>
    ↓
用户采纳 / 拒绝
    ↓
更新 ExplorationState（新的 coveredDimensions/exploredAnchors）
    ↓
computeExplorationMetrics() → ExplorationMetrics
    ↓
触发 UnderstandingClosure
```

## 七、验收标准

- [ ] `#/m89/landing` 显示法国大革命入口（标题 + 描述 + 维度数）
- [ ] 点击"开始探索"进入 Orientation Panel（6 个维度全部 unchecked）
- [ ] Orientation 点击"开始第一步"进入 ExplorationWorkspace

- [ ] 理解地图实时更新（coveredDimensions / missingDimensions / coverageRatio）
- [ ] 全覆盖后触发 UnderstandingClosure（总结 + 新问题）
- [ ] `#/explore` 等现有路由正常（无回归）
