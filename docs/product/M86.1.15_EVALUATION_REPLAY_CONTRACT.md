# M86.1.15 — Evaluation Replay Contract
### Strict Read-Only / Replay Architecture Freeze

> 模式声明：严格只读。冻结 Evaluation Replay 架构。不写代码。

---

## 修正 1：Explain() 返回 ExplanationData（纯数据，无 summary）

summary 由 Experience Layer 生成。

## 修正 2：Replay 对象 = EvaluationSession

EvaluationSession { sessionId, projectionInput, decisionPackage, composerResult, versions }。Replay 回放 Session，非 Projection。

## 修正 3：Decision Package 增加 dependencyGraph (DAG)

DependencyEdge { from, to, type }。Replay 按 DAG 顺序回放。

## 修正 4：Evidence 增加 Stable ID

Evidence { id, type, payload }。Memory 保存 evidenceRefs，非完整 Evidence。

## 修正 5：Deterministic Replay

> **Replay 永远不重新执行 Evaluator。只消费 Decision Package 中已保存的 Decision。**

Replay API vs ReEvaluate API 分离。版本兼容性矩阵：Policy/Template 升级不影响 Replay；Projection 模型升级需 Re-evaluate。

Evaluation → Projection → Explainability(ExplanationData) → Presentation(summary)
