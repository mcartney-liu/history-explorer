## 一、ExplanationProjection 的定位

```
Decision<T>  →  ExplanationProjection  →  ExplanationContext  →  LLM Renderer  →  Human Language
   ↑                    ↑                        ↑                      ↑              ↑
 Runtime           纯翻译层                 结构化叙事                表达系统        最终文本
```

ExplanationProjection 是翻译层，不是决策层。它把 Runtime 的 Decision 结构化数据翻译为 LLM 可渲染的叙事上下文。

---

## 二、三层模型

### 第一层：Decision（Runtime 输出，已有）

```typescript
Decision<CompanionResponsePayload>
```

例如：

```json
{
  "decisionId": "comp-decision-xxx-1",
  "evaluatorId": "companion-policy-default-v1",
  "evaluatorVersion": "1.0",
  "output": {
    "actionType": "explain",
    "targetRef": "roman-expansion",
    "structuredContent": {
      "keyPoints": ["军事扩张", "道路体系", "行政整合"],
      "references": ["entity:rome", "relation:empire-expansion"]
    },
    "suggestedNextStep": null,
    "confidence": 0.9
  },
  "trace": [...],
  "createdAt": 1691234567890
}
```

### 第二层：ExplanationContext（ExplanationProjection 输出）

```typescript
{
  subject: string                    // 叙事主题
  intent: ExplanationIntent          // 叙事意图（对应 actionType）
  narrativeGoal: string              // 叙事目标（人类可读）
  facts: ExplanationFact[]           // 事实列表（来源：Decision.structuredContent）
  references: ExplanationReference[] // 引用列表（来源：Decision.structuredContent.references）
  forbiddenClaims: ForbiddenClaim[]  // 禁止声明（由 Policy 规则推导）
  
  // 叙事风格（由 Projection 根据用户阶段判定，不由 LLM 判定）
  style: {
    tone: 'conversational' | 'educational' | 'exploratory'
    depth: 'shallow' | 'medium' | 'deep'
    language: string                 // 用户语言偏好
  }
  
  // 来源追踪
  sourceDecisionId: string
  sourcePolicyVersion: string
  sourceReferences: string[]         // Decision.structuredContent.references
}
```

### 第三层：LLM Renderer 输入（M87.4.2）

ExplanationContext → LLM prompt → 最终文本

## 三、核心约束

### 约束 1：ExplanationProjection 必须是纯函数

```typescript
// ✅ 允许
explain(decision: Decision<CompanionResponsePayload>) → ExplanationContext

// ❌ 禁止
ExplanationContext → Decision  // 不可逆
```

### 约束 2：ExplanationProjection 禁止访问

- ❌ MemoryStore
- ❌ Knowledge Graph
- ❌ Search API
- ❌ LLM / AI 服务
- ❌ 任何外部 IO

### 约束 3：ExplanationContext 必须携带来源

```typescript
{
  sourceDecisionId: string,      // 哪个 Decision 生成此 Context
  sourcePolicyVersion: string,   // 生成时的 Policy 版本
  sourceReferences: string[]     // Decision 中的 references
}
```

### 约束 4：ExplanationProjection 不产生新认知

允许的操作：
- ✅ 翻译 actionType → intent
- ✅ 结构化 keyPoints → facts
- ✅ 判定叙事风格（基于 actionType + 用户阶段）
- ✅ 添加 forbiddenClaims（基于 RuleTrace 推导）

禁止的操作：
- ❌ 生成新事实（facts 只能来自 Decision.structuredContent.keyPoints）
- ❌ 产生新判断（不在 Decision 基础上新增"应该/不应该"）
- ❌ 推荐新内容（不替代 RecommendationPolicy）
- ❌ 修改 Decision 内容

## 四、类型定义

### ExplanationIntent（映射自 CompanionActionType）

```typescript
type ExplanationIntent =
  | 'explain'      // 解释 → 因果说明
  | 'suggest'      // 推荐 → 方向引导
  | 'question'     // 提问 → 引导思考
  | 'summarize'    // 总结 → 理解收束
  | 'connect'      // 关联 → 建立跨主题连接
```

### ExplanationFact

```typescript
interface ExplanationFact {
  text: string                      // 事实描述
  source: 'decision.keyPoints'      // 来源
  index: number                     // 在 keyPoints 中的位置
}
```

### ExplanationReference

```typescript
interface ExplanationReference {
  ref: string                       // 引用标识（entity:xxx / relation:xxx）
  type: 'entity' | 'relation'       // 引用类型
}
```

### ForbiddenClaim

```typescript
interface ForbiddenClaim {
  claim: string                     // 禁止声称的内容
  reason: string                    // 禁止原因
  ruleId: string                    // 来自 RuleTrace 的 ruleId
}
```

## 五、转换规则

### actionType → intent 映射

| actionType  | intent    | narrativeGoal                                      |
|-------------|-----------|----------------------------------------------------|
| explain     | explain   | "帮助用户理解因果关系"                               |
| suggest     | suggest   | "引导用户发现下一步探索方向"                          |
| question    | question  | "通过提问帮助用户主动思考"                            |
| summarize   | summarize | "帮助用户收束当前理解，形成认知闭环"                   |
| connect     | connect   | "帮助用户建立跨主题的认知关联"                        |

### keyPoints → facts 映射

```typescript
Decision.structuredContent.keyPoints[i]
  → { text: keyPoints[i], source: 'decision.keyPoints', index: i }
```

### references → ExplanationReference[] 映射

```typescript
Decision.structuredContent.references[i]
  → { ref: references[i], type: parseRefType(references[i]) }
  // "entity:rome" → { ref: "entity:rome", type: "entity" }
  // "relation:empire-expansion" → { ref: "relation:empire-expansion", type: "relation" }
```

### RuleTrace → forbiddenClaims 推导

```typescript
// 从 trace 中提取规则约束，禁止 LLM 声称与 Decision 矛盾的内容
// 例如：companion-explain 规则触发 → 禁止声称 "我不知道"
```

## 七、验收标准

- [ ] ExplanationProjection 是纯函数（无副作用）
- [ ] 不访问 MemoryStore / KG / Search / LLM
- [ ] ExplanationContext 携带 sourceDecisionId / sourcePolicyVersion / sourceReferences
- [ ] facts 全部来自 Decision.structuredContent.keyPoints
- [ ] 不产生新事实/新判断/新推荐
- [ ] forbiddenClaims 来自 RuleTrace 推导
- [ ] 单向转换：Decision → ExplanationContext（不可逆）
- [ ] 测试覆盖：每个 actionType 的转换验证
