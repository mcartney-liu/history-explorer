# M88.1 — ExplorationState Model Contract
### Strict Read-Only / Model Freeze

> 模式声明：严格只读。冻结 ExplorationState 数据模型和构建规则。不写代码。

---

## 一、定位

ExplorationState 是**当前探索 Session 的状态快照**。

| 维度 | Memory | ExplorationState |
|------|--------|-----------------|
| 问题 | "用户长期理解发生了什么变化？" | "此刻这一次探索处于什么状态？" |
| 生命周期 | Session → Session（长期） | Session 内（当前） |
| 数据来源 | GrowthGraph（Append Only） | Projection 聚合 |
| 更新时机 | 认知阶段变化时追加 Node | 每次探索跳转时重新计算 |

---

## 二、核心约束

### 必须

- ✅ 不访问 MemoryStore
- ✅ 不访问 Knowledge Graph
- ✅ 不调用 LLM
- ✅ 输入来自 Projection（UnderstandingProjection + MemoryProjection）
- ✅ 输出只是状态模型（不决定下一步）

### 禁止

- ❌ 自己判断下一步探索方向
- ❌ 自己推荐 Topic
- ❌ 保存长期记忆
- ❌ 直接修改 Workspace
- ❌ 成为 Memory 的复制品

## 三、ExplorationState 类型定义

```typescript
ExplorationState {
  // ── Session 标识 ──
  explorationId: string

  // ── 当前主题 ──
  currentTopic: string
  currentAnchorRef: string              // 当前锚点 entityId

  // ── 理解状态（来自 UnderstandingProjection） ──
  understandingStage: UnderstandingStage
  coverageRatio: number
  coveredDimensions: string[]
  missingDimensions: string[]

  // ── 认知缺口（来自 UnderstandingProjection） ──
  missingConnections: MissingConnection[]
  // MissingConnection = { fromRef, toRef, expectedRelationType, templateRef }

  // ── 探索历史（本次 Session） ──
  exploredAnchors: string[]             // 已访问的 entityId 序列（当前 Session）
  exploredRelations: string[]           // 已遍历的 relationId 序列

  // ── 活跃问题 ──
  activeQuestions: string[]             // 用户已提出的问题（当前 Session）

  // ── 记忆投影（引用，非复制） ──
  memorySnapshot: {
    totalNodes: number
    daysSinceStart: number
    activeBranches: { branchId: string; latestStage: string }[]
  }

  // ── 元数据 ──
  computedAt: number
  basedOn: {
    understandingProjectionVersion: string
    memoryProjectionVersion: string
  }
}
```

## 五、字段推导规则

| 字段 | 来源 | 推导规则 |
|------|------|----------|
| understandingStage | UnderstandingProjection.stage | 直接映射 |
| coverageRatio | UnderstandingProjection.coverageState.coverageRatio | 直接映射 |
| coveredDimensions | UnderstandingProjection.coverageState.coveredDimensions | 直接映射 |
| missingDimensions | UnderstandingProjection.coverageState.requiredDimensions - coveredDimensions | 差集 |
| missingConnections | UnderstandingProjection.missingLinks | 直接映射 |
| exploredAnchors | sessionHistory.exploredAnchors | 直接映射 |
| memorySnapshot | MemoryProjection | 提取摘要字段 |
| activeQuestions | sessionHistory.activeQuestions | 直接映射 |

## 六、与 Memory 的边界（重要）

```
MemoryProjection
    ↓
    ├── currentStage ──────→ ExplorationState.understandingStage
    ├── currentCoverageRatio → ExplorationState.coverageRatio
    ├── totalNodes ────────→ ExplorationState.memorySnapshot.totalNodes
    ├── daysSinceStart ────→ ExplorationState.memorySnapshot.daysSinceStart
    └── activeBranches ────→ ExplorationState.memorySnapshot.activeBranches

UnderstandingProjection
    ↓
    ├── coverageState ─────→ ExplorationState.missingDimensions
    ├── missingLinks ──────→ ExplorationState.missingConnections
    └── stage ─────────────→ ExplorationState.understandingStage

Session Context
    ↓
    ├── exploredAnchors ───→ ExplorationState.exploredAnchors
    ├── exploredRelations ─→ ExplorationState.exploredRelations
    └── activeQuestions ───→ ExplorationState.activeQuestions
```

ExplorationState 是聚合层，不是存储层。它引用 Projection，不复制 Memory。
