# M86.1.10 — Understanding Runtime Boundary Contract
### Strict Read-Only / Runtime Architecture Freeze

> 模式声明：严格只读。定义 Understanding Layer 的运行时边界。不写代码。

---

## 第一部分：定位

> **Understanding Layer 是 Analysis Runtime——接收 Context 快照作为输入，输出 Understanding State。不是 Context 的写入者，是 Context 的分析者。**

Context Layer = Exploration Runtime。Understanding Layer = Analysis Runtime。单向依赖：Context ← Understanding（只读）。

---

## 第二部分：数据流

```
Context 快照 + UnderstandingTemplate → Understanding Layer → Understanding State → 投影到 Context (stage + gap)
```

---

## 第三部分：输入/输出

**输入**：Context 快照 { anchorChain, relationChain } + UnderstandingTemplate。不接收 AI 生成/行为指标/ExplorerPath。

**输出**：UnderstandingState { knownObjects, discoveredRelations, coverageState, stage, missingLinks, unresolvedQuestions }。

---

## 第四部分：触发

anchorChain 或 relationChain 新增元素时触发。不由定时器/页面切换/AI 对话触发。

---

## 第五部分：写权限

仅投影两个字段到 Context：cognitiveStage ← stage, unresolvedGap ← unresolvedQuestions[0]。不可写入 anchorChain/relationChain/currentAnchor/previousAnchor/userQuestion/understandingGoal/Template/Entity/Relation。

---

## 第六部分：投影存储

Context 中保存 understandingProjection { stage, primaryGap, lastComputedAt }。完整 Understanding State 由 Understanding Layer 独立持有。不全量嵌入——避免冗余和循环依赖。

---

## 第七部分：宿主

Understanding Layer 在 App() 中与 Context 平级——各自独立管理 state。通信：Context 变化 → App() 调用 compute(snapshot, template) → 投影结果到 Context。

---

## 第八部分：Batch 3 范围

**进入**：UnderstandingState/Template 类型、compute 纯函数、独立 state、触发机制、投影、coverageState 计算。

**禁止**：AI 判定、行为指标、全量嵌入、直接 mutate、AI 生成 Template、Workspace Memory。
