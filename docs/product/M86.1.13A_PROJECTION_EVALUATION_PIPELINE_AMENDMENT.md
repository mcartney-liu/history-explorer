## 修正 1：Builder 输出 ProjectionInput（纯事实，无语义）

移除 coveredDimensions——由 Coverage Evaluator 输出。

## 修正 2：Policy 并行求值

Coverage / Stage / Missing Evaluator 独立接收 ProjectionInput + Template，互不调用。Composer 统一组装。

## 修正 3：Decision<T> 替代 Result

每个 Evaluator 输出 Decision { evaluatorId, evaluatorVersion, input, output, trace: RuleTrace[] }。RuleTrace { ruleId, condition, actual, passed }。

## 修正 4：Evaluator 可组合

ProjectionPolicy { evaluators: Evaluator[] }，非固定三成员。未来可扩展 ConfidenceEvaluator 等。

## 修正 5：Projection Composer 新增

Composer 从 Decision Package 组装 UnderstandingProjection + Evidence + Version + Metadata。
