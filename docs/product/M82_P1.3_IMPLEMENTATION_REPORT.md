## B. Adapter Design

### API

| 方法 | 输入 | 输出 | 说明 |
| --- | --- | --- | --- |
| `get_for_relationship(source_id, target_id, _type=None)` | 两个 Entity GID | `List[CausalStatement]` | 精确匹配 cause→effect |
| `get_for_entity(entity_id)` | 一个 Entity GID | `List[CausalStatement]` | 实体作为 cause 或 effect 的所有 CS |
| `get_for_path(edges)` | Edge 序列（兼容 `graph.Edge` 和 tuple） | `List[CausalStatement]` | 路径上所有匹配的 CS |

### 关键设计决策

| 决策 | 说明 |
| --- | --- |
| **只读** | 所有方法为纯查询——不修改 `CausalIndex`，不生成内容，不调用 AI（C-5/C-6） |
| **Duck-type Edge** | `get_for_path` 兼容 `graph.Edge`（属性）和 tuple/list（索引），不 import graph.py（C-3） |
| **`_type` 参数预留** | `get_for_relationship` 接受 `_type` 但不使用——CausalStatement 通过 Entity GID 索引，Relationship type 是未来扩展点 |
| **空列表返回** | 查询无结果返回 `[]`，调用方负责 fallback（C-8） |
