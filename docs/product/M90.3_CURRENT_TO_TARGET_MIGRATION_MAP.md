# 6. Navigation Contract 迁移影响

## 6.1 当前跳转来源盘点

| 来源 | 是否有 Why 数据 | Stage E 后 |
|------|---------------|-----------|
| `RecommendationPanel` `onNodeClick(gid, ctx)` | ⚠️ 部分（`ctx.reasons` 存在但仅写入 `journeyReasons`，不显示在跳转前） | 补显示 |
| `ContinueExploringPanel` | ❌ 无 | **降级为不可点击** 或补 Relation 数据 |
| `CrossTopicView` `onEntityClick` | ❌ 无 | 同上 |
| `RelatedEntityList` | ❌ 无 | 同上 |
| `TimelinePanel` `onEventClick` | ❌ 无 | 同上（时间跳转属 Mode 内导航，可豁免） |
| `RelationshipView` `onEntityClick` | ⚠️ 有关系类型，缺 Curator 说明 | 补说明，无说明不渲染 |
| `CausalObjectDetailPage` `onCausalObjectClick` | ⚠️ 有因果关系 | 补 From/Value |

## 6.2 预期后果（不是回退）

> Stage E 后可见链接数量会**明显减少**。

这是 Navigation Contract 硬约束的直接结果：**没有 Why 的跳转不允许渲染为链接**。

链接减少 = Information Graph 退场，Understanding Graph 登场。这是产品与 Wikipedia 的分界线，是本次重构的核心目的之一，不是副作用。

## 6.3 三元组数据供给（禁止 AI 生成）

```
From   ← previousAnchor.displayName + 该 Anchor 已产生的理解      （Session 内部）
Why    ← activeRelation.descriptionRef → Causal/Understanding 查询 （EP-009 语义溯源）
Value  ← Curator 撰写的 understandingGoal 片段                    （Curator 预写）
```
