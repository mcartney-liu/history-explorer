## 一、定位

ExplorationPolicy 是第五个 Domain Module 的 Policy 层。

```
ExplorationState
    ↓
ExplorationPolicy.evaluate()
    ↓
Decision<ExplorationAction>
    ↓
CompanionPolicy（决定如何呈现）
    ↓
ExplanationRenderer（语言表达）
```

---

## 二、核心声明

> **ExplorationPolicy 不是 RecommendationPolicy。它输出认知动作（Knowledge Progression），不是内容选择（Content Selection）。**

---

## 三、ExplorationAction（认知动作，非内容推荐）

### 3.1 五种类型

```typescript
type ExplorationActionType =
  | 'open_dimension'     // 打开缺失维度（扩展广度）
  | 'follow_cause'       // 追踪因果关系（加深深度）
  | 'deep_continue'      // 深化当前维度（同一主题更深层）
  | 'compare_context'    // 跨语境对比（横向理解）
  | 'reflect'            // 理解收束（帮助形成总结）
```

### 3.2 ExplorationAction 结构

```typescript
interface ExplorationAction {
  type: ExplorationActionType
  targetRef: string                       // 目标 entityId
  reason: string                          // 为什么建议这个方向
  narrativeHook: string                   // 叙事钩子（吸引用户继续）
  expectedGrowth: {
    dimension: string                     // 预期覆盖的维度
    relationType: string                  // 预期建立的关系类型
  }
  confidence: number
}
```

### 3.3 正确 vs 错误

正确：
```json
{
  "type": "open_dimension",
  "targetRef": "entity:roman-economy",
  "reason": "已覆盖军事和政治维度，缺少经济维度",
  "narrativeHook": "罗马道路不只是军事设施——也是帝国经济的血管",
  "expectedGrowth": { "dimension": "economy", "relationType": "enables" }
}
```

错误：
```json
{
  "recommendedTopic": "罗马经济",
  "score": 0.87,
  "because": "其他用户也看了"
}
```

## 四、ExplorationPolicy 输入

### 只能

```typescript
ExplorationPolicyContext {
  state: ExplorationState
  policyContext: PolicyContext
}
```

### 禁止

- ❌ Conversation
- ❌ LLM
- ❌ User Behavior（点击率/时长）
- ❌ Popularity（其他用户也看了）
- ❌ MemoryStore（通过 ExplorationState 的 Projection 消费）
- ❌ Knowledge Graph（通过 ExplorationState 的 missingConnections 消费）

必须输出 `Decision<ExplorationAction>`，复用 Runtime：

```typescript
Decision<ExplorationAction> {
  decisionId, evaluatorId, evaluatorVersion,
  inputRef, output, trace, createdAt
```

## 六、Policy 规则（第一版——纯规则，非 AI）

### 规则优先级（从高到低）

| 优先级 | 条件 | 输出 |
|--------|------|------|
| 1 | missingDimensions.length > 0 | open_dimension |
| 2 | missingConnections.length > 0 | follow_cause |
| 3 | understandingStage = 'UNDERSTANDING' | reflect |
| 4 | coverageRatio < 1.0 | deep_continue |
| 5 | 默认 | deep_continue |

### 规则说明

**Rule 1 — open_dimension**
- 条件：`missingDimensions.length > 0`
- 选择：第一个 missingDimension 对应的 targetRef
- 叙事钩子：提示用户"你已理解 X，但还缺少 Y 这一环"
- 优先级最高：补缺口优先于挖深度

**Rule 2 — follow_cause**
- 条件：`missingConnections.length > 0`
- 选择：第一个 missingConnection.toRef
- 叙事钩子：提示用户"A 和 B 之间存在你尚未发现的关系"

**Rule 3 — reflect**
- 条件：`understandingStage = 'UNDERSTANDING'`
- 叙事钩子：帮助用户总结当前理解，形成认知闭环

**Rule 4 — deep_continue**
- 条件：`coverageRatio < 1.0`
- 选择：当前 topic 的更深层 entity

**Rule 5 — 默认 deep_continue**
- 兜底：继续当前方向

### 去重约束

如果 `targetRef` 在 `exploredAnchors` 中已存在，跳过当前规则，进入下一条规则。
