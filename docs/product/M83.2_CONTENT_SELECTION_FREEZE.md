### 2.1 S4 — Confidence Authenticity 说明

| Confidence | 数量 | 说明 |
| --- | --- | --- |
| **high** | 7 | 学界共识 — 因果关系明确、有充分史料支撑 |
| **medium** | 2 | 因果关系成立但有解释空间 — cs-007（文化交流的多因性）、cs-010（法律体系的长期影响难以归因于单一法律文本） |
| **low** | 1 | 学界存在争议 — cs-004（理学是否由佛道推动是学术争论焦点） |

**Confidence 不是人为制造的，而是反映历史研究真实状态。**

### 2.2 S5 — Causal Direction Clarity 说明

**通过标准**：Cause → Mechanism → Effect 是单向因果链，不是 "A 和 B 同时代出现" 或 "A 与 B 存在关联"。

| 不符合 S5 的示例（不新增） | 为什么 |
| --- | --- |
| "佛教传入 → 中国文化变化" | 佛教传入确实影响了中国文化，但 "文化变化" 是多因的——不能归因于单一 cause |
| "安史之乱 → 唐朝衰落" | 方向正确，但 mechanism 过于简单（"叛乱导致衰落" 是常识，不需要 CS） |
| "宋朝经济发达 → 理学兴起" | 关联性强但因果方向有争议——经济发达是否为理学的充分条件 |
