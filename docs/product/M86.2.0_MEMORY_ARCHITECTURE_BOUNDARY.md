# M86.2.0 — Understanding Memory Architecture Boundary Contract
### Strict Read-Only / Memory Architecture Freeze

> 模式声明：严格只读。冻结 Memory 架构边界。不写代码。M86.2 入口基线。

---

## 第一条约束：Memory 是 Evaluation Runtime 的消费者

**可新增**：Memory Builder / Memory Evaluator / Memory Projection / GrowthGraph / Workspace 消费层。

**不可修改**：Evaluation Engine / Evaluator Contract / Decision Model / RuleTrace / Explainability / Replay / Projection Factory。

## 第二条边界：Memory ≠ History of Interaction

Memory 记录"用户形成了什么稳定的理解结构"，不记录"用户点击了什么"。

---

## 核心对象关系

EvaluationSession → Projection → ProjectionDelta → MemoryPolicy → MemoryDecision → UnderstandingMemoryUnit → GrowthGraph

---

## UnderstandingMemoryUnit

{ unitId, topicRef, userQuestion, latestSessionRef, latestProjectionRef, growthGraph: GrowthGraph, versions, status }

## GrowthGraph

GrowthNode { type: 'delta'|'milestone'|'merge'|'branch', deltaRef, snapshot: { stage, coverageRatio, missingLinkCount } } + GrowthEdge { type: 'continues'|'branches'|'merges'|'references' }。

支持分支/合并。M86.2 不支持遗忘（只追加）。

## MemoryPolicy 默认规则

milestone: stage 跃迁。delta: coverage 提升>0.2 / 新维度覆盖 / missingLinks 减少>50%。无变化不写入。

## Workspace

消费 MemoryProjection 展示当前状态 + 成长轨迹 + 缺口提示。不写入 Memory。
