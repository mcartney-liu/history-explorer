## Check 3 — Data Flow Verification

### 3.1 完整数据流

```
_explain_path(steps)
    ↓
返回 tuple[str, list[dict]]
    ↓
explore() 解包：explanation, cs_list = self._explain_path(steps)
    ↓
ExploredNode(
    explanation=explanation,
    causal_statements=cs_list,
)
    ↓
to_dict():
    result = {..., "explanation": self.explanation}
    if self.causal_statements:           ← 非空时输出
        result["causal_statements"] = ...
    return result
    ↓
API Response:
    {..., "explanation": "...", "causal_statements": [...]}  ← 有 CS 时
    {..., "explanation": "..."}                              ← 无 CS 时
```

### 3.2 两种场景验证

| 场景 | 数据流 | 预期 API 响应 |
| --- | --- | --- |
| **有 CausalAdapter** | `_explain_path` 返回 `("科举...文官", [{...}])` | `{"explanation": "科举...文官", "causal_statements": [{...}]}` |
| **无 CausalAdapter** | `_explain_path` 返回 `("科举 --[influenced]--> 文官", [])` | `{"explanation": "科举 --[influenced]--> 文官"}`（不含 causal_statements） |

### 3.3 与 PathCandidate 的一致性

| 维度 | PathCandidate（已有） | ExploredNode（新增） | 一致性 |
| --- | --- | --- | --- |
| 字段名 | `causal_statements: list[dict]` | `causal_statements: list[dict]` | ✅ |
| 默认值 | `field(default_factory=list)` | `field(default_factory=list)` | ✅ |
| 序列化 | 空数组不输出 | 空数组不输出 | ✅ |
| 数据来源 | `_explain_path` tuple[1] | `_explain_path` tuple[1] | ✅ |

**结论：数据流完整闭环。ExploredNode 与 PathCandidate 行为完全一致。**
