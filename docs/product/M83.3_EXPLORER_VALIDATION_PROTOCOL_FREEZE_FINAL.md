## Executive Summary

M83.4 不是 "看看用户感觉如何"，而是一个**有预设假设、有对照组、有三级信号判定**的产品实验。

**三种可能的假设**：

```
H0（零假设）：CS 不改变理解，不改变行为
H1（行为假设）：CS 改变探索行为（cs_follow_entity / cs_guide_next 提升）
H2（理解假设）：CS 提升理解，但不一定立即改变行为（Mechanism Recall 提升）
```

H2 的存在是为了防止 M83 错误淘汰 Semantic Layer——如果 Explorer 理解了因果但没立即点击，不是 CS 没价值，而是 CS 的价值体现在理解而非探索路径。

## 1. Hypothesis Model

### 1.1 三种假设

| 假设 | 定义 | 验证指标 | 如果成立，意味着 |
| --- | --- | --- | --- |
| **H0** | CausalStatement 不改变 Explorer 的理解或行为 | 所有定量/定性指标均低于阈值 | CS 在当前呈现方式下无效 → M84 重新设计 |
| **H1** | CausalStatement 改变 Explorer 的**探索行为** | Causal Conversion Rate ≥ 阈值 + Exploration Depth 提升 | CS 有效触发后续探索 → M84 扩展 CS 数据 |
| **H2** | CausalStatement 提升 Explorer 的**理解**，但不一定立即改变行为 | Mechanism Recall ≥ 阈值，但 Causal Conversion Rate < 阈值 | CS 的理解价值被验证，但呈现方式可能阻碍行为转化 → M84 优化呈现而非否定 CS |

### 1.2 为什么 H2 重要

```
如果只有 H0/H1：

  Causal Conversion Rate 低 → "CS 没价值" → 淘汰 Semantic Layer

加入 H2：

  Causal Conversion Rate 低 + Mechanism Recall 高 → "CS 被理解了，但没转化为行为"
  → M84 优化呈现方式（交互/位置/叙事链），而非否定 CS 本身
```

**H2 保护 Semantic Layer 不被错误淘汰。**

## 2. Experimental Design

### 2.1 对照组设计：Topic A-B 对照

采用 **同一用户内对照**（Within-Subject Design），通过不同主题消除学习效应：

```
每个 Explorer 探索两个主题：

  Topic 1（无 CS）：
    罗马历史包（当前无 CS）
    目的：建立无 CS 的探索行为基线

  Topic 2（有 CS）：
    中国历史包（含 8 条 CS）
    目的：观察 CS 出现后的行为变化

顺序随机化：
  2 名 Explorer：先罗马 → 后中国
  2 名 Explorer：先中国 → 后罗马
```

### 2.2 为什么不用 A/B 分组

| 方案 | 优点 | 缺点 | M83 选择 |
| --- | --- | --- | --- |
| **同一用户 Topic A-B**（推荐） | 控制个体差异，样本量 4-5 即可 | 中国包和罗马包的内容不完全可比 | ✅ M83 选择 |
| **A/B 分组**（Group A 有 CS / Group B 无 CS） | 纯对照组 | 需要 ≥8 人（每组 4 人），M83 样本量不足 | ❌ |

### 2.3 学习效应控制

| 风险 | 控制方式 |
| --- | --- |
| 第二个 Topic 探索更深（学习效应） | 顺序随机化 + 对比同顺序内的 Topic 1 vs Topic 2 |
| 中国包内容比罗马包更丰富 | 不直接比较两个包的绝对深度，而是比较每个包的 "深度变化方向" |

## 3. Session Structure

```
1. 开场（2 min）
   - 介绍 History Explorer 是什么
   - 不提及 "因果解释" / "CausalStatement" / "为什么"
   - 告知有两个探索包可以体验

2. Topic 1（8-10 min）
   - 任务："请探索 [罗马/中国] 历史包"
   - 顺序随机化
   - 不提供任何关于 CS 的提示

3. Topic 2（8-10 min）
   - 任务："请探索 [中国/罗马] 历史包"
   - 与 Topic 1 不同
   - 继续不提示 CS

4. 复盘访谈（10-15 min）
   - 针对两个 Topic 分别询问
   - 如果 Explorer 没有主动提及 CS，观察员在访谈中询问：
     Q1: "在探索过程中，你有没有注意到一些解释性的文字？"
     Q2: "你能用自己的话复述一下那个解释吗？"（Mechanism Recall）
     Q3: "看完解释后，你想继续了解什么？"（Exploration Intent）
     Q4: "你觉得这个解释可靠吗？为什么？"（Confidence Awareness）
```

## 4. Observer Protocol

### 4.1 禁止行为

| # | 禁止 | 理由 |
| --- | --- | --- |
| 1 | 提醒 Explorer "这里有一段解释" | 污染 `cs_card_view` — 不是自然发现 |
| 2 | 问 "你看到因果了吗？" | 污染 H1/H2 判定 — 引导关注 |
| 3 | 推荐点击下一步 | 污染 `cs_guide_next` — 不是自然行为 |
| 4 | 解释 CS 内容 | 污染 Mechanism Recall — 不是 Explorer 自己的理解 |
| 5 | 对 CS 内容发表评价（"这个解释很好"） | 污染 Confidence Awareness — 不是 Explorer 自己的判断 |

### 4.2 允许行为

| # | 允许 | 条件 |
| --- | --- | --- |
| 1 | 记录 Explorer 的自然行为 | 全程 |
| 2 | 记录 Explorer 的口头评论 | 不打断 |
| 3 | 在复盘访谈中询问理解 | 仅在访谈阶段，不在探索阶段 |
| 4 | 如果 Explorer 主动提到 CS，追问理解 | 不引导，只追问 |

## 5. Metrics & Success Criteria

### 5.1 定量指标（事件驱动）

| # | 指标 | 事件 | 计算 |
| --- | --- | --- | --- |
| M1 | View Rate | `cs_card_view` | 含 CS 路径中 CS Card 渲染次数 |
| M2 | Expand Rate | `cs_card_expand` / `cs_card_view` | 看到 CS 后主动交互的比例 |
| M3 | Causal Conversion Rate | (`cs_follow_entity` \| `cs_guide_next`) after `cs_card_view` / `cs_card_view` | CS 触发后续探索的比例 |
| M4 | Evidence Open Rate | `cs_evidence_open` / `cs_card_view` | 打开证据来源的比例 |
| M5 | Exploration Depth Change | Topic 2 的 `open_entity` 深度 − Topic 1 的 `open_entity` 深度 | 深度变化（仅比较同顺序内的变化方向） |

### 5.2 定性指标（Session Review 打分）

| # | 指标 | 提问 | 评分 |
| --- | --- | --- | --- |
| Q1 | Mechanism Recall | "你能用自己的话复述那个解释吗？" | 3=完整复述，2=部分复述，1=不能，0=没注意到 |
| Q2 | Exploration Intent | "看完解释后你想继续了解什么？" | 3=明确方向，2=模糊方向，1=不想，0=没注意到 |
| Q3 | Confidence Awareness | "你觉得这个解释可靠吗？" | 3=注意到并正确理解，2=注意到但理解偏差，1=没注意到 |

### 5.3 三级信号判定

```
Strong Signal（强烈信号）：
  定量 ≥ 3/5 达到阈值 + 定性 ≥ 2/3 评分 ≥ 2
  → M84 = Semantic Object Expansion

Weak Signal（弱信号）：
  定量 1-2/5 达到阈值，但定性 ≥ 2/3 评分 ≥ 2（H2 成立）
  → M84 = Causal Presentation Enhancement

No Signal（无信号）：
  定量 ≤ 1/5 达到阈值 + 定性 ≤ 1/3 评分 ≥ 2
  → M84 = Causal Presentation Redesign
```

### 5.4 定量阈值

| 指标 | 阈值 |
| --- | --- |
| Expand Rate | ≥ 40% |
| Causal Conversion Rate | ≥ 25% |
| Evidence Open Rate | ≥ 10% |
| Exploration Depth Change | > 0（Topic 2 深度 ≥ Topic 1） |

### 5.5 H0/H1/H2 判定规则

| H1 成立？ | H2 成立？ | 信号级别 | M84 方向 |
| --- | --- | --- | --- |
| ✅ Causal Conversion ≥ 25% | — | Strong | Semantic Object Expansion |
| ❌ Causal Conversion < 25% | ✅ Recall ≥ 2 | Weak | Causal Presentation Enhancement |
| ❌ Causal Conversion < 25% | ❌ Recall < 2 | No Signal | Causal Presentation Redesign |
