## 三、四屏规格

---

### Screen 1 — Curiosity Entry（`#/m89/landing`）

**数据来源**：`FRENCH_REVOLUTION_PROJECTION`

**显示内容**：

```
标题：法国大革命为什么发生？

描述：不是一场革命，而是一连串财政、政治、
      社会、思想变化共同造成的结果。

涉及维度：财政 · 政治 · 社会 · 思想 · 军事 · 外交（6个）

[开始理解]
```

**交互**：
- 点击"开始理解" → `navigate('#/m89/orientation')`
- 同时调用 `buildExplorationState()` 初始化 ExplorationState

**不显示**：搜索框、主题列表、其他入口

---

### Screen 2 — Orientation（`#/m89/orientation`）

**数据来源**：`ExplorationState`（初始：coverageRatio=0, missingDimensions=[6个]）

**显示内容**：

```
你正在探索：法国大革命为什么发生？

这个问题涉及 6 个角度：
  ○ 财政    ○ 政治    ○ 社会
  ○ 思想    ○ 军事    ○ 外交

我们先从「财政危机」开始。

[开始第一步]
```

**交互**：
- 点击"开始第一步" → `navigate('#/m89/explore')`
- 调用 `evaluateExploration(state)` 生成第一个 ExplorationAction

---

### Screen 3 — Exploration Workspace（`#/m89/explore`）

**这是主循环页面。** 用户在此完成 3-5 次有意义的跳转。

**布局**：左右分栏

**左侧（内容区）**：

```
┌─────────────────────────────────────┐
│ 当前探索：财政危机                   │
│                                     │
│ 法国在路易十六时期面临严重财政危机：  │
│ - 战争开支巨大                       │
│ - 税制不公（贵族免税）               │
│ - 国家债务累积                       │
│                                     │
│ 原因：战争开支 + 税制不公 + 贵族免税  │
│                                     │
│ ┌─────────────────────────────────┐ │
│ │ 你刚理解了：财政危机             │ │
│ │                                 │ │
│ │ 因为：财政危机导致国王召开       │ │
│ │       三级会议                   │ │
│ │                                 │ │
│ │ 所以下一步：三级会议             │ │
│ │                                 │ │
│ │ 帮你理解：为什么财政问题最终     │ │
│ │           演变成政治危机         │ │
│ │                                 │ │
│ │     [继续探索]    [换一个方向]   │ │
│ └─────────────────────────────────┘ │
└─────────────────────────────────────┘
```

**右侧（理解地图）**：

```
理解进度：▰▰▱▱▱▱ 2/6

已理解：
  ✓ 财政
  ✓ 政治

还缺：
  → 社会
  → 思想
  → 军事
  → 外交

探索深度：2 步
```

**交互**：
- 点击"继续探索" → 采纳当前 ExplorationAction → 更新 State（新增 coveredDimension + exploredAnchor）→ 重新 evaluateExploration → 显示下一个内容
- 点击"换一个方向" → 拒绝当前 Action → 同一 State → 重新 evaluateExploration
- 右侧理解地图实时更新
- 当 coverageRatio 达到阈值（≥0.67 或触发 reflect）→ `navigate('#/m89/closure')`

**数据流**：

```
1. evaluateExploration(state) → Decision<ExplorationAction>
2. 用户点击"继续探索" →
3. 更新 ExplorationState（新 coveredDimension + exploredAnchor）
4. 重新 evaluateExploration(newState) → 新 Decision
5. 更新右侧理解地图
6. 重复直到触发 closure
```

## 五、数据流总览

```
Screen 1 (landing):
  FRENCH_REVOLUTION_PROJECTION → 显示入口

Screen 2 (orientation):
  buildExplorationState() → ExplorationState → 显示维度地图

Screen 3 (explore) — 主循环:
  evaluateExploration(state) → Decision<ExplorationAction>
    → 用户采纳 → 更新 State → 重新 evaluate → 循环
    → 用户拒绝 → 同一 State → 重新 evaluate

Screen 4 (closure):
  computeExplorationMetrics(before, after) → ExplorationMetrics
    → 显示总结 + 新问题
```
