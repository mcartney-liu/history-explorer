## 第一部分：EP-009（冻结）

> **Explorer Runtime Context has semantic provenance.**
>
> **Context 中所有影响认知推进的语义变化，都必须来源于权威知识层——不由 AI 临时生成，不由开发者手写硬编码。**

> Context stores the user's understanding relationship, while every semantic transition inside Context must originate from an authoritative knowledge source.

---

## 第二部分：每个 Context 字段的 Provenance 约束

| 字段 | 合法来源 | 禁止来源 |
|---|---|---|
| `user_question` | Curator 预写的 `seed_topic`；用户自主输入 | AI 生成；开发者硬编码 |
| `understanding_goal` | Curator 预写的 `exploration_goals` | AI 生成；开发者硬编码 |
| `current_focus` | Entity 的名称/描述（Knowledge Layer） | AI 生成的摘要；开发者手写标签 |
| `previous_focus` | 同 current_focus | 同 current_focus |
| `relation_reason` | Causal Layer 的已有关系数据 | AI 临时生成；开发者手写 |
| `cognitive_stage` | Understanding Layer 基于理解结构判定 | 路由事件；AI 对话；定时器 |
| `unresolved_gap` | Understanding Layer 基于理解结构 + Curator 种子推导 | AI 推荐；算法生成 |
| `exploration_id` | 系统生成 | — |

> **relation_reason 不由 AI 生成，不由开发者手写。它来自 Causal Layer 的已有关系数据。Experience Layer 只负责"什么时候展示"，不负责"创造"。**

---

## 第三部分：Context 不允许产生知识语义

> **Context 是语义传递层，不是语义创造层。**

Context 不回答"世界发生了什么"（Knowledge），不回答"为什么相关"（Causal），只回答"为什么现在理解它"（Experience）。

### 越界检测
- ❌ 一段完整解释文本 → Knowledge Layer 的内容，不应进入 Context
- ❌ 一段因果论证 → Causal Layer 的内容，不应进入 Context
- ❌ AI 生成的总结 → AI 输出，不应进入 Context

Context 中合法的语义形式：
- ✅ 指向关系："军团扩张需要后勤支持，道路系统解释了这种支持如何实现"（引用 Causal Layer）
- ✅ 指向问题："为什么这种体系最终失效？"（引用理解结构缺口）
- ✅ 指向阶段："用户当前处于 CONNECTION 阶段"（Understanding Layer 判定）

## 第五部分：Workspace Memory 单位冻结

> **Workspace 的最小保存单位不是 Visited Entity，而是 Completed Understanding Loop。**

### 错误（浏览历史）
```
Workspace：
- 罗马帝国（已访问）
- 凯撒（已访问）
- 罗马道路（已访问）
```

### 正确（理解记忆）
```
Workspace：

已完成的理解：
问题：为什么罗马能够扩张？
理解链：军事组织 → 道路网络 → 治理能力
关键发现：罗马扩张是军事+后勤+制度三层协同
尚未理解：为什么这种体系最终失效？
```

> **Workspace 中每一条记录对应一次 Completed Understanding Loop。未完成的理解标记为"可续接"。**

## 第六部分：Context 最终防污染检查清单

- [ ] Context 不包含任何 Entity 的完整属性
- [ ] Context 不包含任何 AI 生成的解释文本
- [ ] 所有 `relation_reason` 可追溯到 Causal Layer 已有关系数据
- [ ] `user_question` 和 `understanding_goal` 可追溯到 Curator 预写数据或用户输入
- [ ] `cognitive_stage` 仅由 Understanding Layer 基于理解结构判定
- [ ] Context 不包含行为指标（浏览次数/停留时长/点击序列）
- [ ] Context 不通过 URL 参数传递
- [ ] Context 不在 localStorage 中持久化（M86 为内存态）
- [ ] 任何 Experience Layer 不持有 Context 本地副本
- [ ] Engine Layer 不感知 Context 的存在
