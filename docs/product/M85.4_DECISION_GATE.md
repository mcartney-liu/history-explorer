### D3：Multi-hop 是否进入？

```
状态：DEFER TO M86
Confidence：High（Defer）
```

**证据**：M85.3 证明 "两个 CausalObject 之间的关系解释有价值"，但没有证明 "链式多跳探索有价值"。

**理由**：

```
M85 验证的：
  A → B（静态一对关系）

Multi-hop 需要验证的：
  A → B → C → D（链式动态探索）

两个问题不同。M85.3 的 4 场 Session 中：
  - 跨对象深度最大为 3 步（P3），但 P3 是基于已有认知
  - 没有 Explorer 自然形成 3+ 步的因果链探索

Multi-hop 的前提：
  1. related_causal_objects 数量 ≥ 20（当前 5）
  2. 链式关系出现（A→B, B→C 同时存在，当前无）
  3. Explorer 自然产生 3+ 步探索行为（当前无）

→ DEFER TO M86
```

### D4：Semantic Relationship 定义正式升级

```
状态：APPROVED
Confidence：High
```

**旧定义（M85.0）**：

```
Semantic Relationship = CausalObject A 与 B 的 curator 策展链接
```

**新定义（M85.4）**：

```
Semantic Relationship = 帮助 Explorer 理解两个 Semantic Object
                        为什么值得关联的解释层结构

核心不是 "connect"（连接），而是 "explain connection"（解释连接）。

KG 回答：有没有关系？
Semantic Relationship 回答：为什么值得一起理解？
```

**含义**：

```
这个定义升级将 History Explorer 的定位从 "知识图谱浏览器" 进一步拉开距离。

History Explorer 不是：
  ❌ Historical Database
  ❌ Knowledge Graph Viewer

History Explorer 是：
  ✅ Civilization Understanding Engine

KG = What exists（事实层）
CausalObject = Why it happened（解释层）
Semantic Relationship = Why they matter together（理解层）
```

## §3 Semantic Relationship 定义升级的架构影响

### 3.1 三层模型正式确立

```
Layer 1 — Fact Layer（KG）
  职责：记录历史事实
  问题：What exists?
  示例：china_v1:idea-qinzhi → caused → china_v1:idea-sanxing-liubu

Layer 2 — Explanation Layer（CausalObject）
  职责：解释因果关系
  问题：Why did it happen?
  示例：秦制通过废分封行郡县，建立了中央集权官僚体系

Layer 3 — Understanding Layer（Semantic Relationship）
  职责：连接解释，形成理解网络
  问题：Why do these explanations matter together?
  示例：理解秦制的中央集权框架，有助于理解科举为什么
        在中国成为必然选择——标准化选官是中央集权的逻辑延伸
```

### 3.2 与 KG 的根本区别

```
KG 连接：Entity A → Entity B（数据库关系）
  示例：造纸术 → enabled → 知识传播

Semantic Relationship：CausalObject A → CausalObject B（理解关系）
  示例：理解造纸术降低书写成本 → 有助于理解印刷术的革命性

区别不是连接对象不同。
区别是连接的目的不同：
  KG：记录事实
  Semantic：促进理解
```

### 3.3 History Explorer 定位升级

```
M82 之前：Historical Database（查资料）
M82-M84：Historical Exploration Platform（探索 + 解释）
M85 之后：Civilization Understanding Engine（理解文明关系）

不是 "更强大的搜索"。
不是 "更智能的推荐"。
是 "帮助 Explorer 建立文明现象之间的理解连接"。
```
