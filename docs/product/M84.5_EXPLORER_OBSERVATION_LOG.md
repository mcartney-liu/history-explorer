Curator 曾将 co-008 和 co-011 的关系分类为 KG（因为两者 effect 相同），但 P2 的行为说明：即使 effect 相同的两个 CausalObject，Explorer 也可能需要理解它们之间的技术链关系——这是 KG 不提供但 Explorer 自然寻找的。

### 重要发现

1. **3/3 Strong Signal**：所有 Explorer 都产生了跨对象理解需求。这不是个例，是模式。

2. **P2 修正了 Curator 判断**：Curator 将 co-008→co-011 分类为 KG（因为 effect 相同），但 P2 的行为说明 Explorer 需要的不只是 "它们 effect 相同" 的 KG 事实，而是 "造纸术如何为印刷术提供前提" 的理解链。这对 M85 的设计有直接启示：**即使 KG 有关联，Semantic Layer 仍然可以提供 KG 不包含的理解层次。**

3. **跨文明对比是真实需求**：P3 的文明对比行为验证了 Curator Candidate #004（从 Low Confidence 提升）。

4. **12 个 CausalObject 的覆盖多样性是关键**：如果只有 3 个中国制度类 CO，P2 和 P3 的行为不会出现。四类覆盖（制度/技术/思想/跨文明）使跨对象探索成为可能。
