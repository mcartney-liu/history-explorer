# M85.11.1 Explorer Research Protocol

> **阶段**：M85.11.1 — 人类文明理解路径研究协议
> **类型**：Research Protocol（非代码，非 Architecture Gate）
> **日期**：2026-08-06
> **基线**：M85.11 Explorer Observation Operation
> **目标**：标准化数据收集流程，为 M86 Pattern 验证提供可靠证据

---

## 0. 研究性质

```
这不是用户测试，不是产品验证。

这是产品科学实验——
研究 "人类和历史知识之间的交互规律"。

用户不是测试员，是实验对象。
目标不是 "用户喜不喜欢产品"，
而是 "人类理解文明时，是否存在共同的认知结构"。
```

## 1. 招募标准

### 1.1 用户画像要求

| 维度 | 要求 | 理由 |
| --- | --- | --- |
| 年龄 | 18-55 | 广泛覆盖 |
| 历史知识 | 不要求专业背景 | 专业历史学者可能行为不同 |
| 产品经验 | 未使用过 History Explorer | 避免学习效应 |
| 好奇心 | 对"为什么"类问题有兴趣 | 无兴趣者不会产生探索行为 |
| 排除 | 内部团队成员 | 内部观察者标记 source=internal |

### 1.2 样本结构

```
Alpha Research 阶段：

  内部观察：10 Sessions（标记 source=internal，仅用于校准仪器）
  外部用户：30 人 × 2-3 Sessions = 60-80 Sessions
  自然访问：持续积累（标记 source=organic）

目标：≥50 有效 Sessions（Depth≥2，source=invited/organic）
```

### 1.3 招募渠道

```
优先：
  - 历史爱好者社区（豆瓣历史小组、知乎历史话题）
  - 高校历史系学生（非专业，兴趣驱动）
  - 知识探索类产品用户

避免：
  - 内部团队成员
  - 付费测试平台（行为可能异化）
  - 已知产品逻辑的用户
```

## 2. 用户任务

### 2.1 任务设计原则

```
不给具体任务。
不说 "请探索秦制和科举的关系"。
不引导用户点击任何特定内容。

只说：
  "这里有一个探索历史的工具。请自由浏览，想看什么就看什么。
   如果不想看了，随时可以停下来。"

然后观察用户自然行为。
```

### 2.2 任务脚本（固定文案）

```
"这是一个探索历史文明关系的工具。

你可以从首页选择一个你感兴趣的问题开始，
也可以自由浏览任何内容。

没有正确或错误的探索方式。
你看到什么觉得有意思，就点进去看。
不想看了就停下来。

整个过程大约 10-15 分钟。"

注意：
  - 不说 "理解关联" / "关系" / "因果" / "模式" 等暗示词
  - 不说 "测试" / "评价" / "反馈" 等评估词
  - 不演示任何功能
```

### 2.3 三种入口随机分配

```
每个用户随机分配一个入口：

  Seed 1：一个庞大的国家，如何解决治理千万人的问题？（→ 秦制）
  Seed 2：为什么有些文明选择法律治理，而另一些选择官僚治理？（→ 罗马法）
  Seed 3：人类如何保存和传播知识，让文明延续千年？（→ 印刷术）

目的：观察不同入口是否产生不同的探索路径和认知结构。
```

### 3.2 认知观察表（L0-A 候选认知结构）

```
每个 Session 结束后，观察者记录：

用户似乎经历了以下认知阶段（勾选观察到的）：

[ ] 识别问题 — 用户表达了 "我想知道为什么..."
[ ] 寻找原因 — 用户关注 mechanism 部分
[ ] 理解影响 — 用户关注 consequence 部分
[ ] 建立关联 — 用户主动比较两个对象
[ ] 形成判断 — 用户表达了 "原来是这样" / "所以..."
[ ] 提出新问题 — 用户表达了想继续探索的方向

用户似乎采用了以下认知结构（观察者判断，记录为假设）：

[ ] 因果链：A 导致 B，B 导致 C
[ ] 对比：A 和 B 有什么不同/相似
[ ] 演化：A 如何变成 B
[ ] 扩散：A 如何传播/影响 B
[ ] 系统：A、B、C 如何构成一个整体
[ ] 其他：_______________

注意：这是观察者假设，不是用户自我报告。
不要问用户 "你是不是在对比？"
只记录观察到的行为模式。
```

## 5. Interview 问题

### 5.1 访谈时机

```
每 10 个 Session 后，抽取 3-5 个用户进行 5 分钟简短访谈。
不打断探索过程。在 Session 结束后进行。
```

### 5.2 三个固定问题

```
Q1：刚才探索过程中，你觉得自己解决了什么问题？
    或者说，你理解了什么东西？

    （目的：验证用户是否形成了理解，而非仅仅浏览）

Q2：如果继续探索，你最想知道什么？

    （目的：捕获 O3 — Explorer-generated question）

Q3：有没有哪个关联让你觉得"原来如此"？

    （目的：验证 explanation 的价值，捕获认知转折点）
```

### 5.3 禁止的问题

```
❌ "你觉得产品好用吗？"
❌ "你最喜欢哪个功能？"
❌ "你会推荐给朋友吗？"
❌ "你觉得哪里需要改进？"

这些是产品验证问题，不是认知研究问题。
```

## 6. Pattern 分析模板

### 6.1 单个 Session 分析

```
Session ID: _______________
Path: [co-xxx, co-xxx, ...]
Depth: ___
Cognitive Theme: _______________
L0-A Candidate: _______________

Explorer Question (O3): _______________
Interview Q1 理解: _______________
```

### 6.2 跨 Session 聚合分析

```
每 20 个 Session 后，运行一次聚合分析：

Q1：是否存在重复路径？
  最常见的 3 条路径：
    1. [co-xxx, co-xxx, co-xxx] × ___ 次
    2. [co-xxx, co-xxx] × ___ 次
    3. [co-xxx, co-xxx, co-xxx, co-xxx] × ___ 次

Q2：是否存在跨 Seed 汇聚？
  不同 Seed 共享的子序列：
    [co-004, co-001]：Seed1 × 15 + Seed2 × 8 = 23 次
    [co-009, co-004]：Seed2 × 12 次

Q3：是否存在 L0-A 认知结构重复？
  最常见的认知结构：
    - 因果链 × ___ 次
    - 演化 × ___ 次
    - 对比 × ___ 次
    - 扩散 × ___ 次
    - 系统 × ___ 次

Q4：Explorer Question 是否指向共同方向？
  高频问题类型：
    - "为什么 X 和 Y 不同？" × ___ 次
    - "X 后来怎么样了？" × ___ 次
    - "其他文明也是这样吗？" × ___ 次
```

### 6.3 Pattern 成立判定

```
L0 Cognitive Motif 成立条件：
  ≥20 个 Session 中，
  同一认知结构（如 "因果链"）被观察者标记 ≥8 次
  且 ≥3 个不同用户表达了类似的认知过程

L1 Path Pattern 成立条件：
  同一 visitedObjects 序列 ≥10 次
  且该序列来自 ≥5 个不同用户

L2 Cross-Seed Pattern 成立条件：
  不同 Seed 的路径中共享 ≥2 个连续 visitedObjects
  且 ≥5 次

L3 Civilization Pattern：
  人工审查 L0+L1+L2 后，
  判断是否可抽象为跨文明的高层模式
```

## 7. 研究伦理

```
1. 所有数据匿名化（sessionId 不关联个人身份）
2. 用户知晓数据用于产品研究（非商业用途）
3. 用户可以随时退出
4. 不记录 IP、浏览器指纹、地理位置
5. ExplorerPath 数据仅存储在 localStorage（用户本地）
```
