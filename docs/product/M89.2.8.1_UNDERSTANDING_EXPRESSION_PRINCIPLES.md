# M89.2.8.1 — Understanding Expression Principles
### Expression Rule / Lightweight Amendment to M89.2.8

> 模式：表达原则。不是新阶段，是给 Workspace Prototype 加一条原则——防止系统替用户下结论。

---

## 核心原则

> **Evidence 是触发变化，不是答案。Closure 是用户理解形成，不是 AI 总结。**

---

## 三条规则

### Rule 1：系统展示推理路径，不给结论

```
❌ "这告诉我们：革命首先是制度危机。"
✅ "新的证据让我们看到：如果财政问题无法通过旧制度解决，
    冲突会从经济问题转向政治问题。"
```

区别：前者系统给结论，后者系统展示推理路径——让用户自己走到结论。

### Rule 2：强调理解演化，不否定用户

```
❌ "你现在理解：革命不是人民反抗国王。"
✅ "你的理解发生了变化：
    开始：革命 = 人民反抗国王
    现在：革命 = 财政、制度、社会结构共同作用的结果"
```

区别：前者暗示"你以前错了"，后者展示"你成长了"。

### Rule 3：Evidence 是解释范围扩大，不是事实→结论

```
❌ 事实 → 结论
✅ 旧解释 → 新证据出现 → 解释范围扩大
```

---

## 新的核心对象：Understanding Transition

M89.2.8 中实际出现了一个比 Evidence 更核心的对象：

```
Understanding Transition {
  from:    "革命是一次人民起义"
  through: "财政危机 + 制度矛盾 + 社会结构"
  to:      "革命是旧制度无法吸收变化后的系统性崩溃"
}
```

这是产品真正的价值单位。Evidence 是触媒，Transition 是结果。

---

## 对 M89.2.8 的具体修正

### 修正前（Rule 1 违规）
> "这告诉我们：革命首先是制度危机，不是国王个人问题。"

### 修正后
> "新的证据让我们看到：当财政问题无法通过旧制度解决时，冲突开始从经济领域转向政治领域。"

### 修正前（Rule 2 违规）
> "你现在理解：革命是多层危机叠加的必然结果。"

### 修正后
> "你的理解发生了变化：从'革命是一次性事件'到'革命是多个危机叠加的过程'。"
