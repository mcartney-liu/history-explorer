### 1.1 样本量风险（须 PO 知悉）

Plan 第 7 节量化 Gate 规定：**N ≥ 4 方可裁定 Gate**。本轮 N = 4。

推论：
- **任一场作废（环境异常/Explorer 中途退出/引导违规），有效样本即降至 3，本轮丧失 Gate 裁定资格**，只能作探索性输入。
- 因此要求：**准备 1 名备用 Explorer（E-Backup）**，场景随缺位者。
- 每场开始前的环境自检为**强制阻断项**，不是建议项——这是保护样本有效性的唯一手段。

### 1.2 Explorer 招募要求

| 项 | 要求 |
| --- | --- |
| 对历史的兴趣 | 有一般兴趣即可，**不要历史专业人士**（专业知识会掩盖产品的解释缺陷） |
| 产品接触史 | **必须为首次接触本产品**，未看过任何原型、截图、演示 |

| 设备熟练度 | 能正常使用浏览器即可 |
| 语言 | 中文母语；须能接受界面存在英文内容（已在 Briefing 声明） |

> 招募时**只说**"体验一个了解历史的产品，约 45 分钟"，**不说**"知识图谱""AI""探索体验验证"等任何框定性词汇。

## 2. 人员角色

每场固定 3 人在场（Explorer + Moderator + Observer），职责互斥，不得兼任。

| 角色 | 人数 | 职责 | 硬约束 |
| --- | --- | --- | --- |
| **Explorer** | 1 | 自然探索，想到什么说什么 | 无任务压力，不被告知"正确路径" |
| **Moderator** | 1 | 照 `M81a_MODERATOR_SCRIPT.md` 宣读、计时、结束访谈 | **不得引导、不得演示、不得解释文案**。全程只在开场/切换/结束发声 |
| **Observer** | 1 | 静默填 `M81a_OBSERVER_WORKSHEET.md` | **全程不发声**，不与 Explorer 眼神互动，不坐在 Explorer 视线正前方 |

**为什么 Moderator 与 Observer 不可兼任**：Moderator 需应对提问，注意力被占用；Observer 需连续记录行为时序。一人兼任必然丢数据或破坏静默环境。若人力不足，**宁可减少场次，不可合并角色**。

**E5 场次**：因时长 70 min，建议 Observer 中途不换人（换人会丢失跨场景对比的连续判断）。

## 3. Session 流程（单场 45 min 标准流程）

| 阶段 | 时长 | 执行者 | 内容 |
| --- | --- | --- | --- |
| **T-15 环境自检** | 15 min | Moderator | 见第 4 节 SOP，**未全通过不得开场** |
| **T0 开场** | 3 min | Moderator | 照读开场白 + 已知情况说明（`MODERATOR_SCRIPT` 第2节） |
| **T3 任务发布** | 1 min | Moderator | 照读场景任务句，**不演示、不指向** |
| **T4 自由探索** | 25 min | Explorer | 静默观察期。Moderator 仅在 Explorer 主动提问时按应答口径回应 |
| **T29 停止** | 1 min | Moderator | "我们先到这里" |
| **T30 结束访谈** | 12 min | Moderator | 照 `M81a_INTERVIEW_GUIDE.md` 选问，记原话 |
| **T42 收尾** | 3 min | Moderator | 致谢；**不解释产品、不透露验证目的、不承诺后续** |
| **T45 场后归档** | 20 min | Observer + Moderator | 见第 6 节 |

### 3.1 E5 双场景流程（70 min）

| 阶段 | 时长 | 内容 |
| --- | --- | --- |
| T-15 环境自检 | 15 min | 同上 |
| T0 开场 | 3 min | 同上，**额外告知**："今天会有两段探索" |
| T3 场景 A′ | 25 min | 任务 A′ 探索 |
| T28 场景切换 | 2 min | 照读："下面换一个方向。" **浏览器回到首页初始状态，不清空、不重启**（保留会话足迹是迁移观察的前提） |
| T30 场景 B | 22 min | 任务 B 探索 |
| T52 结束访谈 | 15 min | 标准访谈 + **迁移追问**（见 3.2） |
| T67 收尾 | 3 min | 同上 |

### 3.2 E5 专属迁移追问（仅 E5 使用，加在标准访谈后）

1. "第二段探索的时候，你觉得跟第一段是同一个东西吗？"
2. "换到第二段，你上手更快了还是更慢了？为什么？"
3. "两段里面，有没有哪些地方你觉得'应该一样但不一样'？"

> 仍遵守访谈原则：问过程，不问"有没有发现 X"。

### 3.3 场次间隔

- 同一天最多排 **2 场**。Observer 连续记录超 2 场后判断力显著下降。
- 场次间隔 **≥ 60 min**，用于归档与环境复位。
- **E5 建议单独排一天**，不与其他场次同日。

## 4. 环境启动 SOP（Moderator 执行，T-15 完成）

> 依据 `M81a_VALIDATION_READINESS_SUMMARY.md` 第 1.B 节：前端强依赖后端（7 处硬编码 `localhost:8000`），任一未启动则整场作废。

### 4.1 启动顺序（顺序不可颠倒）

**① 启动后端**
```
cd backend
.\.venv\Scripts\python.exe -m uvicorn app.main:app --port 8000
```

**② 验证后端**
浏览器访问 `http://localhost:8000/topics` → 须返回主题 JSON 数据（非报错、非空）。

**③ 启动前端**
```
cd frontend
npm run dev
```

**④ 验证前端**
浏览器访问 `http://localhost:5173/` → 须正常加载。

### 4.2 开场前强制检查清单（逐项打勾，任一不过即禁止开场）

- [ ] 后端 `/topics` 返回有效数据
- [ ] 前端 `http://localhost:5173/` 正常加载
- [ ] **首页主题列表有内容**（若空白/加载失败 → 后端未就绪，回 4.1 重来）
- [ ] 随手点入一个主题，能看到实体与关联内容
- [ ] 浏览器**回到首页初始状态**，上一场探索足迹已清空（刷新页面即可，足迹非持久化）
- [ ] 浏览器窗口最大化，缩放 100%
- [ ] 关闭无关标签页、通知、IM 弹窗
- [ ] 录屏已开启（若采用录屏，见 6.3）
- [ ] Observer 就位，Worksheet 与计时器备妥

### 4.3 会话中环境异常处置

| 情况 | 处置 |
| --- | --- |
| 页面报错/白屏 | Moderator 记录时间点与当时操作 → 刷新一次 → 仍失败则**终止本场**，记为作废，启用备用 Explorer |
| 后端中断（数据全空） | 同上，**直接作废**，不得中途重启后续跑 |
| 单个内容加载慢 | **不干预**，如实记录，属有效观察数据 |
| Explorer 误关标签页 | Moderator 协助重开至首页，记录该事件；**不算作废** |

> 判断原则：**影响"体验是否成立"判断的技术故障 → 作废；不影响的 → 记录后继续**。宁可作废重跑，不可带着脏数据进 Gate 裁定。

## 5. 每场记录要求

### 5.1 必交产物（每场 4 项，缺一不可）

| # | 产物 | 责任人 | 交付时限 |
| --- | --- | --- | --- |
| 1 | `M81a_OBSERVER_WORKSHEET.md` 填写件 | Observer | 场后即时 |
| 2 | 访谈原话记录 | Moderator | 场后 20 min 内 |
| 3 | `M81a_EVIDENCE_TEMPLATE.md` 归档件 | Observer + Moderator 共同 | 场后 20 min 内 |
| 4 | 探索路径序列（对象点击顺序） | Observer | 随 Worksheet |

### 5.2 命名与归档

```
docs/product/evidence/M81a_S{场次号}_{ExplorerID}_{场景}.md
例：docs/product/evidence/M81a_S01_E1_A.md
    docs/product/evidence/M81a_S05_E5_AB.md
```

> `evidence/` 目录在**第一场执行时创建**，本文档不预先建目录（避免空目录入库）。

### 5.3 记录硬性规范

**必须记录**：
- 用户**原话**（逐字，不转述、不润色）
- 行为**时序**（第几分钟做了什么，点击对象顺序）
- **停顿**（>3 秒）与**回退**动作
- R1/R2/R3 已知状态反应（Worksheet 第六节）

**禁止记录**：
- ❌ 主观推断："用户似乎感兴趣""看起来懂了"
- ❌ 产品评价："这里 UI 不好""应该加个按钮"
- ❌ 事后补记的"我记得他好像……"

> 原则：**记录可被第三方复核的事实**。写不出具体行为的，就不写。

## 6. Observer 执行规范

### 6.1 三条铁律

1. **全程静默** —— 不出声、不点头、不叹气、不与 Explorer 对视。Explorer 向你提问时，看向 Moderator，由 Moderator 应答。
2. **只记发生，不记感受** —— 打勾制。判断不了的项留空，**留空是合法的**，编造不是。
3. **不提前解释、不安抚** —— Explorer 困惑、卡住、烦躁时，那正是数据。**不得出手相助**。

### 6.2 座位与视线

- Observer 坐在 Explorer **侧后方**，能看到屏幕、不进入 Explorer 视野正面。
- 笔记本电脑屏幕**不得朝向 Explorer**。
- 计时器静音。

### 6.3 录屏（可选但强烈建议）

- 采用前须获 Explorer **口头同意**，并说明"只记录屏幕操作，用于内部复盘，不外传"。
- Explorer 拒绝则**不录**，不追问原因，不影响本场有效性。
- 录屏文件与 evidence 同目录归档，命名一致。

### 6.4 R1/R2/R3 特别提醒

这三项是**已知的当前状态**，不是本场事故：

| 项 | 内容 | Observer 动作 |
| --- | --- | --- |
| R1 | 探索记录不持久 | Explorer 找"保存"入口 → 记录，**不提示"没有这个功能"** |
| R2 | 关系解释含工程术语 | Explorer 停顿/出声读/问"什么意思" → 记原话，**不得解释** |
| R3 | 中英混排 | Explorer 对语言变化有反应 → 记录，**不道歉** |

> Explorer 在此三处的困惑是 **M80.5 Presentation Semantics 与 Shell 语义的直接证据**，解释掉就是销毁证据。

### 6.5 Observer 场后 5 分钟自检

- [ ] 时序记录是否有断档（超过 5 分钟无记录 = 漏记）
- [ ] 原话是否为逐字，有无被我润色
- [ ] 有无写入主观推断词，若有则删除
- [ ] 第六节 R1/R2/R3 是否已确认（含"未出现"也要勾）
- [ ] 路径序列是否完整可复原

## 7. 本轮 Gate 裁定口径

> 2026-08-05 修订：N=5→N=4。修订依据为 Founder 决策——4 场已可充分覆盖 A′/B 两场景 + 跨场景迁移，继续追加样本边际收益低。**此修订在 Gate 裁定前完成，非事后调整**。

**M81a PASS 须同时满足**（N = 4）：

| 指标 | 阈值 | 折算人数 |
| --- | --- | --- |
| 完成 First 5 Minutes 三信号中至少两个 | ≥ 80% | **≥ 4 人**（4×0.8=3.2，向上取整） |
| 主动产生下一探索方向 | ≥ 60% | **≥ 3 人**（4×0.6=2.4，向上取整） |
| 产生未完成问题或回访意愿 | ≥ 50% | **≥ 2 人** |

**附加约束**：任一失败信号在 **≥ 2 人**（50%）身上出现 → 即使达标率满足，仍判 **NEED REVISION**。

失败信号（Plan L112–116）：不知下一步点什么 / 只浏览节点列表 / 理解成百科 / 无探索欲望 / 要求"保存收藏"才肯离开。
