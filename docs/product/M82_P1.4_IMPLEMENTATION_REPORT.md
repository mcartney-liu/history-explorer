## B. Integration Design

### 注入点

```
ExplorationEngine.__init__()
  ├── causal_adapter: CausalStatementAdapter | None (新增可选参数)
  └── self._causal = causal_adapter

ExplorationEngine._explain_path(steps)
  ├── 1. 构建 structural path text (原模板行为，永远执行)
  ├── 2. 如果 self._causal is not None:
  │     ├── 遍历每个 step，调用 adapter.get_for_relationship()
  │     └── 将 CS mechanism 附加到 explanation 末尾
  └── 3. 返回 combined text
```

### 输出格式

```
# 无 Adapter (backward compatible):
Concept '科举制度' —[led_to →]→ Concept '文官体系'

# 有 Adapter + 匹配 CS:
Concept '科举制度' —[led_to →]→ Concept '文官体系' | [high] 科举制度通过标准化考试... | [high] 三省六部制在唐代...

# 有 Adapter + 无匹配 CS (C-8 fallback):
Concept '科举制度' —[influenced →]→ Concept '理学'
```

### 关键设计决策

| 决策 | 说明 |
| --- | --- |
| **可选参数** | `causal_adapter` 默认为 `None`——不传入时 `_explain_path` 保持原有模板行为，零破坏 |
| **structural path 永远保留** | CausalStatement 是 enrichment，不是替代——模板路径文本始终在前，CS 文本用 `\|` 分隔符附加 |
| **C-8 fallback** | `get_for_relationship()` 返回空列表 → 不附加任何 CS 文本，只返回 structural path |
| **TYPE_CHECKING import** | `exploration_engine.py` 不 import `causal/` 模块（仅用于类型标注），保持 Semantic Layer 独立性 |
