## 3. 设计决策

### 3.1 UI 语义约束

```
✅ "理解关联" — Understanding Layer 语言
✅ "继续探索" — Explorer 自主选择
✅ "探索 %{name}" — CTA 保持 Explorer 身份
❌ "相关内容" / "推荐阅读" / "你可能还想了解" — 未出现
```

### 3.2 新增 prop

```
objectTitleMap?: Record<string, string>
```

用于将 `co-001` 映射为 `科举 → 文官体系`。当前为可选，Phase 2 数据加载后使用。

### 3.3 relation_type 中文标签

```
institutional_evolution  → 制度演化
technological_chain      → 技术链
civilization_contrast    → 文明对比
ideological_influence    → 思想影响
```

每个标签有独立颜色（金色/青色/紫色/暖色）。

### 3.4 架构语言 vs 用户语言

```
❌ 不出现：Explanation Layer / Understanding Layer / Fact Layer
✅ 出现：  为什么会发生 / 产生了什么影响 / 理解关联 / 继续探索
```
