## 0. 文档定位与铁律

本文回答：**一个第一次来的用户，在 15 分钟内怎么走完一次完整的探索闭环，并且在离开时确实更聪明。**

铁律遵守方式：

| 条款 | 本文的遵守方式 |
|------|--------------|
| 不得提前设计 | 旅程写的是用户处境与认知事件，不是屏幕流程；无页面、无组件、无控件、无视觉 |
| 节点集一致 | 旅程触点严格 = B1 的 TP-01…TP-30，全部出场（§8 覆盖校验） |
| 可验证 | 每段给出时间预算、交棒条件、离场判据（§2、§3、§6） |

## 1. 首访用户与进场心智

### 1.1 画像（来自 M81a 真人观察 N=4，不虚构）

| 事实 | 出处 | 对旅程的约束 |
|------|------|------------|
| 用户进来时**只有好奇，没有目标** | Phase0 v1 §5 心智信号 | 首屏不能要求用户先说出要什么（TP-26 承担起跳，非 TP-24 检索） |
| 用户会问「我在哪、怎么回去」 | S002：「上面应该有个路径可回溯」，四场共踩 | TP-23 从第一次跳转起必须在场 |
| 用户不信没有依据的连线 | S002：「评分依据哪些维度、规则是什么」 | TP-11 必须与连线同时出场，不能延后 |
| 用户会自发要求比较 | 四场中三场自发提出跨文明对比 | Compare 必须在首访路径出现，且可提前直入 |
| 探索链一断即离场 | S004 十二分钟离场 vs S002 四十二分钟 | 每段必须有明确交棒；停滞处必须有 TP-27 接住 |
| 生硬模板直接导致流失 | M81a | TP-21 表达粒度全程在场 |

### 1.2 一句话旅程目标

> 用户进场时手上只有一个模糊的好奇；离场时手上有**一条自己走出来的理解链**、**一把可信度的尺子**、**一次照见自己的机会**。

这三样分别对应 Article 0 的三层：对象层（理解链）、真值层（可信度尺子）、主体层（照见自己）。三样缺一，就答不出「你觉得自己变聪明了吗」。

## 2. 15 分钟时间预算总表

| 段 | 时段 | 段名 | 用户的一句话 | 主要触点（能力） | 段末用户手上多了什么 |
|----|------|------|------------|----------------|-------------------|
| T1 | 0:00–2:00 | 好奇进场 | 「有点意思，我先看看这个」 | TP-26 TP-25 TP-24 TP-28 TP-23 TP-29 TP-30 | 一个属于自己的问题 |
| T2 | 2:00–5:00 | 事实落地 | 「原来它连着这些」 | TP-01 TP-02 TP-04 TP-05 TP-11 TP-20 TP-15 TP-09 | 一个锚点 + 它的关系网 |
| T3 | 5:00–8:00 | 追问为什么 | 「为什么会这样？这凭什么可信？」 | TP-10 TP-12 TP-06 TP-07 TP-08 TP-21 TP-17 | 一条因果 + 一把可信度尺子 |
| T4 | 8:00–11:00 | 意义与对比 | 「这有什么意义？别处是不是也这样？」 | TP-13 TP-14 TP-03 | 一个理解框架 + 一次跨文明校验 |
| T5 | 11:00–13:00 | 推进闭环 | 「我还缺什么？下一步去哪？」 | TP-16 TP-27 TP-18 | 一个由自己缺口生成的方向 |
| T6 | 13:00–15:00 | 镜像离场 | 「原来我这一路是这么走的」 | TP-19 TP-22 | 一次成长刻度 + 一次自我照见 |

**时间预算说明**：15 分钟不是要求用户看完 30 项能力的说明书，而是**在自然探索中让 30 项能力全部生效**。其中隐性触点（TP-09 TP-17 TP-21 TP-29 TP-30）不占用户动作时间，以「全程不出事」被体验；常驻触点（TP-23 TP-28 TP-15 TP-18 TP-20 TP-16）分摊在各段，不单独计时。

## 3. 六段逐段设计

### T1 · 0:00–2:00 好奇进场

| 项 | 内容 |
|----|------|
| 用户处境 | 只有一点好奇，说不出要什么。此时若要求他先输入关键词，他会走 |
| 认知事件 | 从「随便看看」变成「我想弄明白一件事」 |

**触点与能力来源**

| 触点 | 能力 | 在这一段做什么 |
|------|------|--------------|
| TP-26 起跳台 | **C26** 策展探索包 | 承担首屏心智：给出有编排的起跳对象，把好奇翻译成第一次跳转。不要求用户先知道自己要什么 |
| TP-25 问题锚 | **C25** 提问 | 用户把模糊好奇落成一个可承接的问题，这个问题成为整次探索的语义锚（宪法 P07：探索由疑问驱动） |
| TP-24 定向直达 | **C24** 检索 | **在场但不主导**（R6 / ADR-0014 D2）。只服务「我已经知道要找什么」的少数用户，见 §7 变体 V1 |
| TP-28 术语恒等 | **C28** 多语言与术语 | 用户选定语言，此后同一历史对象在任何位置都是同一个名字，不会被误认成两个 |
| TP-23 定位常驻条 | **C23** 认知定位 | 从进场即在场；此刻记下起点，此后每次跳转都能回答「我从哪来、为什么来」 |
| TP-29 探索语法恒定 | **C29** 领域可插拔（隐性） | 用户在此段学到的动作方式，后面四个主干全部通用，不必重学 |
| TP-30 一致性承诺 | **C30** 冻结治理（隐性） | 用户在这一段建立的术语与关系直觉，全程不会被产品悄悄改掉 |

**C3 前置动作**：本段除起跳外，还须让用户知道「这里可以直接比较」。理由是三分之三的自发比较需求会在 T3–T4 之间冒出来，若那时才第一次见到这个入口，用户已经在找出口了。这不是把 Compare 提前使用，而是**让入口先被看见**（导航级独立入口，B3 §2.3）。

**交棒条件**：用户选定了第一个锚点，并且这个锚点携带了他自己的问题。
**风险与接住**：用户在此停滞（不知道选什么）→ TP-27 停滞接住以确定性引导给出动作提示（禁个性化、禁打分，C27）。

### T2 · 2:00–5:00 事实落地

| 项 | 内容 |
|----|------|
| 用户处境 | 面前有了第一个对象。他要确认「这是什么」，然后立刻会问「它和什么有关」 |
| 认知事件 | 从「一个点」变成「一张小网」 |

**触点与能力来源**

| 触点 | 能力 | 在这一段做什么 |
|------|------|--------------|
| TP-01 事实落地面 | **C01** Fact 事实供给 | 给出带结构化时间与来源标注的事实，作为本次探索的唯一基准 |
| TP-02 关系展开面 | **C02** Relationship 关系结构 | 用带语义的关系把这个锚点连出去，让「历史是连接的」变成用户眼见的结构 |
| TP-04 时间对齐轴 | **C04** Temporal Structuring | 用户开始关心先后与同时；时间在此从一段文字变成可对齐的维度。**同时性在此建立，是 T4 对比的硬前提** |
| TP-05 地点锚定位 | **C05** Spatial Anchoring（降级态） | 用户问「在哪」时，以具名地点作为可跳转锚点接住，并如实说明本期无空间视图，不留假入口（B1 §9 F-1） |
| TP-11 连接理由行 | **C11** Connection Explanation | **与连线同时出场**，回答「这两个为什么被放在一起」。这是 S002 质疑的直接应答，延后出场即失信 |
| TP-20 轨迹链 | **C20** Exploration Trail | 用户第一次跳转，轨迹开始累积。它是认知轨迹（锚点链 + 关系链 + From/Why），不是浏览历史、不是收藏夹 |
| TP-15 认知状态读数 | **C15** Exploration State | 用户第一个探索动作发生，系统开始知道「他覆盖了什么、缺什么」。这是 T5 下一步的唯一合法输入 |
| TP-09 无死路保证 | **C09** Data Integrity（隐性） | 用户点开的每一条关系都指向真实存在的对象，不会走进空白。缺席即 S004 式十二分钟离场 |

**交棒条件**：用户不再追问「还连着谁」，转而追问「为什么」。
**风险与接住**：关系走尽但问题未解 → TP-03 跨主题续走（本段可提前触发，正式归属 T4）。

### T3 · 5:00–8:00 追问为什么（含真相刻度）

| 项 | 内容 |
|----|------|
| 用户处境 | 他看到了关系，但关系本身不构成理解。他要机制，而且他会怀疑 |
| 认知事件 | 从「知道有关」变成「知道为什么，并且知道这有多可信」 |

**触点与能力来源**

| 触点 | 能力 | 在这一段做什么 |
|------|------|--------------|
| TP-10 机制陈述面 | **C10** Causal Explanation | 说清「甲通过什么机制导致乙、后果是什么、置信度多少」 |
| TP-12 人话转译 | **C12** Grounded AI Interpretation | 把结构翻译成可读语言，每条引用对真实事实校验；默认关闭或校验失败时降级 |
| TP-21 表达粒度调节 | **C21** Explanation Companion（隐性） | 方向已由规则定下后，决定用什么粒度说出来。生硬模板在 M81a 中直接导致流失 |
| TP-17 投影通道 | **C17** Understanding Projection（隐性） | 保证此刻用户看到的认知状态与理解结构一致、可复现、可回放 |
| TP-06 来源分级刻度 | **C06** Source Grading | 「这是谁说的」——一手 / 学术 / 参考三级，口径全局唯一 |
| TP-07 证据强度刻度 | **C07** Evidence Claim | 「凭什么」——依据有多硬，以有序刻度呈现，不是有无二值 |
| TP-08 溯源与异议叙述 | **C08** Provenance Tracing | 「有没有人不同意」——溯源清单 + 已登记异议；无异议时明说「当前无已登记异议」，不留静默空白 |

**C2 落点在旅程中的位置（关键）**：真相刻度三件套**贴在结论旁边出场**，不是一个需要用户主动去查的独立环节。用户读到「A 导致了 B」的同一时刻，就看得见这句话的证据强度、来源等级、以及是否存在异议。这一条同时满足两件事：Article 0 第三句成为用户可感知能力（不再是后台质量属性），以及「不跳出产品」（用户不必离开结论去别处查证）。

**降级诚实（B1 §9 F-2）**：因果实例稀薄时，不显示空的机制位；由 TP-11 以「事实语言化」身份接住（不挂解释标签、不配置信度，ADR-0015 D4），同时由 T5 的 TP-16 把这处缺失登记为 `follow_cause` 缺口——「产品暂时答不了」被转化成「你可以自己去追的一条线」，而不是一堵墙。

**交棒条件**：机制被说清且可信度被称量，用户开始问「那这有什么意义 / 别处呢」。

### T4 · 8:00–11:00 意义与对比

| 项 | 内容 |
|----|------|
| 用户处境 | 他手上有若干因果，但还不知道它们怎么组织起来，也不知道这是普遍还是特例 |
| 认知事件 | 从「一串因果」变成「一个理解框架」，并经过一次跨文明校验 |

**触点与能力来源**

| 触点 | 能力 | 在这一段做什么 |
|------|------|--------------|
| TP-13 意义入口 | **C13** Semantic Understanding | 回答「这个连接对我理解整体有什么用」。解释层说机制，理解层说意义——只有到这一步才长出理解结构 |
| TP-14 对比台 | **C14** Cross-civilization Comparison | 「同时期别处怎么做的、差别为什么产生」。**首访路径的 P0 独立入口**，也承接从 T1 就被看见的那扇门 |
| TP-03 边界续走位 | **C03** Cross-topic Connectivity | 对比与意义追问会自然把用户带出当前主题；跨主题连通让探索链不撞墙，用户落到新主题重新进入 TP-01 |

**C3 落点在旅程中的完整表述（ADR-0015 D3 / R5）**

| 时刻 | Compare 在首访路径中的存在形式 |
|------|---------------------------|
| T1 | **入口被看见**：用户知道「这里可以比较」，无前置条件 |
| T2–T3 任意时刻 | **可提前直入**：用户自发比较需求一冒出来就能进，不必先完成理解（§7 变体 V2） |
| T4 | **默认出场**：即便用户没有自发提出，主路径也会带他经过一次跨文明对照 |
| 供给不足时 | **诚实处理**：对比台以「可对比对象成对存在」为出场条件；不成对时呈现已知边界说明 + TP-16 补齐动作，不做点进去是空的入口（B1 §9 F-3） |

**为什么对比必须在首访出现**：四场用研三场自发提出，它是相对百科与 AI 问答最强的差异点（P1-01 C14）。首访没经过对比的用户，感受到的产品与一个做得好一点的百科没有区别。

**交棒条件**：理解框架成型，或对比结论形成，用户开始出现「我还缺什么」的自觉。

### T5 · 11:00–13:00 推进闭环

| 项 | 内容 |
|----|------|
| 用户处境 | 这一段做完了。他不知道下一段去哪——**这是 S004 十二分钟离场的确切时刻** |
| 认知事件 | 从「我走完了」变成「我知道我还缺什么，而且我知道往哪补」 |

**触点与能力来源**

| 触点 | 能力 | 在这一段做什么 |
|------|------|--------------|
| TP-16 下一步探索 | **C16** Cognitive Advancement Decision | 由认知缺口生成一个 `ExplorationAction`（**不是推荐**），告诉用户「你还没走过哪个维度 / 你缺哪条因果链」，并说明理由与补多少 |
| TP-27 停滞接住 | **C27** Deterministic Guide | 用户停在某一步不知该做什么动作时，以确定性模板给出动作提示（禁 LLM、禁打分、禁个性化） |
| TP-18 会话记忆延续 | **C18** Cognitive Memory | 同一会话内，后一段接得住前一段的缺口。Phase 2 为会话态（ADR-0015 D6），刷新即重置，不伪称长期记忆 |

**C1 落点在旅程中的呈现（ADR-0015 D1 / A2）**

用户在这一刻实际读到的是四件事，全部取自 A2 契约字段，无一取自行为指标：

| 用户读到 | A2 字段 | 用户的感受 |
|---------|---------|-----------|
| 这是哪一类推进（打开新维度 / 追一条因果 / 再深一层 / 换个语境比 / 收一收） | `actionType` | 「它知道我在做什么阶段」 |
| 去哪 | `targetEntity` | 「有具体去处」 |
| 为什么是它 | `rationale.text`（可追溯 `ruleId` + `triggeredDimension`） | 「它给的理由我能复述」 |
| 走完能补多少 | `coverageBeforeAfter.delta` | 「我看得见自己在补什么」 |

**三条呈现红线**：① 语汇禁用「推荐 / 猜你喜欢 / 其他用户也看了」；② 理由必须可复述，不能只是一句「相关」；③ 用户拒绝这个方向同样是有效结束（C16 定义），不得反复纠缠或换个说法再推一次——反复推送就是转化优化，即 X01。

**用户视角的根本区别**：推荐说的是「你可能喜欢这个」；这里说的是「你这块还空着」。前者的主语是系统的预测，后者的主语是用户的认知结构。

**交棒条件**：用户采纳或拒绝该方向。采纳则回 T2 开始新一轮（探索循环）；接近 15 分钟或出现离场意图，则进 T6。

### T6 · 13:00–15:00 镜像离场

| 项 | 内容 |
|----|------|
| 用户处境 | 他准备走了。**这一刻决定他能否回答「你觉得自己变聪明了吗」** |
| 认知事件 | 从「我看了一些东西」变成「我看见了这一次的自己」 |

**触点与能力来源**

| 触点 | 能力 | 在这一段做什么 |
|------|------|--------------|
| TP-19 成长刻度 | **C19** Growth Measurement | 汇总本次会话的认知结构变化：深度增量、维度增量、连接增量。度量的是认知结构，不是用户行为 |
| TP-22 镜像出口 | **C22** Cognitive Mirror（**L4.5 终点出口**） | 把用户自己的轨迹结构化后原样反射：他反复回到哪些维度、惯用哪条推进路径。由用户自己解读 |

**C4 落点在旅程中的四条约束（ADR-0015 D2 / ADR-0013 D3）**

| 约束 | 在离场这一刻的具体含义 |
|------|---------------------|
| 只反射，不投喂 | 镜像里不出现任何「所以你应该去看 X」。用户想继续，自己从常驻层回去 |
| 只用自身轨迹 | 原料只有 TP-20 / TP-15 / TP-19，没有他人行为、流行度、点击率 |
| 反射即终点，无出边 | 镜像输出不回流成为 TP-16 的输入；导航上不存在 Mirror → Policy 这条路 |
| 解读权归用户 | 给结构不给结论，不评判他学得好不好，不告诉他「你是某某类型的学习者」 |

**会话态诚实（ADR-0015 D6）**：Phase 2 不持久化，因此镜像反射的是「**这一次探索**里，你……」，而不是长期人格画像。`continuityScore` 连续性分量在本期明示为「跨会话能力尚未开启」，不伪造数值（口径细则见 B5 §4）。跨会话镜像列 v2。

**离场判据**：见 §6。

## 4. 探索循环（Experience Loop）

15 分钟主路径是一次线性叙述，但产品的真实形态是一个**可重复的闭环**：

```
   TP-25 问题锚
        │
        ▼
   TP-01 事实 → TP-02 关系 → TP-11 理由 ─┬→ TP-10 机制 → TP-13 意义
        ▲                                └→ TP-06/07/08 真相刻度（贴住每条结论）
        │                                          │
        │                                          ▼
        │                                     TP-14 对比台
        │                                          │
        └────── TP-16 下一步（ExplorationAction）◄──┘
                        │
                        │（用户接近离场时，且仅在此时）
                        ▼
                 TP-19 成长刻度 → TP-22 镜像出口（终点，无回边）
```

- **循环的驱动力是认知缺口，不是内容供给。** 每转一圈，`coverageRatio` 上升、`missingDimensions` 缩短，这是循环会自然收敛而不是无限刷的原因。
- **循环的出口只有一个方向：Mirror。** 镜像不参与循环，它在循环之外、之后。
- 首访 15 分钟通常走 1 到 2 圈；走满一圈即构成一次完整体验，走两圈是更好的情况，走不完一圈是失败。

## 6. 离场判据（最高判据的可操作化）

ADR-0013 D1 规定最高判据为：**用户离场时能否回答「你觉得自己变聪明了吗」**。本旅程把它拆成三问，三问全中方为通过：

| # | 离场时用户应能回答 | 由哪一段交付 | 对应 Article 0 |
|---|------------------|------------|--------------|
| 1 | 「我搞明白了一件事，而且我能讲出它的来龙去脉」 | T2 + T3 + T4（理解链） | 第一句 对象层 |
| 2 | 「我知道这件事有多可信，也知道哪里还有争议」 | T3（真相刻度三件套） | 第三句 真值层 |
| 3 | 「我看见了这一次我自己是怎么走的、我对什么感兴趣」 | T6（镜像出口） | 第二句 主体层 |

**次级判据**（M89.1，继续有效）：用户离场时应认为产品是「带我理解一个主题」，而不是「在回答我的问题」。本旅程以 T4 意义与对比、T5 缺口驱动的推进两段共同保证这一感受。

## 7. 变体路径（证明不只有一条黄金路径）

首访不是只有一种走法。以下三条变体必须同样走得通，否则「顺滑」只是主路径上的顺滑。

### V1 · 带着目标进场（走 TP-24）

| 段 | 变化 |
|----|------|
| T1 | 用户直接用 TP-24 定向直达命中目标，跳过 TP-26 起跳台。**TP-25 问题锚仍须补上**——否则整次探索没有语义锚，后面的 TP-16 无缺口可算 |
| T2 起 | 与主路径合流 |
| 风险 | 检索命中即走，用户把产品当搜索引擎用。接住方式：命中后立刻由 TP-02 关系展开把他从「查一个词」带进「看一张网」；TP-24 本身不产生理解，这一点在体验上必须被结构接管 |

### V2 · 一进来就想比较（提前直入 Compare）

| 段 | 变化 |
|----|------|
| T1 | 用户看见 Compare 入口，直接进入 TP-14，**不经过 T2/T3** |
| T4 位置 | 对比台在无前置理解时出场，此时需要 TP-04 时间对齐提供同时性，TP-13 意义入口在对比后补建 |
| 之后 | 对比引出的疑问把用户带回 TP-01/TP-02（B3 §7 转移矩阵 Compare→Explore 一格） |
| 意义 | 这条路径是 C3 提为 P0 的真正兑现：比较不再是理解完之后的奖励，而是一种可以先发生的进入方式 |

### V3 · 中途停滞（走 TP-27）

| 段 | 变化 |
|----|------|
| 任意段 | 用户停下、不知道该做什么动作 → TP-27 停滞接住给确定性动作提示 |
| 之后 | 若停滞的是「动作」，TP-27 解决；若停滞的是「方向」，交棒 TP-16 由认知缺口生成方向 |
| 红线 | TP-27 禁个性化、禁打分（C27 定义），它给的是「你现在可以做这个动作」，不是「你应该去看这个内容」。混淆二者即滑向 X01 |

## 9. Exit Criteria 自检

| 判据 | 回答 | 依据 |
|------|------|------|
| 第一次来的用户 15 分钟内能顺滑体验所有能力吗？ | 能 | §2 六段时间预算合计 15 分钟；§8 三十个触点全部出场；隐性/常驻触点不占用户动作时间，以全程在场方式生效（§5）；§7 三条变体路径同样走得通 |
| 任何能力是否需要跳出产品？ | 否 | 全部触点在同一 Explorer Session 内（B3 §1.2 P-A）；真相刻度贴住结论出场，用户不必离开结论去查证（T3） |
| 是否出现多个产品感觉？ | 否 | 四主干共用同一探索语法（B3 §3）；术语与定位全程不换台（§5）；Compare 与 Mirror 虽是独立主干，但动作序列同构 |
| 是否存在体验断裂？ | 否 | 每段有明确交棒条件与风险接住（§3）；三处供给稀薄（C05/C10/C14）均有诚实降级（T2/T3/T4）；停滞与拒绝均为有效结束（§7 V3、T5） |
| C1 是否植入？ | 是 | T5 专节：下一步呈现为认知缺口驱动的 ExplorationAction，四要素全取自 A2 契约，三条呈现红线 |
| C3 是否植入？ | 是 | T1 入口被看见 / T2–T3 可提前直入 / T4 默认出场 / 供给不足诚实处理；§7 V2 为专门变体路径 |
| 是否写了代码 / 组件 / 颜色？ | 否 | 全文只描述用户处境、认知事件与触点交棒 |
