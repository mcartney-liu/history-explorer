# ADR-0013: Product Ultimate Positioning（产品终极定位入宪）

- **Status**: Accepted / Frozen
- **Date**: 2026-08-07
- **Decider**: PO（翔哥）
- **Supersedes**: 无（新增最高层定位，不废止既有 ADR）
- **Related**: ADR-0012（FRW 冻结流程）、M85.1（Relationship ≠ Edge）、M88.0（Exploration ≠ Recommendation）、M89.1（体验阶段与禁项）、M81a（真人观察 N=4）

---

## 1. Background（背景）

History Explorer 自立项以来，产品定位历经多次演进：知识图谱查看器 → 历史探索工具 → 历史理解探索引擎（历史认知 OS）。2026-08-06 FRW Phase 0 产出《Product Discovery Report v1》，将定位固化为「历史理解的探索引擎」，并通过全部六条 Exit Criteria。

2026-08-07，PO 给出**最终定位三句话**，其抽象层级高于既有全部定位表述：

> 第一句：它是一个帮助人类逐渐形成文明、理解、认知结构的探索系统。
> 第二句：它能够帮助用户找到自己的兴趣和自己的学习方法。
> 第三句：它帮助用户无限逼近真相。
>
> 通俗版：用户进来的时候好奇，离开的时候有了一个更聪明的自己。

经与 Phase 0 认知基线逐条比对，识别出三处落差：

| 定位句 | 基线覆盖度 | 落差性质 |
|--------|-----------|---------|
| ① 形成文明 · 理解 · 认知结构 | 高 | 「历史」限定词被移除，领域边界需重新界定 |
| ② 找到自己的兴趣与学习方法 | 低 | **结构性缺口**：五层能力全在处理内容，无一层处理「用户这个人」；北极星四项无一度量此项 |
| ③ 无限逼近真相 | 中 | 底座已有（Evidence/Source 三级/confidence），但为后台质量属性；既有表述为防御性（不承诺答案），PO 表述为进取性（带你逼近真相） |

其中第二句在 M81a 真人观察中已有自发信号但未被承接：S004「这个就是我探索的兴趣」（兴趣自我发现）、S002 自行归纳「了解–研究–扩展」三段法（方法自我生成）。

按 FRW 铁律⑤（任何新增能力须从 Phase 0 重评接入），定位变更较新增能力更根本，故需修订 Phase 0 产物后方可进入 Phase 1。

## 2. Decision（决策）

### D1. 三句话升为 Product Constitution 第零编，凌驾八编之上

三句话以中文原句为权威文本入宪，定名 **Article 0 — Ultimate Positioning（产品终极定位）**。层级关系：

```
Article 0  产品终极定位（本 ADR 确立）
   ▲ 约束
第一编 产品信念 B1-B5
第二编 产品禁区
第三编 体验宪法 P01-P09
第四编 前端不可妥协 FP-01~03
第五编 架构冻结边界
第六编 治理机制
第七编 决策四问
第八编 团队级 P0 执行规则
```

任何下位条款与 Article 0 冲突时，以 Article 0 为准，冲突项须走 Freeze Revision Gate 修订。

**三层结构（本 ADR 对三句话的权威解读，不可另行诠释）**：

| 层 | 定位句 | 回答的问题 | 度量对象 |
|----|--------|-----------|---------|
| 对象层 Object | ① 形成文明 · 理解 · 认知结构 | 用户脑中长出了什么 | 认知结构 |
| 主体层 Subject | ② 找到自己的兴趣与学习方法 | 用户认识了怎样的自己 | 元认知 |
| 真值层 Truth | ③ 无限逼近真相 | 长出来的东西可不可靠 | 可信度 |

三层缺一不可：仅 ① 是「知道得更多」；①+② 是「知道自己怎么知道」；①+②+③ 才是「更聪明」。

**新增可证伪判据（替代 M89.1 原判据作为最高判据）**：用户离场时能否回答「你觉得自己变聪明了吗」。答不上来即定位失败。原 M89.1 判据（「在回答问题还是带我理解主题」）降为次级判据，继续有效。

### D2. 历史 = 首个载体，产品本体 = 认知结构探索系统

- **产品本体**：帮助人类形成认知结构的探索系统，领域无关。
- **当前载体**：历史，且为当前唯一载体。
- **实现范围锁定**：MVP 及可见里程碑内**只做历史**，不扩张领域。本条不构成任何多领域实现授权。
- **依据**：M76-M77 已验证本体框架可插拔，架构上不阻塞未来扩展。
- **约束**：任何多领域实现动作须另走 Freeze Revision Gate，本 ADR 不授权。

后续文档中「历史理解的探索引擎」表述保留为**载体层描述**，不再作为产品本体定义。

### D3. 第二句落地形态 = Cognitive Mirror（认知镜像）

**定义**：系统只将用户自身的探索轨迹结构化后反射给用户，由用户自己解读，系统不据此投喂内容。

| 维度 | Cognitive Mirror（采纳） | Recommendation（禁止） |
|------|------------------------|----------------------|
| 主体 | 用户自己看见自己 | 系统替用户决定 |
| 数据流向 | 轨迹 → 结构化 → 呈现给用户 | 轨迹 → 模型 → 内容投喂 |
| 兴趣定义 | 用户反复回到的维度 | 系统预测的偏好 |
| 方法定义 | 用户惯用的推进路径 | 系统优化的转化路径 |
| 目标函数 | 用户的自我认识 | 停留时长 / 点击率 |

**防火墙（新增，与 M88.0 同级）**：Cognitive Mirror 的输出**不得**作为 ExplorationPolicy 的输入参与下一步权重计算。镜像是终点，不是中间层。违反此条即滑向 M88 战略第九节列为最大风险的推荐系统。

### D4. 新增体验原则 P09 真相可逼近性，关闭 R9

**P09 Truth Approachability（真相可逼近性）**：用户在任一结论处，都能看见该结论的证据强度、来源分级与存在的异议叙述，并能感知「我离真相更近了」。

- 姿态变更：从防御性（历史无唯一答案，故不承诺答案）转为进取性（提供可逼近真相的路径与刻度）。
- 既有底座直接承接：Evidence 分级、Source 三级分级（43 SourceRecords）、CausalStatement.confidence、evidence_refs。
- 变更实质是**从后台质量属性提升为前台体验元素**，不新增数据模型，不触碰冻结边界。
- **R9 正式关闭**（「信任」是否升为显式体验原则）：Resolution = 以 P09 形式采纳，命名为 Truth Approachability 而非 Trust，因「信任」是结果，「可逼近」是机制。

### D5. 补充：历史定位再澄清 + 跨学科学原子化愿景（Supplement 2026-08-07 PO 口述）

> 来源：PO 于 2026-08-07 口述补充，明确本补充对 V1/V2 为「补充优先，冲突以现在为准」。

**D5.1 历史产品的真实身份（澄清 D2，无冲突）**
- 历史是**当前阶段的验证场景**，也是**未来会独立推出的一个产品**。
- 它**不是**产品本体；产品本体仍是 Article 0 之「帮助人类形成认知结构的探索系统」。
- 与 D2 的关系：D2 称历史为「首个载体 / 当前唯一载体」。本补充将历史的身份进一步澄清为「验证场景」——历史的重要性被下调，产品边界不被历史锁死。二者无矛盾，本补充属 D2 的向下澄清。

**D5.2 未来愿景：跨学科学原子化贯通（新增，补充 D2 之未来扩展）**
- 终极形态：把**各学科学知识打散为原子化知识单元（atomic knowledge units）**，再**贯通连接**。
- 覆盖学科不限于历史：文学、科学读物（如《时间简史》）、地理等，均能量化为可探索结构。
- 与既有架构的关系：M76-M77 已验证多领域本体框架可插拔；本期冻结不预支跨领域实现，跨学科学属未来架构研究。

**D5.3 兴趣发现 = 待解决的大问题（强化 D3 / 主体层，无冲突）**
- 人很难自己发现兴趣所在（文学 / 历史 / 其他）。平台目标之一即帮助用户**看见自己对什么有兴趣**。
- 这把 Article 0 第二句从「产品目标」上升为「待解决的大问题」，强化 Cognitive Mirror（D3）存在的根本理由，未改变 Mirror 防火墙。

**冲突判定**：本补充与 V1/V2 及 ADR-0013 D1–D4 **无冲突**；D5.1 为 D2 的向下澄清，D5.2/D5.3 为补充。依 PO 明示「冲突以现在为准」，本次无冲突情形，全部作为累积补充。

**代码 / 冻结影响**：零。8/18 枚举、内存 JSON、排除清单、ai_gateway 唯一 AI 例外全部原样。跨学科学属未来愿景，不在本期实现范围。

**新增未决项**：OD-05（跨学科学原子化的知识单元粒度与贯通关系模型，属未来架构研究，不阻塞本期）。

## 3. Consequences（后果）

### 正面

- 定位具备可证伪判据，且判据比既有更贴近用户可感知语言。
- 长期悬置的 R9 得到闭合。
- 第二句补齐了产品在「用户成长」方向上的目标缺失，continuityScore 的产品意义从「跨会话连续」升级为「跨会话的自我认识累积」。
- 领域边界一次性讲清，避免 Phase 2 体验架构按错误边界设计。

### 负面 / 风险

- **R-1 指标缺口**：现行北极星 understandingGrowthScore 四项（depthDelta / dimensionDelta / connectionDelta / continuityScore）无一度量第二句与第三句。定位与度量暂不同步。
- **R-2 架构缺层**：五层能力（L1 Fact → L5 Experience）无处安放 Cognitive Mirror，落层未定。
- **R-3 滑坡风险**：Cognitive Mirror 与推荐系统在实现层极易混淆，D3 防火墙必须进入 CI 或评审 checklist，否则纸面约束会失效。
- **R-4 文档面广**：Product_Constitution、PROJECT_CONTEXT、Product_DNA、PRD、FRW Phase 0 产物均含旧定位表述，一次性同步成本高。本 ADR 仅同步宪法与 Phase 0 产物，其余文档标记待同步。
