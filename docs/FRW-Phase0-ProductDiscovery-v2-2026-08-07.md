## 一、产品定位 v2（Task 0.1 重写）

### 1.1 终极定位（PO 权威文本，中文原句为准）

> 第一句：它是一个帮助人类逐渐形成文明、理解、认知结构的探索系统。
> 第二句：它能够帮助用户找到自己的兴趣和自己的学习方法。
> 第三句：它帮助用户无限逼近真相。
>
> 通俗版：用户进来的时候好奇，离开的时候有了一个更聪明的自己。

### 1.2 三层结构

| 层 | 定位句 | 回答的问题 | 度量对象 | 基线覆盖 |
|----|--------|-----------|---------|---------|
| 对象层 Object | ① 形成文明 · 理解 · 认知结构 | 用户脑中长出了什么 | 认知结构 | 已覆盖（Understanding Transition） |
| 主体层 Subject | ② 找到自己的兴趣与学习方法 | 用户认识了怎样的自己 | 元认知 | **结构性缺口** |
| 真值层 Truth | ③ 无限逼近真相 | 长出来的东西可不可靠 | 可信度 | 有底座，未上台面 |

三层缺一不可。仅 ① 是「知道得更多」；①+② 是「知道自己怎么知道」；①+②+③ 才是「更聪明」。
**聪明 = 结构 + 方法 + 判断力**，这是本产品对「更聪明的自己」的唯一定义。

### 1.3 领域边界（ADR-0013 D2）

- **产品本体**：帮助人类形成认知结构的探索系统，领域无关。
- **当前载体**：历史，且为当前唯一载体。
- **实现范围**：MVP 及可见里程碑内只做历史，不扩张领域。多领域实现须另走 Freeze Revision Gate。
- **架构依据**：M76-M77 已验证本体框架可插拔，架构不阻塞未来扩展。
- v1 的「历史理解的探索引擎 / 历史认知 OS」表述**降级为载体层描述**，不再是产品本体定义。

### 1.4 它不是什么

v1 第一节的七条排除（百科 / 知识图谱查看器 / AI 聊天机器人 / 时间轴工具 / 搜索引擎 / 推荐系统 / 内容 App）**全部继续有效**，理由不变。

v2 补充一条：

| 不是 | 差异根因 | 依据 |
|------|---------|------|
| 学习路径规划器 | 路径规划是系统替用户安排学习顺序；本产品是用户自己长出方法后被系统照见 | ADR-0013 D3 Cognitive Mirror 防火墙 |

### 1.5 可证伪判据（最高判据，替代 v1 判据的首要地位）

用户离场时能否回答：**「你觉得自己变聪明了吗？」**
答不上来即定位失败。

v1 判据（「你觉得它是在回答问题，还是带你理解一个主题？」）降为**次级判据**，继续有效。

两级判据的关系：次级判据检验过程正确性（是否在做探索而非检索），最高判据检验结果有效性（探索是否真的产生了成长）。

## 二、产品目标 v2（Task 0.2 修订）

### 2.1 最终要解决的问题（扩展）

v1 表述：一个人对历史「知道很多事实，但理解不了它为什么这样发生」。

v2 扩展为三重问题，对应三层定位：

1. **结构问题**：知道很多事实，但建不起因果结构（v1 原问题）
2. **主体问题**：学了很久，但说不清自己真正对什么感兴趣、自己是怎么学会的
3. **真值问题**：接受了一堆说法，但不知道哪条更可靠、离真相还有多远

现有工具（搜索 / 百科 / AI 问答）三个问题一个都不解决，且第 2、3 个问题几乎无人正面处理。

### 2.2 北极星指标（保留，缺口已登记）

```
understandingGrowthScore = depthDelta + dimensionDelta + connectionDelta + continuityScore
```

M88.5.1 定性锚句「衡量认知结构变化，非用户行为」继续有效，DAU / 时长 / PV / 点击率继续排除。

**已识别缺口（OD-01，转 Phase 1）**：四项分量全部服务第一句（对象层），**无一项度量第二句与第三句**。定位与度量当前不同步。

| 定位句 | 现有度量 | 缺口 |
|--------|---------|------|
| ① 认知结构 | depthDelta / dimensionDelta / connectionDelta / continuityScore | 无 |
| ② 兴趣与方法 | 无 | 兴趣清晰度、方法自觉度均无度量 |
| ③ 逼近真相 | 无（confidence 是数据属性，非用户增益度量） | 用户感知到的「逼近程度」无度量 |

Phase 1 需裁决：增补并列指标 / 重构为合成指标 / 暂不度量。**Phase 0 不预设结论。**

### 2.3 continuityScore 的意义升级

v1：continuityScore 证明「为什么必须持续探索」。
v2：在三层定位下，continuityScore 的产品意义升级为**跨会话的自我认识累积**——用户第二次回来时，落在 missingDimensions 上的首探行为，既是认知结构的延续，也是「我知道自己缺什么」这一元认知能力的外显。它同时服务第一句和第二句。

## 三、核心能力地图 v2（Task 0.3 增量）

### 3.1 五层能力总图

v1 第 3.1 节五层结构（L1 Fact → L2 Explanation → L3 Understanding → L4 Runtime → L5 Experience）**完整保留，逐字有效**，不再复制，参见 v1 第三节。

### 3.2 新增待落层：Cognitive Mirror（认知镜像）

**定义**：系统只将用户自身的探索轨迹结构化后反射给用户，由用户自己解读，系统不据此投喂内容。

| 维度 | Cognitive Mirror（采纳） | Recommendation（禁止） |
|------|------------------------|----------------------|
| 主体 | 用户自己看见自己 | 系统替用户决定 |
| 数据流向 | 轨迹 → 结构化 → 呈现给用户 | 轨迹 → 模型 → 内容投喂 |
| 兴趣定义 | 用户反复回到的维度 | 系统预测的偏好 |
| 方法定义 | 用户惯用的推进路径 | 系统优化的转化路径 |
| 目标函数 | 用户的自我认识 | 停留时长 / 点击率 |

**数据来源均为既有制品，无需新增采集**：ExplorationState（coveredDimensions / missingDimensions / coverageRatio）、Personal Exploration Trail（M63-B/M83）、ExplorationMetrics 四 Delta。

**落层未定（OD-02，阻塞 Phase 1 结论）**：
- 选项甲：作为 L4 Runtime 的只读投影扩展（沿用 MemoryProjection 模式）
- 选项乙：新增 L4.5 Meta-cognition 独立层（理由：它度量的对象是用户而非知识，与 L1–L4 的对象根本不同）

Phase 1 能力验证时须先定此项，否则 Phase 2 无法确定它在体验架构中的位置。

### 3.3 能力间的关系约束（v1 六条 + v2 新增第七条）

v1 第 3.3 节六条禁止关系**全部保留**（Fact⇄AI 单向 / L2≠L3 / L3→L4 必经 Projection / L4→L5 只读 / Package 不拥有事实 / Guide 不做个性化 / Exploration≠Recommendation）。

**新增第七条（ADR-0013 D3 防火墙，与 M88.0 同级）**：

> **Mirror 是终点，不是中间层。** Cognitive Mirror 的输出不得作为 ExplorationPolicy 的输入参与下一步权重计算。

违反此条即滑向 M88 战略第九节列为最大风险的推荐系统。此约束须进入 Phase 1 的验证清单与后续评审 checklist（风险 R-3），纸面约束不足以防止实现层滑坡。

### 3.4 已实现 vs 仅为契约

v1 第 3.4 节结论**完全不变**，包括架构师关于 `frontend/src/next/` 游离于冻结白名单与文档之外的关键发现。该发现构成 R1，仍阻塞 Phase 1。

v1 第五节七条心智信号、五阶段旅程、Explore/Discover/Understand/Connection 动词选择**全部保留**。

| 原信号 | v1 中的地位 | v2 中的地位 |
|--------|-----------|-----------|
| S004「这个就是我探索的兴趣」 | 心智信号之一 | **第二句（兴趣发现）的一手实证** |

## 八、三个核心问题 v2

**Q1 到底是什么？（重答）**
一个帮助人类形成认知结构的探索系统，当前以历史为唯一载体。它同时做三件事：把事实转换成用户脑内的因果结构（对象层）、把用户的探索轨迹反射成用户对自己兴趣与方法的认识（主体层）、把每个结论的可靠程度变成用户可感知的刻度（真值层）。三件事都做到，用户离场时才会觉得自己变聪明了。

**Q2 为什么这样设计？（v1 八条因果链保留，新增两条）**

v1 第 1–8 条不变（历史价值在关系里 → 图本身无意义需语义层 → 不能承诺答案 → 必须承诺方向感 → 方向感必须可信 → 一次理解不够 → 体验必须单一 Shell → 规则需强制力）。

9. 认知结构长在用户脑子里，而用户看不见自己的脑子 → 必须有一面镜子把轨迹照回去（Cognitive Mirror）
10. 镜子一旦开始替用户做决定就变成推荐系统 → 必须立防火墙把镜子锁死在终点位置（ADR-0013 D3）

**Q3 为什么不能设计成别的样子？（v1 五种替代设计保留，新增一种）**

| 替代设计 | 撞墙点 | 后果 |
|---------|--------|------|
| 学习路径规划器 | 违反 Article 0 第二句 + ADR-0013 D3 | 系统替用户安排顺序，用户永远长不出自己的方法，第二句直接落空 |

更根本一层不变：以上全部是「交付信息」型产品，价值在交付瞬间完成；本产品价值定义是跨会话的认知与自我认识增长。价值定义不同，架构必然不同。

## 十二、Supplement A — 跨学科学原子化愿景与历史定位澄清（2026-08-07 PO 口述补充）

> 本节能与 V2 主体并存，无冲突；历史身份澄清见 ADR-0013 D5.1，未来愿景见 D5.2，兴趣大问题见 D5.3。
> PO 明示：本补充与 V1/V2 冲突处以本次口述为准；无冲突处作为补充累积。本次经判定无冲突（D5 冲突判定）。

### A.1 历史产品的真实身份
历史是当前阶段的**验证场景**，也是未来会独立推出的一个产品。它**不是**产品本体——产品本体是 Article 0 定义的「帮助人类形成文明、理解、认知结构的探索系统」。

### A.2 未来愿景：原子化知识 + 跨学科学贯通
- 终极形态：把各学科学知识**打散为原子化知识单元**，再**贯通连接**。
- 覆盖学科不限于历史：文学、科学读物（如《时间简史》）、地理等，均能量化为可探索结构。
- 与 M76-M77 多领域本体可插拔验证一致；本期冻结不预支跨领域实现（OD-05）。

### A.3 兴趣发现 = 待解决的大问题
人很难自己发现兴趣所在（文学 / 历史 / 其他）。平台目标之一即帮助用户**看见自己对什么有兴趣**——这是 Article 0 第二句的产品级大问题定义，也是 Cognitive Mirror（D3）存在的根本理由。

### A.4 冲突处理原则（PO 明示）
本补充与 V1/V2 如有冲突，以本次口述为准；无冲突部分作为补充累积。本次无冲突情形，全部累积。

## 十三、Supplement B — 产品哲学七问（2026-08-07 PO 要求落盘）

> 七问将 Article 0 三层定位翻为「用户视角」的浓缩哲学，与 v2 / ADR-0013 完全一致、互为补全。PO 于 2026-08-07 裁定落盘。

### B.1 七问七答

**① 用户为什么来到这里？**
带着**好奇**来：心里有个模糊的兴趣或话题（常只是一个名词），但只有碎片化事实、建不起因果结构，更说不清自己为什么感兴趣、哪条说法可信。他不是来查答案的（搜索/百科/AI 问答都能查），是来「弄明白它到底怎么回事，顺便看清自己」的。M81a 四场真人全是一进来就找入口想探索，但没人真正知道「我该探索什么」。

**② 首页应该完成什么使命？**
把「好奇」翻译成「第一次探索的起跳」——**而不要求用户先知道自己要什么**。三条：不审问（M89.1 硬禁搜索框主导入口，R6 已裁选项 A）；给方向感不给答案（呈现维度/主题入口，点一个就能开始）；种下成长预期（感到「这是能让我变聪明的地方」）。

**③ Explore 与 Understand 有什么区别？**
- Explore = 过程/动作层：用户主动沿维度走、发现事实、建立连接的行为；可发生而无结果（S004 探索 12 分钟未长出结构）。
- Understand = 状态/结果层：探索之后在用户脑中长出的因果结构（L2 Explanation → L3 Understanding）。
- 关系：Understand 不能无 Explore；Explore 可以无 Understand。产品价值定义是 Understanding 的增量，不是 Explore 的时长。

**④ 一次探索成功意味着什么？**
用户离场能答出最高判据「我变聪明了吗？」三件都发生：对象层增量（coveredDimensions↑、connectionDelta>0，长出属于自己的因果结构）；真值层刻度（能说清这条多可靠、离真相差哪步，P09）；主体层微光（照见一点点兴趣或方法，Cognitive Mirror）。反面＝找到一堆事实却说不清「为什么」＝搜索引擎产出，非探索成功。

**⑤ 用户离开的时候应该带走什么？**
对应三层定位三样：对象层＝一段属于自己的因果结构（一张「为什么」的网）；主体层＝对自己兴趣/方法的一点点新认识；真值层＝对「这条多可信、离真相多远」的判断刻度。外加一个钩子＝「我还缺什么」的 missingDimensions 清单（下次回来的理由）。

**⑥ 用户为什么还会回来？**
因为带走的是「一个未完成的、属于我的认知结构」，不是「看完的内容」：missingDimensions 是开放钩子；Cognitive Mirror 让用户看见「我在长」，成长感驱动自发回流；系统不投喂（Exploration≠Recommendation），回流来自主权与成长欲而非推送绑架；continuityScore 升级为「跨会话的自我认识累积」，回来时系统接住上次缺口。

**⑦ 产品体验哲学（一句话）**
我们不做答案的供应商，只做认知结构的脚手架：陪你探索、帮你照见自己、让你离真相更近一步。

### B.2 与既有决议的呼应

- ③ Explore/Understand ⇄ L2/L3 五层能力、S004 12min 失败案例。
- ④ 成功判据 ⇄ Article 0 最高可证伪判据「我变聪明了吗」、P09、D3 Cognitive Mirror。
- ⑥ 回流 ⇄ continuityScore 意义升级（跨会话自我认识累积）、M88.0 Exploration≠Recommendation。
