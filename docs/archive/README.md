# docs/archive — 历史里程碑过程文档归档

> **归档性质**：本目录存放**已发布里程碑（vM65 / vM66）的过程性报告与阶段性快照**。
> 这些文档对应的里程碑均已 CLOSED 并 release（vM 标签已在仓库），其**最终结论已沉淀**在 `README.md`（Latest releases 段）、`PROJECT_CONTEXT.md` §5 与 `CHANGELOG.md` 中。

## 归档规则

- **只读档案**：归档内容不随新里程碑更新，保留当时的历史事实。
- **查询入口**：需要某里程碑的完整过程细节时，按文件名检索本目录；需要最新状态时，以 `README.md` / `PROJECT_CONTEXT.md` / `CHANGELOG.md` 为准。
- **不混入**：归档文档不参与任何功能/验证流程（freeze-check 仅扫描 `backend/` 与 `frontend/`）。
