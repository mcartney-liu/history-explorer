## 一、问题现象

实体卡显示名「罗马文明」（Roman Civilization），但 AI 生成的"历史见解"内容写的是**罗马帝国**：
- 内容提到"公元前 27 年屋大维建立元首制 → 公元 476 年西罗马帝国灭亡"
- 依据引用 Cambridge Ancient History 关于 **Roman Empire** 的年代定义
- 用户感知：AI 内容与实体名不贴切

## 二、根因（已代码+数据双重核实）

**数据建模层面**（本次要修的部分）：

```
实体：civ-roman（显示名 Roman Civilization / 罗马文明）
global_id：roman_empire:civ-roman        ← 挂在「罗马帝国」topic 下
start_date：27 BC / end_date：476 CE     ← 这是罗马帝国的年代，不是罗马文明
evidence 引用：ec-rom-001 / ec-rom-002   ← 证据声明几乎全是 "The Roman Empire…" 表述
```

即：**「罗马文明」这个实体（王政→共和→帝国→拜占庭延续，跨约 2200 年）被建模成了「罗马帝国」（27BC–476CE 一个阶段）**。主题、起止年份、证据全是帝国的，AI 自然输出罗马帝国内容。

**代码层面**（已完成，提交 8c1e46a）：
- `backend/app/ai_gateway/insight_service.py`：prompt 现在显式传实体名 + 约束"勿用证据中的相近概念替代实体本身"
- `backend/app/main.py`：生成入口取实体显示名传入

代码修复后 AI 知道该写"罗马文明"，但**证据仍是帝国内容，仍可能被带偏**——所以必须修数据。

## 四、修改内容（核心）

### 4.1 实体起止年份修正

将 `civ-roman` 的起止年份从"罗马帝国年代"改为"罗马文明全周期"（建议值，可按史料调整）：

```json
"start_date": { "value": -753, "precision": "year", "certainty": "approximate", "label": "753 BC" },
"end_date":   { "value": 1453, "precision": "year", "certainty": "approximate", "label": "1453 CE" }
```

依据：罗马文明从王政时代（传说前 753 年建城）延续至东罗马（拜占庭）1453 年终结，**远不止帝国阶段**。

### 4.2 补非帝国期证据

当前证据 `ec-rom-001` / `ec-rom-002` 几乎全是帝国期内容。建议新增/调整声明覆盖以下阶段（每条都需真实史料来源，遵循项目"不编造事实"纪律）：

| 阶段 | 建议证据主题 | 来源类型示例 |
|------|-------------|-------------|
| 王政时代（753–509 BC） | 罗慕路斯建城传说、王政制度 | Cambridge Ancient History 等 |
| 罗马共和国（509–27 BC） | 元老院与执政官、十二铜表法、布匿战争扩张 | Cambridge Ancient History 等 |
| 罗马帝国（27 BC–476 CE） | 现有 ec-rom-001/002 保留 | 已有 |
| 东罗马/拜占庭（330–1453） | 君士坦丁堡建都、罗马法传承（查士丁尼法典） | Oxford Handbook of Roman Studies 等 |

若证据声明在 `data/examples/roman_empire_example.json` 内或独立文件，请按你现有 `evidence`/`claims` 结构补充并更新 `civ-roman.evidence` 引用数组。

### 4.3 检查 aliases / labels

```
aliases: ['Rome', 'Romanitas', 'Imperium Romanum']
labels:  { en: 'Roman Civilization', la: 'Civilitas Romana', zh: '罗马文明' }
```
- 建议确认是否需要把 `Imperium Romanum`（帝国含义）从 aliases 中移除或降级，避免别名引向帝国
- `labels.zh = 罗马文明` 保持不动（前端依赖它显示中文名）
