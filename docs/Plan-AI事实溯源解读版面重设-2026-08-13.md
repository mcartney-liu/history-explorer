## 一、当前业务含义（事实）

`AIExplanationPanel` 组件挂在实体页「研究 → 解读与 AI」区底部，业务本质是：

> **让用户就当前实体向 AI 提问，AI 拿着知识图谱里"经证据验证的事实"回答，不是凭空编。**

三个交互：
1. **顶部 5 个模式标签**（为何重要 / 为何发生 / 历史影响 / 多文明视角 / 时间线解读）—— 必须先选一个，决定 AI 用什么"思考角度"答
2. **输入框** —— 用户输入具体问题
3. **「问 AI」按钮** —— 把「模式 + 问题」发给后端，AI 基于图谱事实回答

## 二、当前 UX 痛点（PO 截图反馈）

1. **模式标签不像按钮**：视觉上像装饰标签/分类标签，但其实必须点击才能选"思考角度"；选中态变化不够明显
2. **输入框不知道问什么**：placeholder 只给一个例子（"这个文明为何衰落？"），用户不知道还能问什么
3. **顶部文案晦涩**：「基于当前探索上下文（1 个实体）提供可被知识图谱验证的解读」——技术化，用户不知道"我能得到什么"
4. **没解释业务价值**：用户进到这个板块不知道"为什么要用这个、用了能帮上什么忙"
5. **底部 hint 重复**：「输入问题后点击「问 AI」…」和「AI 解读由知识图谱中的事实驱动…」——两段都在解释用法，但位置分散

## 三、设计目标

把"我能拿这个干什么"和"怎么用"在前 3 秒内讲清楚，再给一个有引导感的输入。

## 四、版面设计（改造后）

```
┌──────────────────────────────────────────────────┐
│  AI 事实溯源解读                              [已溯源]│
│  用知识图谱里真实可查的事实，回答你关于            │
│  《罗马文明》的任何问题。                         │
│  ────────────────────────────────────────         │
│  选一个角度（必选）                                │
│  [为何重要] [为何发生] [历史影响]                  │
│  [多文明视角] [时间线解读]                        │
│  当前选择：为何重要 ↓                           │
│  ────────────────────────────────────────         │
│  试试问：                                         │
│  · 为什么罗马文明能延续上千年？                   │
│  · 罗马文明对后世法律有什么影响？                 │
│  · 罗马文明是怎么衰落的？                         │
│  ────────────────────────────────────────         │
│  [输入框：例如「罗马文明为何重要？」]   [问 AI]   │
│  答案会基于知识图谱中已验证的事实，并附引用          │
└──────────────────────────────────────────────────┘
```

**关键改进**：

| 改动 | 解决 |
|------|------|
| 顶部副标题改为「用知识图谱里真实可查的事实，回答你关于《X》的任何问题」+ 实体名 | 解释业务价值（这次回答基于什么） |
| 模式标签加「选一个角度（必选）」，选中态用强对比（主色填充 + ✓） | 明确这是选项、可点击 |
| 选完模式后下方显示「当前选择：XX ↓」提示 | 视觉反馈用户"已经选过了" |
| 新增 3 条**示例问题**（基于当前实体，依据模式动态生成） | 解决"不知道问什么" |
| 输入框 placeholder 保留引导文案 | 强化提示 |
| 底部两段 hint 合并为一句：「答案会基于知识图谱中已验证的事实，并附引用」 | 减少视觉噪音 |

## 五、动态示例问题（按模式 + 实体）

每种模式给 3 个示例问题（写死模板，按实体名拼）：
- `why_important`：「为什么{name}在历史上重要？」「{name}对后世有什么影响？」
- `why_happened`：「{name}是何时/如何形成的？」「{name}兴起的关键因素是什么？」
- `historical_impact`：「{name}对后世的影响是什么？」「{name}的遗产如何延续？」
- `multi_civilization_view`：「其他文明如何看待{name}？」「{name}与其他文明有何交流？」
- `timeline_explanation`：「{name}经历了哪些阶段？」「{name}的兴衰时间线是怎样的？」

用户点击示例 → 自动填入输入框，可直接改。

## 七、验收标准

1. 用户打开板块 3 秒内理解：①这是干什么的（业务价值）②怎么用（模式 + 输入）
2. 模式标签视觉上明显是按钮（至少 1 个有强对比选中态）
3. 输入框未输入时看得到 3 个示例问题（点击自动填入）
4. 底部只剩 1 句免责声明，不重复
5. 测试全绿，TS 零错误，Freeze 通过
