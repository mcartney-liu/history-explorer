## 2. Diff Summary

### Task 1 — `narrative.ts`: new `resolveNarrativeKey()` (pure, no data change)
Keeps `NARRATIVE` / `getNarrative` / `hasNarrative` untouched.

```ts
// M35.1 — normalize a possibly-partial navigation target into the canonical
// narrative key. global_id wins; else reconstruct `${topic}:${id}`; else topic slug; else ''.
export function resolveNarrativeKey(input: {
  global_id?: string
  topic?: string
  id?: string
}): string {
  if (input.global_id) return input.global_id
  if (input.topic && input.id) return `${input.topic}:${input.id}`
  if (input.topic) return input.topic
  return ''
}
```
